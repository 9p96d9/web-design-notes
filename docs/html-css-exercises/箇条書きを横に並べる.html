コーディング演習 2025/12/18

箇条書きを横に並べる

  • プロンプト例

初心者が２カラムを理解するためのシンプルなレイアウトを作成して

  • ロゴは中央揃え
  • ロゴ下にnavを５個長方形の横個並び
  • メインビジュアルの下に「main」と「aside」を配置
  • footerは、幅100%・背景色：黒色

[ ロゴ（中央） ]
[ nav ×5（横並び） ]
[ メインビジュアル ]
[ main | aside ]   ← 2カラム
[ footer（黒・100%） ]
完成例

  • 本来「２カラムレイアウト」は、ブログ（CMS）のようにデータベースの更新にともなう表示の更新に向いています
ワイヤーフレーム

制作ポイント
  • コンテンツをブラウザの左右中央に配置
  • ナビゲーション・ボタンを横並び（均等割）
  • 文章構造（mainとaside）を横並び
  • main内のdl（dtとdd）を横並び

main タグ

  • body 内に、１回のみ設定
  • main 直下に見出しは不要

aside タグ

  • 主要な内容と間接的な関係しかない記事に設定（asideがなくても、mainの内容のみでテーマを伝えることが可能）

nav タグ

  • ナビゲーションリンクの主要なブロックのみに用います（グローバルナビゲーションにのみ設定）
  • 現在このような長方形型ボタンは、積極的には採用されてはいません

time タグ

  • 特に「ブログ」のような「投稿時間」と数字を連携させる場合は必須

ナビゲーションの設定

幅の計算

  • calc() 関数は、計算式の結果を CSS プロパティの値として使用されます

developer.mozilla.org

.gnav li {
  width: calc(100% / 5);
  text-align: center;
  line-height: 50px;  /* ボタンの高さを指定 */
}

.wrapper の指定

  • 「display: flex;」で、横並び
  • 「gap: 40px;」で空きを指定（「justify-content: space-between;」を設定すると、この空きが可変になります）
  • 「gap: 40px;」を固定値で指定した場合、「main」「aside」は足して「100％」にすると、gapの値を引いて計算しなくても自動的に割合を計算して表示されます
