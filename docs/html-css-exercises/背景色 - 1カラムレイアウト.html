}

}

  margin-bottom: 10px;
}

🚀 学習ポイント解説

① HTMLの基本構造
header → main → footer

→ Webページの王道構成

② 1カラムレイアウトの作り方
main {
  max-width: 800px;
  margin: 0 auto;
}

→ 横幅を制限＋中央寄せ

③ 最初に覚えるべきCSS
  • margin
  • padding
  • background
  • color
  • font-family
  • border-radius
