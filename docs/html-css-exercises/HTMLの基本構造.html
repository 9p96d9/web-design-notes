HTMLの基本構造

  • プロンプト例

（わたしは、）HTMLの基本構造を作りたい

目的

  • タイピングの練習
  • HTMLの全体像を捉える
  • コンテンツ内容の意味づけではなく「<head>」と「<body>」の部分を理解する

制作手順

  1. テキストエディターで基本構造を作成する
  2. 「index.html」というファイル名で保存して、ブラウザで表示
HTMLとは
  • コンテンツ内容の構造化をする言語
  • ブラウザ上で閲覧者にコンテンツ内容を伝えるための意味付けをする
  • 構造化することにより「検索エンジン」も認識しやすくなる
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのHTML</title>
</head>
<body>

  <h1>Hello World!</h1>
  <p>ここに本文を書きます。</p>

</body>
</html>

解説

<!DOCTYPE html>

→ HTML5で書いていることを宣言

<html lang="ja">

→ ページの言語が日本語であることを指定

<head>

→ 設定エリア（文字コード・タイトル・CSSなど）

<meta charset="UTF-8">

→ 日本語が文字化けしないようにする

<title>

→ ブラウザのタブに表示されるタイトル

<body>

→ 実際に画面に表示される内容
