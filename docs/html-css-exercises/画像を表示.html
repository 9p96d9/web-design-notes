HTMLで画像を表示する方法

HTMLで画像を表示するには、 タグを使います。

基本構文

<img src="画像のURLまたはパス" alt="代替テキスト">

各属性の意味

属性 説明
src 表示したい画像のURLやファイルパス
alt 画像が表示できないときの代替テキスト（必須推奨）
例①：同じフォルダの画像を表示
<img src="sample.jpg" alt="サンプル画像">

【フォルダ構成例】

index.html
sample.jpg
例②：別フォルダの画像を表示
<img src="images/photo.png" alt="写真">

【フォルダ構成例】

index.html
images/
  photo.png
例③：Web上の画像を表示
<img src="https://example.com/image.jpg" alt="外部画像">

<img> タグ（画像表示の基本）

主な属性（超重要）

1. src（必須）

  • 画像ファイルの **場所（URLやパス）** を指定する

2. alt（必須レベルで重要）

  • 画像が表示されないときや、スクリーンリーダー用の代替テキスト
  • 画像が壊れたときに表示される
  • SEOにも影響あり
  • 装飾目的だけなら alt="" でもOK
サイズ指定
  • どちらか一方だけ指定すると縦横比を保ったまま自動調整されます。

HTML属性で指定（簡単）

<img src="image.jpg" alt="画像" width="300" height="200">

CSSで指定（おすすめ）

  • CSS指定の方が柔軟＆モダン
<img src="image.jpg" alt="画像">

img {
  width: 300px;
  height: auto;
}
よくあるミス
  • ❌ 閉じタグを書く
<img></img>  ← ダメ

画像が表示されない原因

原因 対策
パス間違い フォルダ構成を確認
拡張子違い `.jpg` と `.JPG` の大文字小文字に注意
ファイル未配置 正しい場所に保存
よく使う便利属性
  • loading="lazy"（遅延読み込み）

→ スクロールされるまで読み込まない（高速化◎）

<img src="image.jpg" alt="画像" loading="lazy">

相対パスと絶対パス

<!-- 同じフォルダ -->
<img src="image.jpg">

<!-- imagesフォルダ内 -->
<img src="img/image.jpg">

<!-- ひとつ上の階層 -->
<img src="../image.jpg">
