就職のためにWebページを作る

コーディング演習 2025/12/01

就職のためにWebページを作る

  • プロンプト例

完全未経験者がWebページを完成させる作業を始める前に考えて置くべきこと

  • 就職するための理解を深めるために作りたい

Webページ制作を始める前に考えておくべきこと

① 目的をはっきりさせる（これが一番重要）

まず 「何のために作るのか」 を明確にしましょう。

【例】

  • 自己紹介サイトを作りたい
  • 会社のホームページを作りたい
  • ブログを始めたい
  • ポートフォリオを作りたい
  • 商品を売りたい（EC）

👉 目的によって、必要な技術・構成・デザインが全く変わります。

② ゴールのイメージを持つ

「完成形」をイメージしておくと、途中で迷いにくくなります。

考えるポイント

  • 何ページくらい必要？
  • スマホ対応は必要？
  • 問い合わせフォームは必要？
  • ログイン機能は必要？

初心者なら
まずは「1ページのシンプルなWebサイト」 をゴールにすると挫折しにくいです。

③ 最初から完璧を目指さない

未経験者が一番挫折しやすい原因です。
❌ 完璧なデザイン
❌ プロレベルの機能
❌ 最新技術のフル導入

⭕ まずは

  • 表示できる
  • クリックできる
  • 情報が読める

👉 「動くものを作る」ことを最優先 にしましょう。

④ 作る流れを理解する（全体像）

制作の流れを知ると混乱しません。

  • 目的決定
  • 構成を考える（どんなページが必要か）
  • ワイヤーフレーム（簡単な設計図）
  • HTML作成
  • CSSでデザイン
  • スマホ対応
  • 公開

👉 いきなりコードを書き始めないのがポイントです。

就職のためにWebページを作る人が最初に考えるべきこと

① ゴールは「作品」＋「説明できる力」

企業が見ているのは：

何を作ったか × どんな考えで作ったか

つまり：

  • 作品（ポートフォリオ）
  • 制作プロセスを説明できる力

これが 就職に直結する評価ポイント です。

② 目標は「ポートフォリオ1サイト完成」

まず目指すべきゴール：

オリジナルのWebサイトを1つ完成させる

これがあるだけで、
未経験 → 本気度の高い未経験者 になります。

③ 企業が評価するポイント（超重要）

企業はここを見ます：

項目 見られる理由
見た目 デザインセンス
構成 情報設計力
使いやすさ UX思考
コード 基礎理解
制作意図 論理力

👉 「なぜこう作ったか」説明できるかが超重要

就職向け：最短で評価される制作ルート

ステップ①：テーマ決定（実務を想定）

架空でもOK。実在しそうなサイトが一番評価されます。
おすすめテーマ：

  • カフェの公式サイト
  • 美容室のサイト
  • IT会社のコーポレートサイト
  • 学習塾のサイト
  • イベントLP

👉 「実案件っぽさ」が超重要。

ステップ②：サイト構成（企業が一番見る）

最低限これ：

  • トップページ
  • サービス紹介
  • 会社概要
  • お問い合わせ

👉 この構成が 実務で最も多い基本型。

ステップ③：設計を言語化（超重要）

これが 就職で最強の武器 になります。
【例】

ターゲットを20代女性に設定し、
ファーストビューでは安心感と清潔感が伝わるデザインを意識しました。

👉 設計意図を説明できる = 即戦力評価
