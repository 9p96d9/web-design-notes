HTMLの見出しと段落の関係について解説して

HTMLにおける見出し（heading）と段落（paragraph）の関係は、文書構造を正しく表現し、可読性・アクセシビリティ・SEOを高めるためにとても重要です。

1. 見出しと段落の基本

見出し（<h1> ～ <h6>）
  • 文書の構造（アウトライン）を作るための要素
  • 重要度の高い順に：
  • <h1> → 最も重要な見出し（ページ全体のタイトル）
  • <h2> → 大きな章
  • <h3> → 小さな節
  • ...
  • <h6> → 最も小さな見出し
段落（<p>）
  • 文章のまとまりを表す要素
  • 見出しの説明・本文として使う

2. 正しい構造の基本形

<h1>HTMLの基本</h1>

<h2>見出しとは</h2>
<p>見出しは文書の構造を表します。</p>

<h2>段落とは</h2>
<p>段落は文章のまとまりを表します。</p>

構造イメージ

HTMLの基本（h1）
 ├ 見出しとは（h2）
 │   └ 説明文（p）
 └ 段落とは（h2）
     └ 説明文（p）

3. 見出しと段落の関係性

基本ルール
👉 「見出し → その説明として段落」
つまり：

<h2>トピック</h2>
<p>このトピックについての説明文</p>

という形が最も自然です。

4. 良い例と悪い例

  • ✅ 見出しは順番を守る
  • ❌ いきなり飛ばさない
  • ✅ <h1>は基本1ページに1つ（特に <header> 内にある <h1> ）
  • ❌ デザイン目的で使わない（文字を大きくしたいだけなら CSS を使う）

✅ 良い例

<h2>犬の特徴</h2>
<p>犬は人懐っこく、学習能力が高い動物です。</p>
  • 見出しと段落の意味が一致
  • 文書構造が明確

❌ 悪い例①：見出しレベルが飛ぶ

<h1>タイトル</h1>
<h3>概要</h3>

👉 h2 を飛ばすのはNG
正しくは：

<h1>タイトル</h1>
<h2>概要</h2>

❌ 悪い例②：見出しだけで文章構造を作る

<h2>犬の特徴</h2>
<p>犬は人懐っこく、学習能力が高い動物です。</p>

👉 見出しは文章を書く場所ではない
→ 段落（

）を使うべき

<p> の中に入れられないタグ（重要）

  • <p> は ブロック要素を中に含められない
  • ✅ OKなもの（インライン要素）

5. SEO・アクセシビリティの観点

検索エンジン（SEO）

  • 見出し構造を元にページ内容を理解
  • 正しい構造 → 検索順位向上に有利

スクリーンリーダー（アクセシビリティ）

  • 見出しを使って文章構造を把握
  • 適切な階層 → 視覚障害者にも読みやすい
ありがちなNG例まとめ

見た目は似てるけど 意味が全然違う

  • ❌ 空の <p>
<p></p>
  • ❌ デザイン目的だけの <p>
<p class="box">ただの箱</p>
  • 文章じゃないなら <div> を使う
