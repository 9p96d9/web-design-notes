データからカードUIを動的生成する

JavaScript・DOM操作 2026/05/28

動的生成とは何か

図鑑データが17件ある。これをHTMLで手書きするとこうなる。

手書きの問題：
データが1件増えるたびにHTMLを1ブロック追加しなければならない。
17件 → 170件になった瞬間、HTMLが膨大になり、修正も地獄になる。

動的生成はこれを解決する。データは1か所（zukanData）に、HTMLの構造は1か所（JS関数）に集中させる。

zukanData（17件のデータ） ↓ JavaScriptが走る カード17枚のHTMLを自動生成 ↓ #cardContainer に一気に流し込む

データが増えても、JS側を変える必要はない。zukanData に1行追加するだけで、カードも自動で増える。

forEach でカードを作る基本パターン

まずHTMLに空のコンテナを用意する。

<!-- index.html --> <div id="cardContainer"></div>

次にJSで各エントリをHTMLに変換して流し込む。

const container = document.getElementById('cardContainer'); zukanData.forEach(item => { const card = document.createElement('div'); card.className = 'zukan-card'; card.innerHTML = ` <img src="${item.image}" alt="${item.name}"> <div class="card-body"> <h3>${item.name}</h3> <p class="yomi">${item.yomi}</p> <span class="tag">${item.category}</span> <span class="tag">${item.season}</span> </div> `; container.appendChild(card); });

ポイントは テンプレートリテラル（バッククォート） だ。${item.name} のように書くと、変数の値をHTMLの中に埋め込める。

書き方結果
'<h3>' + item.name + '</h3>'文字列を + で連結（古い書き方）
`<h3>${item.name}</h3>`テンプレートリテラルで埋め込む（読みやすい）

innerHTML と appendChild の役割分担

card.innerHTML = `...`; // カードの中身を一気に設定 container.appendChild(card); // コンテナにカードを追加

innerHTML はノードの中身をまるごと書き換える。appendChild は子要素として末尾に追加する。この2つを組み合わせることで、「構造を文字列で作り → DOMツリーに挿入する」流れが完成する。

画像・よみがな・月表示の実装

実際のカードに表示したい要素を順番に見ていく。

画像の表示

<img src="${item.image}" alt="${item.name}">

image フィールドは /works/web/osanpo/img/zukan01.jpg のようなパス文字列になっている。そのまま src に埋め込むだけでよい。alt に name を入れておくと、アクセシビリティ対応にもなる。

よみがなの表示

<p class="yomi">${item.yomi}</p>

yomi フィールドはひらがなの読みを持っている。小さめのフォントでカード下部に表示すると図鑑らしさが出る。検索インデックスとして使う場合は非表示（CSS で display:none）にして data属性に持たせる方法もある。

月表示 — 配列を join で文字列に変換

month フィールドは配列なので、そのまま表示すると 3,4 のように出る。

// NG：そのまま埋め込む `<span>${item.month}</span>` // → 3,4 // OK：join で整形する `<span>${item.month.join('月・')}月</span>` // → 3月・4月
join(区切り文字) の使い方：
配列の要素を指定した区切り文字でつなぎ、1つの文字列にする。
[3, 4].join('月・') → "3月・4月"

memo フィールド — 空のときは非表示

memo が空のエントリもある。空文字のまま表示すると余白が生まれる。三項演算子で制御する。

// memo が空なら何も表示しない `${item.memo ? `<p class="memo">📝 ${item.memo}</p>` : ''}`
三項演算子の読み方：
条件 ? 真のとき : 偽のとき
item.memo が空文字（falsy）なら何も表示しない。

完成コード（まとめ）

function renderCards(data) { const container = document.getElementById('cardContainer'); container.innerHTML = ''; // 再描画前にクリア data.forEach(item => { const card = document.createElement('div'); card.className = 'zukan-card'; card.innerHTML = ` <img src="${item.image}" alt="${item.name}"> <div class="card-body"> <h3>${item.name} <span class="yomi">${item.yomi}</span> </h3> <p>${item.description}</p> <p>${item.month.join('月・')}月</p> ${item.memo ? `<p class="memo">📝 ${item.memo}</p>` : ''} <span class="tag">${item.category}</span> <span class="tag">${item.season}</span> </div> `; container.appendChild(card); }); } // 最初は全件表示 renderCards(zukanData);

関数化しておく理由がある。絞り込みやリセットのとき、引数を変えて renderCards(filteredData) と呼ぶだけで再描画できる。次の記事ではこの仕組みを使ってフィルター機能を実装する。
