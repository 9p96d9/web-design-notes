JavaScriptを実装するには？

  • JavaScriptを実装する方法は、Webページに動きを付ける場合とアプリやサーバーで使う場合で少し違います
HTMLにJavaScriptを実装する基本

方法1：HTML内に直接書く（簡単・学習向け）

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>JavaScriptテスト</title>
</head>
<body>

<button onclick="alert('こんにちは！')">クリック</button>

</body>
</html>

👉 ボタンを押すとアラートが表示されます。

方法2： 

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>JS実装</title>
</head>
<body>

<button id="btn">クリック</button>

<script>
  document.getElementById("btn").addEventListener("click", function() {
    alert("こんにちは！");
  });
</script>

</body>
</html>

👉 実務では この書き方が基本 です。

方法3：外部ファイルとして読み込む（実務で最重要）
【HTML】

<script src="script.js" defer></script>

【script.js】

document.getElementById("btn").addEventListener("click", function() {
  alert("こんにちは！");
});

👉 規模が大きくなったら必ずこの方法
