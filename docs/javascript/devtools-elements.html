ElementsタブでDOMとCSSをリアルタイムデバッグする

JavaScript・DevTools 2026/05/28

Elementsタブでできること

DevTools の Elementsタブは、HTMLとCSSを同時に確認・編集できる作業台だ。主にできることは3つある。

できること詳細
HTMLツリーの確認ブラウザが解釈したDOMの構造を階層表示で見られる
CSSのその場編集プロパティの値を書き換えて見た目をすぐ試せる（保存はされない）
CSS適用状況の確認どのルールが効いているか・打ち消されているかを一目で確認できる
「保存はされない」が重要：
Elements タブで HTML や CSS を編集しても、ページをリロードすれば元に戻る。あくまでブラウザ上の一時的な表示テストだ。確認できたら、エディタ側のソースファイルを編集する。

DOMツリーの読み方

Elementsタブを開くと、左側にHTMLのツリー構造が表示される。基本的な操作をまとめた。

要素をクリック → 右側の Styles パネルにその要素のCSSが表示される ▶ アイコンをクリック → 子要素を展開して中を確認できる 要素の上にマウスをホバー → ページ上で対応する領域がハイライト表示される 要素を右クリック → 「Copy selector」 → CSSセレクタをクリップボードにコピーできる

「Copy selector」で取得したセレクタは、JavaScript の querySelector() や querySelectorAll() にそのまま使える。

// Elements で右クリック → Copy selector で取得したセレクタを使う const el = document.querySelector('#main > ul > li:nth-child(2)'); console.log(el.textContent);
ページ内の要素を特定したいとき：
検査アイコン（矢印マーク）をクリックしてからページ上の要素をクリックすると、DOMツリーの該当箇所に自動でジャンプする。探している要素を素早く特定できる。

CSSをその場で編集する

右側の Stylesパネルでは、適用中のCSSプロパティを直接編集できる。

値をクリック → 直接入力で書き換え（矢印キーで数値を増減できる） 打ち消し線のプロパティ → 別のルールに上書きされて無効になっている チェックボックス → オフにするとそのプロパティだけ一時的に無効化できる 「element.style」欄 → ここに書くとインラインスタイルが追加される
打ち消し線 = 効いていないプロパティ：
「color を設定したはずなのに変わらない」というときは、Stylesパネルで打ち消し線が入っていないか確認する。より詳細なセレクタや !important によって上書きされているサインだ。

「element.style」欄はインラインスタイル（style="..." 属性）に対応する。ここで試してから、確認できたら CSS ファイルに書き移す使い方が効率的だ。

よく使う検査パターン

実際の作業でよく登場するパターンを4つ紹介する。

余白・パディングの確認

Styles パネルの下にある「Computed」タブを開くと、ボックスモデルの図解が表示される。margin・border・padding・content の実際の計算値を視覚的に確認できる。「なぜか隙間がある」「要素が押し出されている」というときに使う。

Computed タブ → ページ上部の box model 図を確認 → margin / padding の実際の値が px 単位で表示される

フォントが効いていない

Stylesパネルでは、そのプロパティがどのセレクタから継承されているかも表示される。「フォントを指定したのに変わらない」場合、より強いセレクタが別のフォントを設定しているケースが多い。

Styles パネルで font-family を探す → 打ち消し線のルールを確認 → どのセレクタが勝っているか特定する → 自分のセレクタを強くするか、継承元を修正する

ホバー状態をロックする

:hover のスタイルは、マウスを乗せている間しか確認できない。DevTools の :hov ボタンを使うと、ホバー状態を強制的に固定できる。

Elements で要素を選択 → Styles パネルの「:hov」ボタンをクリック → 「:hover」にチェックを入れる → マウスを外してもホバー状態のスタイルが表示されたまま
:focus・:active・:visited も同様に強制適用できる。
:hover だけでなく、フォーカス時・クリック中・訪問済みリンクのスタイルも同じ手順で固定して確認できる。

検査パターンまとめ
