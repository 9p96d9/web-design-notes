お気に入り機能と localStorage の使い方

JavaScript・localStorage 2026/05/28

localStorage とは

通常、JavaScriptで変数に値を入れても、ページを閉じると消える。localStorage はこれを解決する仕組みだ。

localStorage の特徴：
ブラウザが持つキー・バリュー形式の保存場所。ページを閉じても消えない。同じオリジン（ドメイン）のページ間で共有される。

基本の操作は3つだけだ。

// 保存 localStorage.setItem('キー', '値'); // 読み込み const value = localStorage.getItem('キー'); // 削除 localStorage.removeItem('キー');

注意点がひとつある。localStorage に保存できるのは文字列のみだ。配列やオブジェクトを保存するには、JSON に変換する必要がある。

// 配列を保存する const ids = [1, 3, 5]; localStorage.setItem('favorites', JSON.stringify(ids)); // → '{"0":1,"1":3,"2":5}' ではなく '[1,3,5]' という文字列で保存される // 読み込むときは JSON.parse で元に戻す const saved = JSON.parse(localStorage.getItem('favorites')); // → [1, 3, 5]（配列に戻る）
メソッド役割
JSON.stringify(値)JavaScript の値 → JSON文字列
JSON.parse(文字列)JSON文字列 → JavaScript の値

お気に入りトグルの実装

図鑑データの各エントリは favorite: true というフィールドを持っている。でもこの値はデータファイル内の初期値でしかない。ユーザーが操作した「実際のお気に入り状態」は localStorage で管理する。

設計方針

zukanData の favorite → 初期値（全て true） localStorage の favorites → ユーザーが操作した実際の状態 → ページ読み込み時に localStorage を優先する

お気に入りIDの配列を localStorage に保存する方針をとる。

お気に入りを保存する関数

function saveFavorites(ids) { localStorage.setItem('osanpo_favorites', JSON.stringify(ids)); } function loadFavorites() { const saved = localStorage.getItem('osanpo_favorites'); if (saved === null) { // 初回：zukanData の初期値を使う return zukanData.filter(item => item.favorite).map(item => item.id); } return JSON.parse(saved); }
null チェックが必要な理由：
getItem はキーが存在しないとき null を返す。
JSON.parse(null) は null になるので、初回は zukanData の初期値にフォールバックする。

ハートボタンのトグル

let favoriteIds = loadFavorites(); // 起動時に読み込む function toggleFavorite(id) { if (favoriteIds.includes(id)) { // すでにお気に入り → 外す favoriteIds = favoriteIds.filter(fid => fid !== id); } else { // お気に入りでない → 追加 favoriteIds = [...favoriteIds, id]; } saveFavorites(favoriteIds); updateHeartUI(id); // ハートの見た目を更新 }

スプレッド構文 [...favoriteIds, id] は「既存の配列をコピーして末尾に id を追加した新しい配列を作る」書き方だ。元の favoriteIds を直接変えない。

ハートUIの更新

function updateHeartUI(id) { const btn = document.querySelector(`[data-id="${id}"] .heart-btn`); if (!btn) return; btn.textContent = favoriteIds.includes(id) ? '❤️' : '🤍'; } // カード生成時にボタンを作る部分 card.innerHTML = ` ... <button class="heart-btn" data-id="${item.id}"> ${favoriteIds.includes(item.id) ? '❤️' : '🤍'} </button> `; card.querySelector('.heart-btn').addEventListener('click', () => { toggleFavorite(item.id); });

ページ読み込み時に状態を復元する

ページを開いたとき、localStorage から読み込んで初期表示に反映する必要がある。全体の初期化フローをまとめると：

① loadFavorites() → favoriteIds を取得 ↓ ② renderCards(zukanData) → カード全件描画 ↓ ③ 各カードのハートに favoriteIds を反映
// アプリ起動時 let favoriteIds = loadFavorites(); renderCards(zukanData); // renderCards 内でハートの初期状態も設定される

お気に入りだけ表示するフィルター

favOnlyBtn.addEventListener('click', () => { const favData = zukanData.filter(item => favoriteIds.includes(item.id)); renderCards(favData); });

favoriteIds の配列を includes() で引くだけで、お気に入り済みのエントリを取り出せる。前の記事で作った renderCards() がここでも使い回せる。
