「営業中 / 時間外」を判別

JavaScript 2026/01/19

「営業中 / 時間外」を判別

  • プロンプト例

JavaScriptで営業中か時間外かを判別 -営業中は、10時から21時まで

現在時刻で判定するシンプルな例
const now = new Date();
const hour = now.getHours(); // 現在の「時刻」

if (hour >= 10 && hour < 21) {
  console.log('営業中です');
} else {
  console.log('時間外です');
}

判定ルール

  • 「10:00」ちょうど → 営業中
  • 「20:59」→ 営業中
  • 「21:00」ちょうど → 時間外
分まで含めて正確に判定したい場合
const now = new Date();
const minutes = now.getHours() * 60 + now.getMinutes();
const open = 10 * 60;   // 10:00
const close = 21 * 60; // 21:00

if (minutes >= open && minutes < close) {
  console.log('営業中です');
} else {
  console.log('時間外です');
}

曜日ごとに営業時間を変えて判定する

  • プロンプト例

「曜日によって営業時間が違う」

  • 通常9時から19時まで
  • 水曜日・土曜日は、9時から12時まで
  • 日曜日は、休業
曜日別 営業時間判定（指定条件対応）

条件まとめ

曜日 営業時間
月・火・木・金 9:00 〜 19:00
水・土 9:00 〜 12:00
日 休業

現在時刻で判定

const now = new Date();
const day = now.getDay();   // 0=日,1=月,2=火,3=水,4=木,5=金,6=土
const hour = now.getHours();

let isOpen = false;

// 日曜は休業
if (day === 0) {
  isOpen = false;
}
// 水・土 → 9:00〜12:00
else if (day === 3 || day === 6) {
  if (hour >= 9 && hour < 12) {
    isOpen = true;
  }
}
// 月・火・木・金 → 9:00〜19:00
else {
  if (hour >= 9 && hour < 19) {
    isOpen = true;
  }
}

if (isOpen) {
  console.log("営業中");
} else {
  console.log("時間外");
}
