プログラムとは？

JavaScript 2026/01/01

プログラムとは？

  • プロンプト例

プログラムとは何か？初学者が理解できるように説明して

プログラムとは、

👉 コンピュータに「何を」「どんな順番で」やらせるかを書いた指示書のこと。

  • 「言語化」ではなく「手順化」
  • コンピュータはとても正直だけど、自分では何も考えられない
  • だから、人間が細かく・正確に手順の指示を書いてあげる必要がある。それがプログラム
身近な例で考えてみよう
  • レシピにたとえると…

カレーのレシピ

  1. 野菜を切る
  2. 肉を炒める
  3. 水を入れて煮る
  4. ルーを入れる

これを順番通りにやらないと失敗する。
👉 この「手順書」が、コンピュータにとってのプログラム。

コンピュータにとってのプログラム
  • 例えば「画面に『こんにちは』と表示したい」とする。
  • 人間なら一瞬だけど、コンピュータにはこんな感じで伝える必要がある。
  • 文字を表示する準備をして
  • 「こんにちは」という文字を指定して
  • 画面に表示する

この指示をプログラミング言語（Python、Java、Cなど）で書いたものがプログラム。

大事なポイント3つ

① コンピュータは空気を読まない

  • 「いい感じにやって」は通じない→ 全部書く必要がある

② 順番が超重要

  • 順番が違うと、エラーになったり、変な動きをする

③ プログラム = 考えを形にすること

  • 「こうなってほしい」を、コンピュータが理解できる形に変換する作業
まとめ
  • プログラムとは コンピュータへの指示書
  • レシピやマニュアルと同じ
  • 難しそうに見えるけど、本質は「順序立てて説明する」こと
