配列を利用する理由

JavaScript 2026/01/17

配列を利用する理由

  • プロンプト例

JavaScriptで配列を利用する理由

1. 複数のデータをまとめて管理できる
  • 配列を使うと、複数の値を1つの変数で管理できます。

配列を使わない場合

let apple = 100;
let banana = 200;
let orange = 150;

→ 変数が増えて管理が大変になります。

配列を使う場合

let prices = [100, 200, 150];

→ スッキリ管理できるようになります。

2. ループ処理と相性が良い
  • 配列は for文やforEachなどの繰り返し処理 と組み合わせることで、同じ処理をまとめて実行できます。
let scores = [80, 90, 70, 85];

for (let i = 0; i < scores.length; i++) {
  console.log(scores[i]);
}

→ 大量データの処理が簡単

3. データの追加・削除・変更が簡単
  • 配列は 要素の操作がとても便利 です。
let fruits = ['りんご', 'みかん'];

// 追加
fruits.push('バナナ');

// 削除
fruits.pop();

// 変更
fruits[0] = cいちご';
4. 実務で必須（超重要）

実際の開発では、以下のような 大量データの処理 に必ず配列が使われます。

  • 商品一覧
  • ユーザーリスト
  • APIから取得したデー
  • フォーム入力の集合
  • 検索結果一覧
let users = [
  { name: 'Tanaka', age: 20 },
  { name: 'Suzuki', age: 25 }
];
5. 配列を使わないと何が困る？
  • 変数が増えすぎて管理不能
  • 同じ処理を何度も書くことになる
  • プログラムが読みにくくなる
  • バグが増える

→ 配列は「整理整頓」そのもの
