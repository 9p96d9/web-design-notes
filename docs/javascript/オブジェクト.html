オブジェクト（object）

オブジェクトとは
  • 次の３つをひとまとめにした概念です
  1. データ
  2. オブジェクトを操作するメソッド（method）
  3. オブジェクトの状態を示すプロパティ（property）

document.getElementById('id名').プロパティ

「documentオブジェクト」の「getElementByIdメソッド」の値をプロパティ（実行）する

メソッドとプロパティの違い

  • 最後にカッコを指定しているのがメソッド
  • そうでないのがプロパティ
文字列は String オブジェクト
  • 「lengthプロパティ」文字列の長さを示す

ES6の場合

<body>
<h1>入力された文字を表示</h1>
<p>文字を入力してください。</p>
<p><input type="text" id="mytext"></p>
<button id="sendButton">送信</button>
<h2 id="msg">ここを書き換える</h2>
<script>
  const btnClick = () => {
    const msg = document.getElementById('mytext').value;
    document.getElementById('msg').textContent = `入力された文字の数は、「${msg.length}」です。`;
  };

  document.getElementById('sendButton').addEventListener('click', btnClick);
</script>
</body>

ES5の場合

<body>
<h1>入力された文字を表示</h1>
<p>文字を入力してください。</p>
<p><input type="text" id="mytext"></p>
<button onclick="btnClick()">送信</button>
<h2 id="msg">ここを書き換える</h2>
<script>
  function btnClick() {
    let msg = document.getElementById('mytext').value;
    document.getElementById('msg').textContent = `入力された文字の数は、「${msg.length}」です。`;
  }
</script>
</body>
変数と文字列の連結
  • 文字列と変数を続けて記述し、「バックテック（バッククォート）」で囲む
  • 変数は「${}」で囲む

大文字を小文字に変換
  • toLowerCase()メソッドを実行

ES6の場合

<body>
<h1>大文字を小文字に変換する</h1>
<p>文字を入力してください。</p>
<p><input type="text" id="mytext"></p>
<button id="sendButton">送信</button>
<h2 id="msg">ここを書き換える</h2>
<script>
  const btnClick = () => {
    const msg = document.getElementById('mytext').value;
    document.getElementById('msg').textContent = msg.toLowerCase();
  };

  document.getElementById('sendButton').addEventListener('click', btnClick);
</script>
</body>
