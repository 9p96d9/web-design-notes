JavaScriptで時間判別と曜日判別の問題を作成して

  • 結果は、consoleに表示

時間判別＆曜日判別 問題

問題①：時間によって挨拶を表示しよう

仕様
現在の時刻を取得し、時間帯に応じて以下のメッセージを表示するプログラムを作成してください。

時間帯 表示する結果
5時〜10時 おはようございます
11時〜16時 こんにちは
17時〜22時 こんばんは
23時〜4時 おやすみなさい

条件

  • Date オブジェクトを使って現在の時間を取得すること
  • if文 または switch文 を使うこと

結果例

こんにちは
問題②：曜日を日本語で表示しよう

仕様
今日の曜日を取得し、日本語で表示するプログラムを作成してください。

数値 曜日
0 日曜日
1 月曜日
2 火曜日
3 水曜日
4 木曜日
5 金曜日
6 土曜日

条件

  • getDay() を使用すること
  • switch文 または 配列を使って判別すること

結果例

今日は金曜日です
問題③（応用）：時間＋曜日の組み合わせ判定

仕様
現在の「時間」と「曜日」を使って、次のように表示を切り替えてください。

条件 表示
平日の9時〜17時 勤務時間中です
平日のそれ以外 業務時間外です
土日 休日です

結果例

勤務時間中です
サンプルコード
const now = new Date();
const hour = now.getHours();
const day = now.getDay();

// 時間判別
if (hour >= 5 && hour <= 10) {
  console.log(`おはようございます`);
} else if (hour >= 11 && hour <= 16) {
  console.log(`こんにちは`);
} else if (hour >= 17 && hour <= 22) {
  console.log(`こんばんは`);
} else {
  console.log(`おやすみなさい`);
}

// 曜日判別
const days = ['日', '月', '火', '水', '木', '金', '土'];
console.log(`今日は ${days[day]} 曜日です`);
