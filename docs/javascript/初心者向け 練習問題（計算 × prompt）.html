問題 1：2つの数字の足し算

問題

  • promptで2つの数字を入力し、その合計をconsoleに表示しなさい。

解答例

let a = prompt('1つ目の数字を入力してください');
let b = prompt('2つ目の数字を入力してください');

let result = Number(a) + Number(b);

console.log("合計は：" + result);

解説

  • prompt() → 文字列で入力される
  • Number() → 数値に変換
  • 文字列のまま足すと '2' + '3' = '23' になるので注意！
問題 2：引き算（大きい数 − 小さい数）

問題

  • 2つの数字を入力し、「大きい数 − 小さい数」の結果を表示しなさい。

解答例

let a = Number(prompt('1つ目の数字'));
let b = Number(prompt('2つ目の数字'));

let result;

if (a > b) {
  result = a - b;
} else {
  result = b - a;
}

console.log('引き算の結果：' + result);

解説

  • if文で大小比較
  • 必ず正の数になる計算ロジック
問題 3：掛け算

問題

  • 2つの数字を入力し、その掛け算結果を表示しなさい。

解答例

let a = Number(prompt('1つ目の数字'));
let b = Number(prompt('2つ目の数字'));

let result = a * b;

console.log('掛け算の結果：' + result);

解説

  • * が掛け算演算子
  • Number変換しないと計算バグの原因になる
問題 4：割り算

問題

  • 2つの数字を入力し、「1つ目 ÷ 2つ目」の結果を表示しなさい。

解答例

let a = Number(prompt('割られる数'));
let b = Number(prompt('割る数'));

let result = a / b;

console.log('割り算の結果：' + result);

解説

  • / が割り算
  • b が 0 のときはエラーになる（発展問題で例外処理が必要）
問題 5：平均値の計算

問題

  • 3つの数字を入力して、平均値を表示しなさい。

解答例

let a = Number(prompt('1つ目の数字'));
let b = Number(prompt('2つ目の数字'));
let c = Number(prompt('3つ目の数字'));

let average = (a + b + c) / 3;

console.log('平均値は：' + average);

解説

  • 合計 ÷ 個数 = 平均
  • 数式をそのままコードにする感覚を身につける

偶数・奇数判定

問題

  • 数字を1つ入力し、偶数か奇数かを判定して表示しなさい。

解答例

let num = Number(prompt('数字を入力してください'));

if (num % 2 === 0) {
  console.log('偶数です');
} else {
  console.log('奇数です');
}

解説

  • % → 余りを求める演算子
  • 偶数 → 2で割った余りが0
  • === → 厳密な比較（型も一致）
消費税計算（10%）

問題

  • 商品の税抜価格を入力し、消費税込価格（10%）を表示しなさい。

解答例

let price = Number(prompt('税抜価格を入力してください'));
let taxRate = 0.1;

let total = price + (price * taxRate);

console.log('税込価格：' + Math.floor(total) + '円');

解説

  • 消費税10% → ×1.1
  • 実務では Math.floor() で端数処理を行うことも多い
BMI計算

問題

  • 身長(cm)と体重(kg)を入力し、BMIを計算して表示しなさい。
  • BMI = 体重 ÷ (身長(m) × 身長(m))

解答例

let height = Number(prompt('身長(cm)を入力'));
let weight = Number(prompt('体重(kg)を入力'));

height = height / 100;

let bmi = weight / (height * height);

console.log('BMI：' + bmi.toFixed(2));

解説
cm → m に直すため ÷100

  • 計算式をそのままコード化
  • 小数点2桁まで表示
合計金額＋割引率計算

問題

  • 合計金額と割引率(%)を入力し、割引後の金額を表示しなさい。

解答例

let total = Number(prompt('合計金額'));
let discount = Number(prompt('割引率(%)'));

let result = total * (1 - discount / 100);

console.log('割引後金額：' + result + '円');

解説

  • 割引率を 小数に変換 → /100
  • 10%引き → 1 - 0.1 = 0.9
成績判定（if文）

問題

  • 点数を入力し、以下の条件で成績を表示しなさい。
点数 評価
90以上 A
80以上 B
70以上 C
60以上 D
60未満 F

解答例

let score = Number(prompt('点数を入力'));

if (score >= 90) {
  console.log('評価：A');
} else if (score >= 80) {
  console.log('評価：B');
} else if (score >= 70) {
  console.log('評価：C');
} else if (score >= 60) {
  console.log('評価：D');
} else {
  console.log('評価：F');
}

解説

  • 上から順に判定するのが重要
  • 大きい条件から書くのが
総合練習（発展）
let price = Number(prompt("商品価格"));
let qty = Number(prompt("個数"));
let discount = Number(prompt("割引率"));

let total = price * qty;
let result = total * (1 - discount / 100);

console.log("支払金額：" + result + "円");
