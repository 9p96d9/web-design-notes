prompt で入力された値を受け取って計算する方法

JavaScriptで prompt で入力された値を受け取って計算する方法

prompt() とは？

prompt('表示するメッセージ');
  • ユーザーに入力させるためのダイアログ（入力欄付きポップアップ）を表示する関数です。

👉 入力された値を 文字列（string）として取得 できます。

基本構文
let value = prompt('ここにメッセージ');

【例】

let name = prompt('あなたの名前を入力してください');
alert(name);

💡 入力 → OK → 入力した内容が name に入る

戻り値の仕組み
let x = prompt('入力してください');

この x に入る値は 必ず文字列 です。

👉 計算する場合は 数値に変換が必須

let num = Number(prompt('数字を入力'));
キャンセルが押された場合
let x = prompt('入力してください');
console.log(x);
操作 結果
OK + 入力 入力した文字
OK + 未入力 ''（空文字）
キャンセル null

安全な書き方

let x = prompt("数字を入力");

if (x === null) {
  alert("キャンセルされました");
} else {
  alert("入力値: " + x);
}
デフォルト値を設定する
prompt('メッセージ', '初期値');

【例】

let age = prompt('年齢を入力', '20');

→ 入力欄に最初から 20 が入る

よくあるトラブル集

数字なのに計算できない
let a = prompt('数字');
let b = prompt('数字');
alert(a + b);   // ❌

原因 → 文字列の連結

【解決】

alert(Number(a) + Number(b));
NaN になる
let x = Number(prompt('数字'));

入力が文字だった場合 → NaN（Not a Number）

【対策】

let x = Number(prompt('数字'));

if (isNaN(x)) {
  alert('数字を入力してください');
}

実用サンプル集

電卓ミニ版
let a = Number(prompt('1つ目の数字'));
let b = Number(prompt('2つ目の数字'));
let op = prompt('演算子を入力 (+ - * /)');

let result;

if (op === '+') result = a + b;
if (op === '-') result = a - b;
if (op === '*') result = a * b;
if (op === '/') result = a / b;

alert('結果: ' + result);
年齢判定
let age = Number(prompt('年齢を入力'));

if (age >= 20) {
  alert('成人です');
} else {
  alert('未成年です');
}
prompt の注意点
  • スマホでは 使いにくい
  • モダンなWebアプリでは ほぼ使わない
  • 学習・簡易入力には 最適

👉 実務では input + フォーム を使うことが多い
