ダイアログボックスを利用する

ダイアログボックスを利用する

  • プロンプト例

JavaScriptでダイアログボックスを利用する場合

  • JavaScriptでダイアログボックスを利用する場合、主に以下の 3種類の標準ダイアログ がよく使われます。
３種類のダイアログボックス
項目 コード
警告 alert()
確認 confirm()
入力 prompt()

alert（警告ダイアログ）

  • メッセージを表示し、OKボタンのみ のシンプルなダイアログです。
alert('処理が完了しました');

用途例

  • 完了通知
  • エラーメッセージ表示

confirm（確認ダイアログ）

  • OK / キャンセル の2つの選択肢を表示し、結果を true / false で受け取れます。
if (confirm('削除しますか？')) {
  console.log('削除しました');
} else {
  console.log('キャンセルしました');
}

【戻り値】

  • OK → true
  • キャンセル → false

用途例

  • 削除確認
  • 実行確認

prompt（入力ダイアログ）

  • 文字入力欄付き ダイアログです。
let name = prompt('名前を入力してください');

if (name !== null) {
  console.log(`こんにちは ${name} さん`);
}

【戻り値】

  • 入力 → 入力文字列
  • キャンセル → null

用途例

  • 簡易入力フォーム

実務でよく使われるカスタムダイアログ

  • 最近のWeb開発では、見た目や操作性を良くするため、標準ダイアログではなくHTML+CSS+JSでモーダルダイアログを作成 することが多いです。
<dialog id="myDialog">
  <p>本当に削除しますか？</p>
  <button onclick="ok()">OK</button>
  <button onclick="cancel()">キャンセル</button>
</dialog>

<script>
const dialog = document.getElementById('myDialog');

function openDialog() {
  dialog.showModal();
}

function ok() {
  console.log('OK');
  dialog.close();
}

function cancel() {
  console.log('キャンセル');
  dialog.close();
}
</script>
