記述ルールと出力

console 2025/10/02

JavaScriptの記述

  • テキストエディター「VS Code」を使用します

書き方のルール

  1. 基本的に「半角英数字と記号のみ」を使う
  2. 文字列を扱う場合は「シングルクォート」か「ダブルクォート」で囲む
  3. 大文字と小文字は区別される
  4. 命令文の末尾には「セミコロン」をつける
  5. 複数行にわたるまとまりの命令文は「{}波括弧」で囲む（囲まれた範囲をブロックと呼ぶ）

記述する場所

  • </head>の前（内部参照）
  • </body>の前（内部参照）
  • 外部JavaScriptファイル（外部参照）

<title>JavaScript</title>
</head>

</body>

文字列を出力

  • プログラムに直接記述した値のことを「リテラル」と呼びます
    1. 文字列リテラル：（いち、に、さん）という文字列
    2. 整数リテラル：（456）という整数値
    3. 少数リテラル：（78.9）という小数値
Hello World
  • 文字列の出力
  • コンソールに出力（ console.log(); ）
Google JavaScript Style Guide 和訳

文字コード
  • 文字コードは、UTF-8を使用する
  • UTF-8は、定義される文字集合を用いて記述された文字列をバイト列（数値の列）に変換する方式の一つ

    • プログラムに説明を書く

Chromeのconsoleを使う

  • console.log()
  • コンソールに出力（ console.log(); ）
コンソールの使い方
  • 「検証」→「Console」を選択
  • 記述されているコードをクリアにする

電卓代わりの数値計算

  • １行、式を入力して「return(Enter)」キーを押すと「実行」され結果が次の行に表示されます

  • 四則演算を「Console」の中で試してみましょう
コンソールへのいろいろな出力方法
// メッセージを出力
console.log('メッセージを出力');

// 情報として出力
console.info('情報です');

// 警告として出力
console.warn('警告です');

// エラーとして出力
console.error('エラーです');

画面構成説明
HTML表示現在表示してるページのHTMLが表示される
CSS表示現在表示してるページのCSSが表示される
コンソール簡単なプログラムを記述し、実行できる場所

出力例

四則演算
  • 演算子（operator）の前後は「半角スペース」を空ける
// 5と3を足した値を出力
console.log(5 + 3);

// 20から8を引いた値を出力
console.log(20 - 8);

// "4 + 5" を文字列として出力
console.log('4 + 5');

// 8と4をかけた結果を出力
console.log(8 * 4);

// 24を4で割った結果を出力
console.log(24 / 4);

// 7を2で割った余りを出力
console.log(7 % 2);
