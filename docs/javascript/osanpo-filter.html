カテゴリ・季節ボタンで絞り込む filter() の使い方

JavaScript・配列操作 2026/05/28

filter() の基本

JavaScriptの filter() は、配列から条件に合う要素だけを取り出して新しい配列を返すメソッドだ。元の配列は変わらない。

// 基本形 const result = 配列.filter(要素 => /* true か false を返す条件 */);

具体例で見てみよう。

const numbers = [1, 2, 3, 4, 5]; const even = numbers.filter(n => n % 2 === 0); // → [2, 4]（元の numbers は変わらない）

ルールはシンプルだ。

filter() の動き：
配列の全要素を1件ずつチェックする。コールバックが true を返した要素だけが新しい配列に入る。

図鑑データに当てはめると、「花だけ取り出す」「春のものだけ取り出す」が1行で書ける。

const flowers = zukanData.filter(item => item.category === '花'); const spring = zukanData.filter(item => item.season === '春');

カテゴリ絞り込みの実装

絞り込みの流れは3ステップだ。

① ボタンをクリック ↓ ② zukanData を filter() で絞る ↓ ③ renderCards() で再描画

ボタンを動的生成する

const filterArea = document.getElementById('filterArea'); // 「全て」ボタン const allBtn = document.createElement('button'); allBtn.textContent = '全て'; allBtn.addEventListener('click', () => renderCards(zukanData)); filterArea.appendChild(allBtn); // カテゴリボタン（categoryData から生成） categoryData.forEach(cat => { const btn = document.createElement('button'); btn.textContent = cat; btn.addEventListener('click', () => { const filtered = zukanData.filter(item => item.category === cat); renderCards(filtered); }); filterArea.appendChild(btn); });

クリックのたびに zukanData 全件を filter している。元のデータが破壊されないので、「全て」ボタンで renderCards(zukanData) と呼ぶだけで完全に元に戻せる。

アクティブボタンの見た目を変える

btn.addEventListener('click', () => { // 全ボタンの active を外す document.querySelectorAll('#filterArea button').forEach(b => b.classList.remove('active')); // クリックしたボタンに active を付ける btn.classList.add('active'); const filtered = zukanData.filter(item => item.category === cat); renderCards(filtered); });

複数条件の組み合わせ

「カテゴリ：花」かつ「季節：春」のように複数条件で絞り込む場合を考える。

まず選択状態をオブジェクトで管理する。

let activeFilters = { category: null, // null は「指定なし（全て）」 season: null };

絞り込み関数を1つにまとめる。

function applyFilters() { let result = zukanData; if (activeFilters.category) { result = result.filter(item => item.category === activeFilters.category); } if (activeFilters.season) { result = result.filter(item => item.season === activeFilters.season); } renderCards(result); }
設計のポイント：
filter を2回重ねることで AND 条件になる。
1回目の filter の結果をさらに filter するので、「カテゴリ AND 季節」の絞り込みが実現できる。

カテゴリボタンのクリック処理はこうなる。

btn.addEventListener('click', () => { activeFilters.category = cat; applyFilters(); });

「全て」ボタンのリセット処理

allBtn.addEventListener('click', () => { activeFilters = { category: null, season: null }; applyFilters(); });

activeFilters をリセットすれば、条件なし（全件）になる。filter() は元のデータを変えないため、いつでもリセットできる。

補足：OR 条件にしたいとき

// 「花」か「草」のどちらか const result = zukanData.filter(item => item.category === '花' || item.category === '草' ); // 選択中カテゴリが配列の場合（複数選択UIのとき） const selected = ['花', '草']; const result2 = zukanData.filter(item => selected.includes(item.category));
まとめ：
AND条件 → filter を2回重ねる
OR条件 → || または includes() を1つの filter の中で使う
