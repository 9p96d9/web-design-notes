３種類のダイアログボックス

項目コード
警告alert()
確認confirm()
入力prompt()

メッセージを表示するダイアログボックス

alert( メッセージ );

ユーザーに確認を求めるダイアログボックス

confirm( メッセージ );

変数 = confirm( メッセージ );

  • confirmメソッドは「戻り値を返す」
  • ブーリアン型「true（真）」または「false（偽）」
ユーザーにデータを入力してもらうダイアログボックス
  • promptから取得できた値は「文字列」です

prompt( メッセージ );

変数 = prompt( メッセージ, デフォルトの値 );

入力ダイアログで文字列を取得
  • console()で出力
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>消費税合算後の支払金額を求めるプログラム（基本）</title>
</head>
<body>
<script>
// 変数の値は「再代入」されるため「let」で宣言
  let price = prompt('単価を100以上の半角数字を整数で入力してください');
// parseInt()関数で、小数点以下は切り捨てて「整数化」
  price = parseInt(price);
  let piece = prompt('個数を1以上の半角数字を整数で入力してください');
  piece = parseInt(piece);

  const taxRate = 0.1;  // 消費税率
  let total = 0;  // 計算結果の初期値
</script>
</body>
</html>

この段階は、お金の計算であることにより整数化しています。
ダイアログボックスに「0」が入力された場合、「全角」が入力された場合もしくは計算できない文字が入力された場合は、条件分岐の内容に入った段階で「if」文を使い判別していきます。

元値と消費税額を加算

total = (price * piece) + (price * piece * taxRate)

consoleに出力

  • 出力を簡潔に記述するために、変数に代入します
  • 文字列と変数の値を同時に出力する場合は、テンプレートリテラルで記述
const str = `購入単価「${price}」円の商品を${piece}個購入した時の消費税合算後の支払金額は、「${total}」円です。`;

console.log(str);

少数点以下の結果を四捨五入

  • お金の計算のため、必ず「四捨五入」して結果を表示します
  • 数学オブジェクト「Math」と「round()」メソッドを利用します
total = (price * piece) + (price * piece * taxRate);
total = Math.round(total);

まとめ

  • 変数の宣言「 price」と「piece」を const で宣言し、再代入がないことを明示しました
  • 「整数化」は、１行の中で記述した場合「let」に書き換えなくても進めることができます
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>消費税合算後の支払金額を求めるプログラム</title>
</head>
<body>
<h1>消費税合算後の支払金額を求める</h1>
<script>
    const price = parseInt(prompt('単価を100以上の半角数字を整数で入力してください'));
    const piece = parseInt(prompt('個数を1以上の半角数字を整数で入力してください'));

    const taxRate = 0.1;  // 消費税率
    const total = Math.round((price * piece) + (price * piece * taxRate) );  // 四捨五入

    const str = `購入単価「${price}」円の商品を${piece}個購入した時の消費税合算後の支払金額は、「${total}」円です。`;
    console.log(str);
</script>
</body>
</html>
