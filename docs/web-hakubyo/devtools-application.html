ApplicationタブでStorage・Cookieを管理する

JavaScript・DevTools 2026/05/28

Applicationタブとは

DevToolsの「Application」タブは、ページが「保存しているデータ」を全部確認できる場所だ。

ブラウザはページのために様々なデータを手元に保存している。これらをまとめて確認・編集・削除できるのがApplicationタブの役割だ。

項目内容
Local Storageタブを閉じても消えないキー・バリュー保存領域
Session Storageタブを閉じると消えるキー・バリュー保存領域
Cookies有効期限付きのデータ。サーバーにも自動送信される
IndexedDB大量データを扱えるブラウザ内データベース
Cache StorageService Workerがキャッシュしたファイル

日常の開発でよく使うのは Local Storage と Cookies の2つだ。

localStorage を確認・編集する

左側のツリーから「Storage → Local Storage → ドメイン名」をクリックすると、そのドメインが保存しているキーと値の一覧が表示される。

Application タブを開く ↓ 左ツリー → Storage → Local Storage ↓ ドメイン名をクリック ↓ キーと値の一覧が表示される

一覧では次の操作ができる。

操作方法
値を確認するキー行をクリックすると下部パネルに値の詳細が表示される
値を編集するValue列をダブルクリックすると直接編集できる
キーを削除する行を選択してDeleteキーを押す
全件削除するツールバーの「Clear All」ボタン（禁止マーク）をクリック
よく保存されているもの：
お気に入り機能の状態・ダークモード設定・フォームの入力値・ユーザーの設定情報など。JavaScript側では localStorage.getItem('key') で取得、localStorage.setItem('key', 'value') で保存する。

localStorage vs sessionStorage vs Cookie

3種類のストレージは「いつ消えるか」「JavaScriptからアクセスできるか」「容量」が異なる。

種類消えるタイミングJSからのアクセス容量
localStorage明示的に削除するまで消えない可（getItem / setItem）約5MB
sessionStorageタブを閉じると消える可（getItem / setItem）約5MB
Cookie有効期限（Expires）まで可（document.cookie）※HttpOnlyを除く約4KB
使い分けの目安：
永続させたい設定 → localStorage、ページセッション中だけ使う一時データ → sessionStorage、サーバーと共有したい認証情報 → Cookie。
// localStorage の基本操作 localStorage.setItem('theme', 'dark'); // 保存 const theme = localStorage.getItem('theme'); // 取得 → 'dark' localStorage.removeItem('theme'); // 削除 localStorage.clear(); // 全削除

Cookie を確認する

左側のツリーから「Cookies → ドメイン名」をクリックすると、そのドメインのCookie一覧が表示される。

表示される列の意味を確認しておこう。

列名内容
NameCookieの名前
ValueCookieの値（セッションIDなど）
DomainこのCookieが送信されるドメイン
PathこのCookieが送信されるパス（/ は全パス）
Expires / Max-Age有効期限。Session は「タブを閉じると消える」
SizeCookieのデータサイズ（バイト）
HttpOnlyチェックがついているとJavaScriptから読めない
SecureチェックがついているとHTTPS接続のみで送信される
HttpOnly に注意：
HttpOnly 列にチェックがついているCookieは、document.cookie を実行しても取得できない。サーバー側で Set-Cookie ヘッダーに HttpOnly フラグを付けて発行されたCookieがこれに該当する。

「document.cookieで見えるCookieと、Application → Cookiesで見えるCookieの数が違う」と感じたら、HttpOnlyフラグが原因だ。Application タブには両方が表示されるが、JavaScriptからは HttpOnly でないものしか読めない。

よくある使い方

Application タブが実際の場面でどう役立つか、パターンをまとめる。

症状確認・対処
ログイン状態がなぜか消えるsessionStorageに保存していた → localStorage に変更する
document.cookieで取れないCookieがあるApplication → Cookies で HttpOnly 列を確認する
localStorageの値が古くてバグが再現するApplicationタブでDelete Allして再テストする
ページの動作をリセットしたいStorage → 「Clear site data」ボタンでlocalStorage・Cookies・Cacheを一括削除
お気に入り機能が保存されないLocalStorageにキーが存在するか確認する
「Clear site data」の場所：
Applicationタブ左ツリーの一番上にある「Storage」をクリックすると、右側に「Clear site data」ボタンが表示される。localStorageとCookiesとCache Storageをまとめて削除できる。
Application → Storage（左ツリー上部） ↓ 右パネルに「Clear site data」ボタン ↓ クリックで全Storageをリセット
