コーディング基礎 2026/02/24

main内のブロック構造

  • プロンプト例

HTMLでmain内のブロックの具体的な実例を作成して

  • １ブロック、２ブロック、３ブロック、４ブロックのそれぞれの例をテキスト・画像も含めて

main内4パターン👇

① 1ブロック → ヒーロー（ファーストビュー）
② 2ブロック → 画像＋説明（最重要）
③ 3ブロック → サービス紹介
④ 4ブロック → ギャラリー・一覧

① 1ブロック（基本構造）

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>1ブロック</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- main -->
<main class="main">
  <section class="hero">
    <h2>心地よいカフェ時間</h2>
    <p>自然光と花に包まれた癒しの空間</p>
  </section><!-- hero -->
</main>
<!-- /main -->
</body>
</html>

【CSS】

@charset "UTF-8";

/* --------------------------------------------
  reset
-------------------------------------------- */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}


/* --------------------------------------------
  body
-------------------------------------------- */
body {
  font-family: sans-serif;
}


/* --------------------------------------------
  layout
-------------------------------------------- */
.hero {
  display: flex;
  justify-content: center;
  align-items: center;
  flex-direction: column;
  height: 100vh;
  background: url("../img/hero.jpg") center/cover;
  color: #fff;
  text-align: center;
}
  .hero h2 {
    font-size: 48px;
    font-family: serif;
  }
  .hero p {
    font-size: 18px;
  }
② 2ブロック（横並び）

👉 画像＋テキスト（超よく使う）

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>2ブロック</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- main -->
<main class="main">
  <section class="container">
    <div class="block">
      <img src="img/coffee.jpg" alt="コーヒー">
    </div>
    <div class="block text">
      <h2>こだわりのコーヒー</h2>
      <p>コーヒーは、豆の産地や品種、焙煎によって変わる風味を楽しむ一杯です。挽き方や抽出方法でも味わいは変化し、自分好みを見つける楽しさがあります。丁寧に淹れたコーヒーは、香りとともに日常を特別な時間へと変えてくれます。</p>
    </div>
  </section><!-- /.container -->
</main>
<!-- /main -->
</body>
</html>

【CSS】

@charset "UTF-8";

/* --------------------------------------------
  reset
-------------------------------------------- */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
img {
  max-width: 100%;
  vertical-align: bottom;
}


/* --------------------------------------------
  body
-------------------------------------------- */
body {
  font-family: sans-serif;
}


/* --------------------------------------------
  layout
-------------------------------------------- */
.container {
  display: flex;
  align-items: center;
  max-width: 960px;
  margin: 50px auto;
}
.block {
  width: 50%;
}
  .block img {
    height: auto;
    object-fit: cover;
  }
  .text {
    padding: 50px;
    line-height: 1.8;
  }
  h2 {
    margin-bottom: 30px;
    font-family: serif;
  }
