HTMLの構造を理解する

コーディング基礎 2026/02/05

HTMLの構造を理解する

  • プロンプト例

完全未経験者がHTMLの構造を理解するためにやるべきこと

HTMLの構造を理解するためのロードマップ

① HTMLは「文章の骨組み」だと理解する

まずは役割のイメージが大切です。

  • HTML = Webページの構造（骨組み）
  • CSS = 見た目（デザイン）
  • JavaScript = 動き・操作

👉 HTMLは「見た目を作るものではない」という理解が超重要です。

② 最小構成のHTMLを丸暗記レベルで理解する

まずこれだけ覚えましょう👇

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>タイトル</title>
  </head>
  <body>
    内容を書く
  </body>
</html>

ポイント

  • html → 全体
  • head → 設定・情報
  • body → 画面に表示される中身

👉 「bodyの中身だけが画面に表示される」

③ タグの意味を「役割」で理解する

丸暗記ではなく 役割ベース で覚えると楽になります。

タグ 役割
h1 一番大きな見出し
p 文章
a リンク
img 画像
ul, li 箇条書き
div グループ化
section 意味のあるまとまり

👉 「この文章は何？」→ タグを決める という思考が大事。

④ 木構造（親子関係）を理解する【超重要】

HTMLはツリー構造（入れ子）です。

<body>
  <div>
    <h1>タイトル</h1>
    <p>文章</p>
  </div>
</body>

【構造イメージ】

body
 └ div
    ├ h1
    └ p

👉 HTML理解の8割はこの構造理解

⑤ とにかく手を動かす（写経 → 改造）

最短ルートはこれです：

Step1：丸写し
簡単なHTMLをそのまま書く

Step2：いじる

  • 文章を変える
  • タグを変える
  • 追加する
  • 消す

👉 「壊して学ぶ」

⑥ 自分の簡単なページを作る

以下レベルでOK：

  • 自己紹介ページ
  • 好きなもの紹介ページ
  • 架空の商品紹介ページ

【構成例】

<h1>自己紹介</h1>
<p>こんにちは。〇〇です。</p>

<h2>好きなもの</h2>
<ul>
  <li>映画</li>
  <li>音楽</li>
  <li>ゲーム</li>
</ul>

👉 作れた瞬間に理解が爆伸び
