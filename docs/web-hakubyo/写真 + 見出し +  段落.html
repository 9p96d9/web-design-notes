写真 + 見出し + 段落

コーディング基礎 2026/02/08

写真 + 見出し + 段落

  • プロンプト例

HTMLとCSSの役割を200文字程度でまとめたコンテンツを作成したい

  • 各ブロックが写真 + 見出し + 段落で
完成例

テキスト
【写真：Webページの構造図】

HTMLの役割

HTMLはWebページの骨組みを作る言語です。見出し、文章、画像、リンクなどの要素を配置し、情報の構造と意味を定義します。ページ全体の内容を正しく伝える基盤となります。

【写真：デザイン装飾のイメージ】

CSSの役割

CSSはHTMLで作られた構造にデザインを加える言語です。色、文字サイズ、レイアウト、余白などを調整し、見やすく美しいWebページに仕上げます。

🧩 模範解答：写真 + 見出し + 段落

  • コーディングルールは、自前のルールで記述（AIのコーディング大筋のみ利用します。）
  • 画像は、nano bananaで作成

HTML

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>HTMLとCSSの役割</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="container">
    <section class="block">
      <img src="img/01.jpg" alt="Webページの構造図">
      <h2>HTMLの役割</h2>
      <p>HTMLはWebページの骨組みを作る言語です。見出し、文章、画像、リンクなどの要素を配置し、情報の構造と意味を定義します。ページ全体の内容を正しく伝える基盤となります。</p>
    </section><!-- /.block -->
    <section class="block">
      <img src="img/02.jpg" alt="デザイン装飾のイメージ">
      <h2>CSSの役割</h2>
      <p>CSSはHTMLで作られた構造にデザインを加える言語です。色、文字サイズ、レイアウト、余白などを調整し、見やすく美しいWebページに仕上げます。</p>
    </section><!-- /.block -->
  </div><!-- /.container -->
</body>
</html>

CSS

@charset "UTF-8";

/* -------------------------------------
  reset
------------------------------------- */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}


/* -------------------------------------
  body
------------------------------------- */
body {
  background-color: #f4f4f4;
  font-size: 16px;
  font-family: sans-serif;
  line-height: 1.0;
}


/* -------------------------------------
  layout
------------------------------------- */
.container {
  max-width: 480px;
  margin: 40px auto;
  padding: 30px 40px;
  background-color: #ffffff;
  border-radius: 8px;
  box-shadow: 0 0 4px rgba(0,0,0,0.2);
}

/* -------------------------------------
  section
------------------------------------- */
  .block {
    margin-bottom: 30px;
  }
    .block img {
      width: 100%;
      max-width: 400px;
      display: block;
      margin-bottom: 8px;
    }
    h2 {
      margin-bottom: 20px;
      text-align: center;
    }
    p {
      text-align: justify;
      line-height: 1.6;
    }
