text-align - 行揃え

CSS 2026/01/24

CSSで行揃え

  • プロンプト例

CSSでの行揃えについて解説して

CSSでの行揃え（テキストや要素の整列）は、レイアウトや可読性に大きく影響します。

CSSでの行揃え（text-align）の基本

行揃えには主に次の4種類があります。

値 意味
left 左揃え（デフォルト）
center 中央揃え
right 右揃え
justify 両端揃え
① テキストの行揃え：text-align

文章の横方向の整列に使用します。

p {
  text-align: justify;
}

各値の挙動

text-align: left;    /* 左揃え */
text-align: center;  /* 中央揃え */
text-align: right;   /* 右揃え */
text-align: justify; /* 両端揃え */

💡 **両端揃え（justify）**は日本語サイトでは特に有効です。

② 縦方向の行揃え：vertical-align

インライン要素やテーブルセル内での縦位置調整

span {
  vertical-align: middle;
}
値 内容
baseline 基準線揃え（初期）
middle 中央
top 上
bottom 下

※ div の縦中央揃えには使えません（後述）

③ ブロック要素の中央揃え：margin: auto
div {
  width: 300px;
  margin: 0 auto;
}

→ 横方向の中央揃え（幅指定必須）

④ Flexboxによる行揃え（最重要）

現代CSSで最も使われる方法

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
プロパティ 役割
justify-content 横方向揃え
align-items 縦方向揃え

値一覧

justify-content: flex-start; /* 左 */
justify-content: center;     /* 中央 */
justify-content: flex-end;   /* 右 */
justify-content: space-between;
justify-content: space-around;

align-items: flex-start;
align-items: center;
align-items: flex-end;
⑤ Gridによる行揃え（高度）
.container {
  display: grid;
  place-items: center;
}

→ 縦横ともに中央揃え

よくある行揃えパターンまとめ

やりたいこと 方法
テキスト中央揃え text-align: center
divを中央配置 margin: 0 auto
縦横中央揃え flex + center
行の両端揃え text-align: justify
実用例：縦横完全中央揃え
.container {
  height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
}
補足：日本語の両端揃え最適化
p {
  text-align: justify;
  text-justify: inter-ideograph;
}

→ 日本語向けに最適な両端揃え

まとめ

CSSでの行揃えは主に：

  • テキスト → text-align
  • 配置 → Flex / Grid

を使えばほぼ全ケースに対応できます。
