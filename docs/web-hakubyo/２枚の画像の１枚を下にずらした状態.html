２枚の画像の１枚を下にずらした状態

コーディング基礎 2026/02/27

２枚の画像の１枚を下にずらした状態

  • コンセプト例

section内を画像と文字のスペースに２分割レイアウト

  • sectionは、文字と画像の順に -コンテンツ内容は、カフェの「コンセプト」で
  • 画像は、２枚挿入で１枚は下にずらした状態で

          心と体をやさしく整えるための場所です。
          自然光が差し込む店内と、花に囲まれた空間で、

「画像をずらす」方法

① transform（←一番おすすめ🔥）
.concept-image img:nth-of-type(2) {
  transform: translate(14px, 40px);
}

✔ 特徴

  • レイアウトを壊さない（超重要）
  • アニメーションと相性◎
  • hover演出も簡単

✔ ポイント

  • transform: translate(X, Y);
  • → 右にX、下にYずれる

👉 プロはまずこれ使う

② position
/* 画像 */
.concept-image {
  flex: 1;
  position: relative;
}
  .concept-image img {
    width: 48%;
    height: 400px;
    object-fit: cover;
  }

/* 2枚目をずらす */
.concept-image img:nth-of-type(2) {
  position: absolute;
  top: 40px;  /* 下にずらす */
  right: 0;  /* 右端にずらす */
  width: 48%;
}

✔ ポイント

  position: relative;  /* 親 */
  position: absolute;  /* 子 */
③ marginでずらす
.concept-image img:nth-of-type(2) {
  margin-top: 40px;
  margin-left: 40px;
}

✔ 特徴

  • シンプルでわかりやすい
  • 初心者向け

⚠️ デメリット

  • 他の要素も一緒に動く（レイアウトに影響あり）
④ flex + align調整
.concept-image {
  display: flex;
  flex-direction: column;
}
.concept-image img:nth-of-type(2) {
  align-self: flex-end;
  margin-top: 40px;
}

✔ 特徴

  • 縦レイアウトで自然にズレる
  • カードUIに向いてる
⑤ gridで配置ずらし
.concept-image {
  display: grid;
}
.concept-image img:nth-of-type(1) {
  grid-area: 1 / 1;
}
.concept-image img:nth-of-type(2) {
  grid-area: 1 / 1;
  transform: translate(40px, 40px);
}

✔ 特徴

  • 重ねレイアウトが超得意
  • デザイン自由度高い
✅ 結局どれ使うべき？
方法 おすすめ度 理由
transform ⭐⭐⭐⭐⭐ レイアウト壊さない・最強
position ⭐⭐⭐⭐ 完全コントロールできる
margin ⭐⭐ 簡単だけど崩れやすい
grid ⭐⭐⭐⭐ モダンで強い
