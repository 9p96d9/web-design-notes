【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>  
<meta charset="UTF-8">
<title>オーバーラップ</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- main -->
<main>
  <section class="concept wrapper">
    <div class="concept-img">
      <img src="img/concept.jpg" alt="">
    </div>
    <div class="concept-text">
      <h2 class="section-title">心がほどける、やさしいひととき<br>
      何気ない毎日を、少しだけ特別に</h2>
      <p class="description">やさしい時間に包まれるひととき。
      毎日を心地よく過ごしたいあなたへ。
      肌にも心にもやさしく寄り添うように、無添加にこだわったシンプルなやさしさ。
      しっとりと満たされるうるおいが、いつもの日常を少しだけ美しく整えていきます。</p>
    </div>
  </section>
</main>
<!-- /main -->
</body>
</html>

【CSS】

@charset "UTF-8";

  layout
