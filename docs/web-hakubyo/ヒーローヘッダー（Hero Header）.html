ヒーローヘッダー（Hero Header）

コーディング基礎 2026/02/14

ヒーローヘッダー（Hero Header）

  • プロンプト例

HTMLのヒーローヘッダーに関して解説して

  • Webページでよく使われる ヒーローヘッダー（Hero Header） は、ページの最上部に配置される 大きなビジュアルエリア のことです。
  • 訪問者が最初に見る部分なので、サイトの印象や目的を一瞬で伝える役割があります。✨

ヒーローヘッダーとは

ヒーローヘッダーとは、Webページの最上部に配置される 大きな画像・キャッチコピー・ボタンなどを組み合わせた領域 のことです。

主な目的は次の3つです。

  • サイトのテーマを伝える
  • 視覚的に印象を残す
  • ユーザーに行動を促す（問い合わせ・購入など）
ヒーローヘッダーの基本構成

一般的には次の要素で作られます。

Hero Header
├ キャッチコピー（h1）
├ 説明文（p）
├ ボタン（CTA）
└ 背景画像

HTMLの基本構造

ヒーローヘッダーは通常 header要素で作ります。

【HTML】

<header class="hero">
  <div class="hero-text">
    <h1>心地よいカフェ時間を</h1>
    <p>自然光と花に囲まれた癒しの空間</p>
    <a href="#" class="btn">メニューを見る</a>
  </div>
</header>

【CSS】

body{
  margin: 0;
  font-family: sans-serif;
}
.hero{
  height: 500px;
  background-image: url("https: //images.unsplash.com/photo-1554118811-1e0d58224f24");
  background-size: cover;
  background-position: center;
  display: flex;
  justify-content: center;
  align-items: center;
  text-align: center;
  color: #fff;
}

/* テキスト */
.hero-text h1{
  font-size: 48px;
  margin-bottom: 10px;
}
.hero-text p{
  font-size: 18px;
  margin-bottom: 20px;
}

/* ボタン */
.btn{
  display: inline-block;
  padding: 12px 24px;
  background: #c89b5b;
  color: white;
  text-decoration: none;
  border-radius: 5px;
}

表示イメージ

ヒーローヘッダーのよくあるパターン

① フルスクリーン型
  • 画面いっぱいに表示
height: 100vh;
② 画像＋文字中央配置
  • LPで最も多いパターン
③ 画像＋2カラム
　| 画像 | キャッチコピー |
④ スライダー型
  • 背景が自動で切り替わる

ヒーローヘッダーの重要ポイント

① h1はキャッチコピー
  • SEOにも重要
<h1>人生を変える旅へ</h1>
② CTAボタンを置く
  • CTA = Call To Action

【例】

予約する
詳しく見る
③ 背景画像はテーマに合うもの

まとめ

ヒーローヘッダーは

  • サイトの第一印象を決める部分
  • 背景画像＋キャッチコピー＋ボタン
  • LPやポートフォリオではほぼ必須

とても重要なエリアです。
