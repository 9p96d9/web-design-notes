Google Fonts 利用

  • プロンプト例

Google Fontsを利用する事例を作って

fonts.google.com

Google Fonts からコードを取得
  1. Google Fonts にアクセス
  2. フォントを選択
  3. 表示された をコピー
Google Fontsの設定ポイント

① CSSで指定する

  font-family: 'Noto Serif JP', serif;

② 複数フォントを指定できる

  • 欧文→日本語→汎用 の順に記述
  font-family: 'Playfair Display', 'Noto Serif JP', serif;
設定例

Language（Japanese）を選択

Noto - Serif （明朝体）を選択

Embed Code をコピー

記述例

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<!-- Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@100..900&family=Noto+Serif+JP:wght@200..900&family=Playfair+Display:ital,wght@0,400..900;1,400..900&display=swap" rel="stylesheet">
<!-- Original CSS -->
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<header class="header">
  <h1>心地よいカフェ時間</h1>
  <p>自然光が差し込むカフェで、
  ゆったりとした時間を楽しみませんか。
  香り高いコーヒーと焼きたてのスイーツが
  あなたをお待ちしています。</p>
</header>
</body>
</html>

【CSS】

@charset "UTF-8";

/* ----------------------------------------
  reset
---------------------------------------- */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}


/* ----------------------------------------
  body
---------------------------------------- */
body {
  background-color: #f5f5f5;
  color: #333;
  font-family: 'Noto Sans JP', sans-serif;
  line-height: 1.0;
}


/* ----------------------------------------
  header
---------------------------------------- */
.header {
  width: 800px;
  margin: 50px auto;
  background: #fff;
  padding: 40px;
}
  h1{
    margin-bottom: 30px;
    font-size:32px;
    font-family: 'Playfair Display', 'Noto Serif JP', serif;
  }
  p{
    line-height:1.8;
  }
