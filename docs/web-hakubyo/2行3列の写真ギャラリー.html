2行3列の写真ギャラリー

  • プロンプト例

HTMLで２行３列の写真のギャラリーを作りたい

  • 幅は960px
  • gapは20px
  • 写真は料理で
完成例

レイアウトのポイント

① 3列にする
grid-template-columns: repeat(3, 1fr);
  • 3列作る
  • 各列の幅は均等
② 隙間を20px
gap: 20px;
  • 写真の 縦横の間隔が20px になります。
③ 高さを統一
height: 200px;
object-fit: cover;

これで

  • 写真サイズがバラバラでも
  • 高さが揃った綺麗なギャラリー

になります。

完成例

【CSS】

@charset "UTF-8";

/* -----------------------------------
  reset

  padding: 0;
  box-sizing: border-box;
}

  body

  color: #666;
  font-family: serif;

/* -----------------------------------
  layout
----------------------------------- */
.content {
  width: 960px;
  margin: 20px auto;
  text-align: center;
}
h2 {
  margin-bottom: 20px;
}
.gallery{
  display: grid;
  grid-template-columns: repeat(3,1fr);
  gap: 20px;
}
  .gallery img{
    width: 100%;
    height: 200px;
    object-fit: cover;
    border-radius: 8px;
  }
