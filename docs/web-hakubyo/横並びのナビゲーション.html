横並びのナビゲーション

  • プロンプト例

CSSで横並びのナビゲーション例を作って

  • header内にnavで
  • headerの背景色は白
完成例

横並びナビの設計ポイント（重要）

① Flexboxを使う
今のWeb制作の基本

display: flex;

② liを横並びの単位にする
ul → li → a

③ aタグをブロックにする

display: block;

④ hoverを必ず作る
ユーザーが操作していることを伝える

⑤ ナビ幅を決める
【例】

width: 960px;
margin: 0 auto;
初心者がよくやるミス

❌ liを横並びにしない
❌ aタグをinlineのまま
❌ ulの余白を消さない

記述例

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>横並びナビゲーション例</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- header -->
<header>
  <nav>
    <ul class="nav-list">
      <li><a href="#" class="current">HOME</a></li>
      <li><a href="#">ABOUT</a></li>
      <li><a href="#">SERVICE</a></li>
      <li><a href="#">BLOG</a></li>
      <li><a href="#">CONTACT</a></li>
    </ul>
  </nav>
</header>
<!-- /header -->
</body>
</html>

【CSS】

@charset "UTF-8";

/* -----------------------------------
  reset
----------------------------------- */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
ul {
  list-style: none;
}
a {
  color: inherit;
  text-decoration: none;
}


/* -----------------------------------
  body
----------------------------------- */
body{
  background-color: #fff;
  color: #666;
  font-family: sans-serif;
}

/* -----------------------------------
  layout
----------------------------------- */

/* header */
header{
  background:#ffffff;
  padding:20px 0;
}

/* navのリスト */
.nav-list{
  display:flex;
  justify-content:center;
}

/* リンク */
.nav-list a {
  display: block;
  padding: 12px 20px;
  font-weight:bold;
}

/* ホバー */
.nav-list a:hover, a.current {
  background-color: #e67e22;
  color: #fff;
}
