🖥 コンピュータとは？

コンピュータとは、
👉 情報を「入力」→「処理」→「出力」する機械 のことです。

もう少し簡単に言うと、

  • 計算したり、考えたり、作業を自動でやってくれる便利な道具 です。

🔁 コンピュータの基本の流れ（3ステップ）

① 入力（Input）

人が情報を入れます。
【例】

  • キーボードで文字を打つ
  • マウスでクリックする
  • カメラで写真を撮る
② 処理（Processing）

コンピュータが中で計算・判断します。
【例】

  • 文字を表示用に変換
  • 写真をきれいに補正
  • ゲームの動きを計算
③ 出力（Output）

結果を人に見せます。
【例】

  • 画面に文字を表示
  • 音を出す
  • プリンタで印刷

💡 身近なコンピュータの例

実は、コンピュータは身の回りにたくさんあります。

もの 中身
スマートフォン 小さなコンピュータ
ノートPC コンピュータ
ゲーム機 コンピュータ
電子レンジ 制御用コンピュータ
洗濯機 自動制御コンピュータ
🧠 コンピュータは何をしているの？

コンピュータはすべてを 「0と1」 で考えています。

  • 0 → 電気が流れていない
  • 1 → 電気が流れている

この 0と1の組み合わせ で、

  • 文字
  • 画像
  • 音
  • 動画

をすべて表現しています。

部品 役割
CPU 頭脳（考える）
メモリ 作業机（すぐ使うデータ）
ストレージ 本棚（保存）
画面 結果表示
キーボード 入力
🎯 まとめ（超重要）

コンピュータとは：
👉 「入力 → 処理 → 出力」を自動で行う機械
👉 私たちの生活を 速く・便利に・正確に してくれる存在

プログラミングって何？

  • プロンプト例

プログラミングって何？

👉 コンピュータに「何をどう動かすか」を指示すること です。

もっと簡単に言うと：

コンピュータに出す「命令書」を作ること

です。

🤖 なぜプログラミングが必要？

コンピュータはとても速くて正確ですが、自分では何も考えられません。

なので、人間が：
👉「こう動いてね」
👉「この順番でやってね」

と 細かく指示 する必要があります。
この指示を書くのが プログラミング です。

📝 具体例（超かんたん）

たとえば：
「2 + 3 を計算して表示して」
とコンピュータにやらせたいとき：

print(2 + 3)

これが プログラム です。
実行すると → 5 と表示されます。

🏗 プログラミングでできること
できること 例
アプリ作成 LINE、Instagram
ゲーム制作 マインクラフト、ポケモン
Webサイト YouTube、Amazon
自動化 作業の自動処理
AI開発 ChatGPT、画像認識
🗣 プログラミング言語って何？

コンピュータに指示するための特別な言葉です。
【代表例】

言語 特徴
Python 初心者向け・人気No.1
JavaScript Webサイト用
C言語 高速・本格派
Java アプリ・業務向け
🍳 料理にたとえると…
料理 プログラミング
レシピ プログラム
料理人 コンピュータ
調理手順 命令
料理 実行結果

👉 レシピがないと料理できない
👉 命令がないとコンピュータは動けない

🎯 まとめ

プログラミングとは
👉 コンピュータにやってほしいことを 命令として書くこと
👉 コンピュータを 思い通りに動かす魔法の言葉
