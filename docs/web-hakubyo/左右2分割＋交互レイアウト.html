左右2分割＋交互レイアウト

コーディング基礎 2026/02/26

左右2分割＋交互レイアウト

  • プロンプト例

section内を画像と文字のスペースに２分割レイアウト

  • 偶数番目のsectionは、文字と画像の順に変更
  • コンテンツ内容は、カフェの「コンセプト」で
  • 画像挿入の状態で


テキスト
明るいカフェ店内
自然光に包まれる空間
Bloom Caféは、やわらかな自然光と花に囲まれた癒しの空間です。 忙しい日常から少し離れ、ゆったりとした時間をお過ごしいただけます。

カフェ店内
身体にやさしいメニュー
素材にこだわったヘルシーなメニューをご用意。 心も身体も満たされる、やさしい味わいをお楽しみください。

カフェ空間
花とともに過ごす時間
店内には季節の花々を飾り、訪れるたびに違った表情を楽しめます。 心がふっと軽くなるような空間づくりを大切にしています。
記述例
  • 画像は、AIの提案を差し替えています。
