完成例

アートボードサイズ

  • いままで作成していた、SNSサイズ「800×800px」は、「スクエア」と呼びます
  • 縦長のバナーサイズは「スカイスクレイパー」と呼びます
    • アスペクト比（縦長）1：1.91（例：1080×1920）
今回のアートボードサイズ
  • スマートフォン最小横幅サイズ「375px（Retinaディスプレイの場合、2倍の750px）
  • 横「750px」で縦「1333px」で作成

写真切り抜き

  • 「オブジェクト選択ツール」で「被写体を選択」
  • 「レイヤーマスクを追加」

レイヤーマスクを追加
  • 顔は「補正」をしてメリハリが出るようにしています
  • 顔の上下をぼかす

メインコピーを追加
  • 基本的には、Illustratorで作成します
  • 文字サイズを決めて、書体と微調整は写真に配置後行います（Illustrator初期設定は、小塚ゴシックPr6N）

スマートオブジェクトで配置

切り抜き写真を配置

  • Free Vector画像は、Illustratorから「EPS」画像を開くと画像を別々に選択できます（ただし、バージョンが違うため思ったような作業ができません）
  • 今回は「JPG」画像から切り抜きました
  • 切り抜き写真は、あらかじめ補正をしておきます

配置写真を微調整

  • 顔と商品切り抜きを微調整

肌の切り抜き写真にコピーを追加

サブコピーを追加

サブコピーの背景を作成

  • 泡の表現を以下のように切り抜きます

  • レイヤー効果で色彩を濃い状態にします
  • その後、文字を読みやすく「シャドウ」を追加します

サブコピーの目立たせる部分の色を変える

  • 「補色」で設定します

メインコピーを修飾
  • 数字書体「Buffet Script」（Adobe Fonts）
  • 吹き出しを追加

手書き文字の修飾

  • 「マカポップ」をアウトラインにして加工しました（見本にある「花とちょう」は、有料です）
  • Photoshopで「グラデーション」を設定します

  • 「レイヤー効果」→「グラデーションオーバレイ」

  • 「アートブラシ：木炭・鉛筆」で文字の飾りを作成

縦書き文字を修飾

肌のクローズアップ写真の解説文字

  • 「グラデーション」を帯ごとに設定するため、Illustratorで指定します

キャッチを修飾

  • 文字を立体化（ベベルとエンボス）
  • Illustratorでアウトラインをして加工
  • Photoshopへペーストした「スマートオブジェクト」を「ラスタライズ」（ビットマップにする）

  • ラスタライズしたレイヤーに「レイヤー効果：ベベルとエンボス」を追加

メインコピーの飾り
  • 月形の形を作り、別々にスマートオブジェクトで配置
  • 手書き文字の「グラデーション」を「レイヤースタイルをコピー」
  • 「レイヤースタイルをペースト」で適用させる

  • 顔の切り抜きのときに選択していた「顔の後ろにある髪」を削除しました

商品のミラーリング
  1. レイヤーの複製
  2. 「編集」→「変形」→「垂直方向に反転」
  3. 位置を移動
  4. 「レイヤーマスクを追加」→マクス内に「グラデーション」

背景画像を配置
  • 背景画像を表示するために、顔の白いぼかしを選択範囲に変換して削除します
  • 背景画像の最下部のみをレイヤーマスクを追加して白く見せます

キャッチコピーの補足
  • 白いシャドウを追加して読みやすくします

完成


  • 「枠線」を追加した場合
