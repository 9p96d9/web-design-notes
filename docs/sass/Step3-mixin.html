Step 3：mixinを導入

ステップ演習 2026/04/09

mixinとは？

mixin（ミックスイン）は、「スタイルのかたまりに名前をつけて再利用する」機能です。

  • @mixin 名前 { } で定義する
  • @include 名前; で呼び出す
  • 引数（パラメータ）を使ってカスタマイズもできる

変数が「値の再利用」なら、mixinは「スタイルブロックの再利用」です。

基本的な使い方

/* ① mixin の定義 */
@mixin flex-row($justify: flex-start) {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: $justify;
      -ms-flex-pack: $justify;
          justify-content: $justify;
}

/* ② mixin の使用（@include で呼び出す） */
.header__inner {
  @include flex-row(space-between);  /* justify-content: space-between */
}

.hero__content {
  @include flex-row(center);         /* justify-content: center */
}

.menu-grid {
  @include flex-row(flex-start);     /* 引数省略時のデフォルト値 */
}

$justify: flex-start の : flex-start 部分はデフォルト値です。引数を省略したときに使われます。

コンパイル後のCSS

/* コンパイル後 */
.header__inner {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: justify;
      -ms-flex-pack: justify;
          justify-content: space-between;
}

.hero__content {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: center;
      -ms-flex-pack: center;
          justify-content: center;
}

.menu-grid {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: start;
      -ms-flex-pack: start;
          justify-content: flex-start;
}

毎回コピペしていたベンダープレフィックスが、@include の1行に集約されました。

引数なしのmixin

引数が不要なケースでもmixinは便利です。

/* 画像をカードに収める共通スタイル */
@mixin cover-image {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}

/* リセットリスト（デフォルトスタイルを消す） */
@mixin reset-list {
  list-style: none;
  margin: 0;
  padding: 0;
}

/* 使用例 */
.menu-card__image {
  @include cover-image;
}

.nav__list {
  @include reset-list;
  display: flex;
  gap: 16px;
}

複数の引数を使うmixin

/* ボタンのバリエーションを引数で制御 */
@mixin button($bg: $brand-color, $color: $white, $size: 14px) {
  background-color: $bg;
  color: $color;
  font-size: $size;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
  cursor: pointer;

  &:hover {
    opacity: 0.85;
  }
}

/* 使用例 */
.btn--primary {
  @include button;                           /* デフォルト値を使う */
}

.btn--large {
  @include button($size: 18px);              /* サイズだけ変える */
}

.btn--outline {
  @include button($bg: transparent, $color: $brand-color);
  border: 2px solid $brand-color;
}

Step 3のまとめ

機能役割構文
定義スタイルブロックに名前をつける@mixin 名前 { }
呼び出し定義したスタイルを展開する@include 名前;
引数呼び出すたびに値を変える@mixin 名前($引数: デフォルト値)

mixinを使うと「同じスタイルのコピペ」がなくなり、変更が一箇所で済むようになります。
