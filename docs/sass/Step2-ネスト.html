Step 2：ネストを導入

ステップ演習 2026/04/09

ネストとは？

ネスト（入れ子）とは、セレクタの中に別のセレクタを書く機能です。

HTMLの構造がそのままコードの構造になるため、「どの要素のスタイルか」が視覚的にわかりやすくなります。

CSSとSassの比較

CSSの場合（ネストなし）
/* CSS：毎回セレクタをフルで書く必要がある */
.header {
  background-color: #6F4E37;
}

.header__inner {
  max-width: 1100px;
  margin: 0 auto;
}

.header__logo {
  color: #ffffff;
  font-size: 24px;
}

.header__nav {
  display: flex;
  gap: 24px;
}

.header__nav a {
  color: #ffffff;
}

.header__nav a:hover {
  text-decoration: underline;
}
Sassの場合（ネストあり）
/* SCSS：ネストで構造がわかりやすい */
.header {
  background-color: $brand-color;

  &__inner {          /* & は親セレクタ（.header）に置き換わる */
    max-width: 1100px;
    margin: 0 auto;
  }

  &__logo {           /* → .header__logo */
    color: $white;
    font-size: 24px;
  }

  &__nav {            /* → .header__nav */
    display: flex;
    gap: 24px;

    a {               /* → .header__nav a */
      color: $white;
    }

    a:hover {         /* → .header__nav a:hover */
      text-decoration: underline;
    }
  }
}

&（親セレクタ参照）

& は「今いる親のセレクタ」に置き換わる特殊な記号です。

.btn {
  background: $brand-color;
  color: $white;

  &:hover {       /* → .btn:hover */
    opacity: 0.8;
  }

  &--large {      /* → .btn--large（BEMのModifier） */
    font-size: 18px;
    padding: 16px 32px;
  }

  &--outline {    /* → .btn--outline */
    background: transparent;
    border: 2px solid $brand-color;
    color: $brand-color;
  }
}
Sassの書き方コンパイル後のCSS
&:hover.btn:hover
&--large.btn--large
&__icon.btn__icon

BEMとネストの相性

BEM（Block Element Modifier）はクラス命名規則の一つです。

  • .block：独立したコンポーネント（例：.card）
  • .block__element：Blockの中の要素（例：.card__title）
  • .block--modifier：状態・バリエーション（例：.card--featured）
/* カードコンポーネントのBEM + ネスト */
.card {
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
  overflow: hidden;

  &__image {              /* → .card__image */
    width: 100%;
    height: 200px;
    object-fit: cover;
  }

  &__body {               /* → .card__body */
    padding: 16px;
  }

  &__title {              /* → .card__title */
    font-size: 18px;
    color: $brand-color;
    margin-bottom: 8px;
  }

  &__price {              /* → .card__price */
    font-weight: bold;
    color: $text-color;
  }

  &--featured {           /* → .card--featured（おすすめカード） */
    border: 2px solid $brand-color;
  }
}

HTMLのブロック構造とSCSSのネスト構造が対応するため、コードを読むだけで構造が把握できます。

ネストの注意点

  • 深くネストしすぎると逆に読みにくくなる（目安は3階層まで）
  • ネストが深いとコンパイル後のセレクタが長くなり、CSS詳細度が上がる
/* NG：深すぎるネスト */
.header {
  .nav {
    ul {
      li {
        a {          /* → .header .nav ul li a（詳細度が高すぎる） */
          color: red;
        }
      }
    }
  }
}

/* OK：適切な深さ */
.header {
  &__nav {
    a { color: $white; }      /* → .header__nav a */
    a:hover { opacity: 0.8; } /* → .header__nav a:hover */
  }
}
