Sass環境構築

環境構築 2026/04/09

Dart Sass とは

Sassの実装にはいくつか種類がありますが、現在の公式・推奨は Dart Sass です。

  • Node.jsがあれば npm で簡単にインストールできる
  • npx sass を使えばインストールなしでも試せる

インストール方法

npm でグローバルインストール（推奨）
# Node.jsがある場合（npm）
npm install -g sass

# インストール確認
sass --version
# → 1.xx.x compiled with dart2js x.x.x
npxで直接使う（インストール不要）
# インストールなしで試したいとき
npx sass --version

学習段階では npx でも十分です。チームで使うときはグローバルインストールかプロジェクトへの追加が推奨されます。

SCSSをCSSに変換するコマンド

1回だけ変換
sass scss/style.scss css/style.css
#     ↑ 入力ファイル   ↑ 出力ファイル
ファイルを監視して自動変換（--watch）
# ファイル1つを監視
sass --watch scss/style.scss:css/style.css

# フォルダごと監視（scss/ 内の変更を css/ に自動出力）
sass --watch scss/:css/

--watch オプションをつけると、SCSSファイルを保存するたびに自動でコンパイルされます。ファイルを更新するたびにコマンドを打つ必要がなくなります。

ソースマップを生成しない
sass --no-source-map scss/style.scss css/style.css

ソースマップの詳細はソースマップとはを参照してください。

実際の作業手順（Step 1の例）

# 1. プロジェクトフォルダに移動
cd step1-variables

# 2. フォルダ構成を確認
ls scss/
# → style.scss

# 3. 監視開始
sass --watch scss/style.scss:css/style.css

# ターミナルに以下が表示されれば成功
# → Sass is watching for changes. Press Ctrl-C to stop.

# 4. scss/style.scss を編集して保存すると自動でコンパイルされる
# → Compiled scss/style.scss to css/style.css.

推奨フォルダ構成

project/
├── index.html
├── css/
│   ├── style.css       ← sass が自動生成（手動編集しない）
│   └── style.css.map   ← ソースマップ（自動生成）
└── scss/
    ├── style.scss      ← メインファイル（@use のみ書く）
    ├── _variables.scss
    ├── _mixin.scss
    ├── _base.scss
    └── _header.scss
  • css/style.css は自動生成なので、直接編集しない
  • 編集するのは常に scss/ 内のファイル

VS Code 拡張機能を使う方法

コマンドラインを使わず、VS Codeの拡張機能でコンパイルする方法もあります。

拡張機能名特徴
Live Sass Compiler保存時に自動コンパイル。設定が簡単
SassSCSSのシンタックスハイライト

VS Codeの拡張機能を使う場合は、Dart Sassのインストールは不要です（拡張機能に同梱）。

Live Sass Compiler の設定例
// .vscode/settings.json
{
  "liveSassCompile.settings.formats": [
    {
      "format": "expanded",       // コンパイル後の形式（expanded: 読みやすい形）
      "extensionName": ".css",
      "savePath": "/css"          // CSSの出力先
    }
  ]
}
