【002】コンソールに表示

  • プロンプト例

完全未経験者がJavaScriptでconsoleに出力することを理解できる練習問題を５問作成して

JavaScript：console出力 練習問題（超入門）

問題1：文字を表示してみよう

「こんにちは」とコンソールに表示するプログラムを書いてください。

ヒント

console.log('文字');
問題2：数字を表示してみよう

数字の「100」をコンソールに表示してください。

ヒント

console.log(数字);
問題3：計算結果を表示してみよう

「10 + 5」の計算結果をコンソールに表示してください。

ヒント

console.log(10 + 5);
問題4：文字と数字を一緒に表示してみよう

「答えは：20」とコンソールに表示してください。

ヒント

console.log('文字' + 数字);
問題5：自分の名前を表示してみよう

あなたの名前をコンソールに表示してください。

ヒント

console.log('山田太郎');

お手本（答え）

// 問題1
console.log('こんにちは');

// 問題2
console.log(100);

// 問題3
console.log(10 + 5);

// 問題4
console.log('答えは：' + 20);

// 問題5（例）
console.log('あなたの名前');
学習ポイントまとめ
書き方 意味
'文字' 文字を表示
数字 数字を表示
+ 足し算 / 文字の連結
console.log() コンソールに表示
