解答例

問題①（足し算）
let a = 12;
let b = 8;
console.log(a + b);

解説

  • + は加算演算子。
  • a + b により 12 + 8 = 20 が表示されます。
問題②（引き算）
let x = 25;
let y = 9;
console.log(x - y);

解説

  • - は減算演算子。
  • 25 - 9 = 16
問題③（掛け算）
let m = 7;
let n = 6;
console.log(m * n);

解説

  • * は乗算演算子。
  • 7 × 6 = 42
問題④（割り算）
let p = 36;
let q = 4;
console.log(p / q);

解説

  • / は除算演算子。
  • 36 ÷ 4 = 9
問題⑤（四則演算の組み合わせ）
let a = 10;
let b = 5;
let c = 2;

console.log((a + b) * c);

解説

  • 計算の優先順位を変えるため ( ) を使用します。
(10 + 5) × 2 = 15 × 2 = 30
覚えるべき四則演算記号まとめ
演算 記号
足し算 +
引き算 -
掛け算 *
割り算 /
