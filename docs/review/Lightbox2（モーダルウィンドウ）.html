Lightbox2（モーダルウィンドウ）

jQuery 2025/10/24

Lightbox2（モーダルウィンドウ）

  • モーダルウィンドウは、元のウィンドウの上に別枠で表示されるウィンドウのこと
  • 今回の画像は、「幅 1000px」「高さ 700px」
Lightbox2
  • jQueryプラグイン

lokeshdhakar.com

完成例

導入
  • 「Github」からプラグインデータをダウンロード

フォルダー構成
  1. フォルダー名「lightbox」を作成
  2. ダウンロードしたフォルダーも見える位置に置いておきます

自作「lightbox」内

ダウンロードデータ「lightbox2-dev」内「src」を開く

「src」の必要なデータを、自作「bxslider」内に移動（コピー）

  • 「css」フォルダー内「lightbox.css」
  • 「js」フォルダー内「lightbox.js」
  • 「images」フォルダー内「close.png」と「loading.gif」と「next.png」と「prev.png」

記述例
  • 外部JavaScriptファイルを読み込み
<script src="js/lightbox-plus-jquery.min.js" defer></script>

<main class="main">
