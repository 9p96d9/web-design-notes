スライダー - bxSlider

bxslider.com

導入
  • 「Github」からプラグインデータをダウンロード

フォルダー構成
  1. フォルダー名「bxslider」を作成
  2. ダウンロードしたフォルダーも見える位置に置いておきます

自作「bxslider」内

ダウンロードデータ「bxslider-4-master」内「src」を開く

「src」の必要なデータを、自作「bxslider」内に移動（コピー）

  • 「css」フォルダー内「jquery.bxslider.css」
  • 「js」フォルダー内「jquery.bxslider.js」
  • 「images」フォルダー内「bx_loader.gif」と「controls.png」

画像の準備
  • 横幅「1920px」高さ「なりゆき」

  • 書き出した画像を自作「bxslider」内の「img」フォルダーに移動

コーディング
  • フォルダー「bxslider」を管理

<!DOCTYPE html>

script.js

$(function(){
  $('.bxslider').bxSlider({
    mode: 'horizontal', 
    auto: true,
    pager: true,
  });
});
  • この段階は「水平移動」「自動再生」「ページャー表示」

カスタマイズ
  • 「bxSlider」の「options」を参照

bxslider.com

  • 画像がクロスフェード
mode: 'fade',
  • 変化する時間

※２秒の場合

speed: 2000,
  • 画像を停止する時間

※６秒停止する場合

pause: 6000,
  • ページャーをなしにする（ドット）
pager: false,

枠線の影をなくす

  • 「style.css」に追記
.bx-wrapper {
  -moz-box-shadow: 0;
  -webkit-box-shadow: 0;
  box-shadow: 0;
  border: 0;
  background: #fff;
}
