lightgallery.js（モーダルウィンドウ）

www.lightgalleryjs.com

  • 今回の画像は、Lightbox2同様「幅 1000px」「高さ 700px」
完成例

導入
  • CDNで必要なファイルを読み込み（jQuery不要）
// CSSを読み込み
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/lightgallery-js/1.2.0/css/lightgallery.min.css">

// JSを読み込み
<script src="https://cdnjs.cloudflare.com/ajax/libs/lightgallery-js/1.2.0/js/lightgallery.min.js" defer></script>
記述例

index.html

  • 画像を囲む親要素に id名「default」を記述（JavaScriptでこのid名に対して処理を行う）
