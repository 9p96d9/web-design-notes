1 フォルダ構成の整理

目的： おみくじアプリとガチャアプリで共通のCSSを使えるようにする。

作業手順：

  1. 「portfolio」フォルダを新規作成
  2. 既存の「omikuji」フォルダをその中に移動
  3. 同じ階層に「gacha」フォルダを新規作成
  4. 同じ階層に「css」フォルダを新規作成
  5. omikuji内のCSSフォルダにあった style.css を、新しい css/ フォルダに移動
  6. 空になった omikuji 内の css フォルダは削除

最終的なフォルダ構成：

portfolio/ ├── omikuji/ ├── gacha/ │ └── img/ └── css/ └── style.css

CSSのパス修正： omikuji の index.html のスタイルシートリンクが切れるため、以下のように修正する。

<!-- 修正前 --> <link rel="stylesheet" href="css/style.css"> <!-- 修正後 --> <link rel="stylesheet" href="../css/style.css">
「../」の意味
1階層上のフォルダに戻ってから、そこにある css フォルダを参照する。
omikuji/ の中から css/ を見るには、一度 portfolio/ まで上がる必要がある。

3 Photoshopでの画像作成

カードサイズ

560px × 720px（スマホの高解像度ディスプレイを考慮したバイサイズ）
新規ファイル作成時：「Web」を選択 → 幅560・高さ720を入力。アートボードのチェックは外す。

レイヤー・グループ構成

グループ名内容
rankSSR・SR・R のランクアイコン画像
SSRSSRキャラ 3枚
SRSRキャラ 6枚
RRキャラ 9枚
背景（SSRのみ）SSR演出用の背景画像

作業のポイント

  • 各グループを作成したらロックをかけ、作業中は不要なグループを目玉アイコンで非表示にする
  • 画像を中央揃えにするには Ctrl+A（全選択）→ 整列パネルで「水平方向中央揃え」→ Ctrl+D（選択解除）
  • 縦横比を維持したまま拡大縮小：Alt キーを押しながらバウンディングボックスをドラッグ
  • こまめに Ctrl+S で上書き保存（Photoshopは落ちる前提で作業すること）
  • 貼り付け時は右上の丸ボタンで1枚ずつ確定する

4 画像の書き出し

書き出し方法： ファイル → 書き出し → ウェブ用に保存

ランク保存形式背景
SSRJPEG（画質100）背景画像あり
SRPNG-24背景透明
RPNG-24背景透明

手順（1枚ずつ繰り返す）

  1. 書き出したいキャラの目玉アイコンをON、他はOFF
  2. ファイル → 書き出し → ウェブ用に保存
  3. 形式・画質を確認して保存
  4. 保存先は img フォルダ内に専用サブフォルダを作成して整理
  5. ファイル名の先頭に必ずランクをつける（例：ssr_luffy.jpg）
SR・Rの背景透明書き出し
背景レイヤー（白）を非表示にしてから PNG-24 で書き出すと、背景が透明のまま保存される。

5 設計

要点は以下の通り。

  • ランク別の画像を配列データとして用意する
  • ボタンにイベントリスナーを追加し、クリック時に以下の処理を実行
  • 表示箇所は3つあるので、for文で同じ処理を繰り返す

各ループの中でやること：

  1. 0〜99までのランダム値を取得
  2. ランダム値を確率代わりにランク別に割り当てる
ランク条件（gachaNum）確率
SSR0〜910%
SR10〜4940%
R50〜9950%
  1. ランダム値に応じて、各ランクの配列からインデックス番号をランダムで取得
  2. 該当する画像を所定の位置に表示する

7 JavaScript

// ssrの画像を用意 const ssrImage = [ 'img/ssr_luffy.png', 'img/ssr_nami.png', 'img/ssr_zoro.png' ]; // srの画像を用意 const srImage = [ 'img/sr_usopp.png', 'img/sr_sanji.png', 'img/sr_robin.png', 'img/sr_franky.png', 'img/sr_chopper.png', 'img/sr_brook.png' ]; // rの画像を用意 const rImage = [ 'img/r_moria.png', 'img/r_lucci.png', 'img/r_linlin_kaido.png', 'img/r_kurohige_teach.png', 'img/r_jinbe.png', 'img/r_enel.png', 'img/r_doflamingo.png', 'img/r_crocodile.png', 'img/r_buggy.png' ]; // ボタンを取得 const gachaBtn = document.querySelector('.btn'); // 表示スペースを取得（3つのboxのimgをまとめて取得） const gachaSpace = document.querySelectorAll('.box img'); // 誤作動防止の存在チェック if (gachaBtn) { gachaBtn.addEventListener('click', () => { // 表示スペース（3つ）分だけ繰り返す for (let i = 0; i < gachaSpace.length; i++) { // 0〜99までの数値をランダムで取得 let gachaNum = Math.floor(Math.random() * 100); if (gachaNum < 10) { // 0〜9 → SSR（10%） let ssrNum = Math.floor(Math.random() * ssrImage.length); gachaSpace[i].src = ssrImage[ssrNum]; } else if (gachaNum < 50) { // 10〜49 → SR（40%） let srNum = Math.floor(Math.random() * srImage.length); gachaSpace[i].src = srImage[srNum]; } else { // 50〜99 → R（50%） let rNum = Math.floor(Math.random() * rImage.length); gachaSpace[i].src = rImage[rNum]; } } }); }

ポイント① Math.random の働き

Math.random() は 0 以上 1 未満の小数をランダムで返す。
0〜99 の整数を得たいなら Math.random() * 100 で最大 99.9… になる。
小数を切り捨てる Math.floor() を組み合わせて → Math.floor(Math.random() * 100)

ポイント② if文で確率を切り分ける

gachaNum < 10 → 0〜9 の10通りに当たったら SSR（全体の10%）
gachaNum < 50 → 10〜49 の40通りに当たったら SR（40%）
それ以外（50〜99）→ R（50%）
条件を重ねるだけで確率の重み付けができる。

ポイント③ 各ランクの画像もランダムで選ぶ

SSR の配列 ssrImage は3要素なので、インデックスは 0・1・2 のいずれか。
Math.floor(Math.random() * ssrImage.length) で柔軟に取得できる。
.length で配列の要素数を数えているので、画像を追加しても自動で対応できる。
