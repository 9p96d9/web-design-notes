OGPの作成時の注意点

OGPは、Webページが SNSでシェアされた際の表示（タイトル・説明・画像など）を制御する仕組みです。
主に Facebook / X（旧Twitter） / LINE などで利用されます。

OGP作成時の重要ポイント

1. 必須タグを正しく設定する（最重要）

最低限、以下の4つは必須です。

<meta property="og:title" content="ページタイトル">
<meta property="og:description" content="ページの説明文">
<meta property="og:type" content="website">
<meta property="og:url" content="https://example.com/">
<meta property="og:image" content="https://example.com/ogp.jpg">

注意点

  • 絶対パス（https://〜）で指定
  • 相対パス（/images/ogp.jpg）はNG
  • URLの末尾の「/」の有無を正規URLと統一
2. og:image（画像）の仕様に注意

推奨サイズ

1200 × 630px（アスペクト比 1.91:1）

最低条件

  • 幅：600px以上
  • ファイルサイズ：8MB以下
  • 形式：jpg / png / webp

注意点

  • 小さすぎるとトリミング・ぼやける
  • 文字は中央寄せ + 余白多め
  • 端ギリギリに文字を置かない
3. タイトルと説明文はSNS用に最適化

og:title

  • 20〜30文字前後
  • 内容が一瞬で伝わる文言

og:description

  • 60〜90文字前後
  • ページ内容 + メリット

【例】

<meta property="og:title" content="初心者向けHTML入門｜ゼロから学ぶWeb制作">
<meta property="og:description" content="HTMLを基礎から分かりやすく解説。初学者がつまずきやすいポイントも丁寧に説明します。">
4. ページごとにOGPを個別設定する

NG例

  • 全ページで同一OGP → SNS流入率が激減

OK

  • トップページ
  • 記事ページ
  • 商品ページ

→ すべて個別設定

WordPressの場合

  • SEOプラグイン（Yoast / RankMath / All in One SEO）で自動管理
5. Twitter（X）用タグも必ず追加

OGPだけだと Xでの表示が不完全 になる場合あり。

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="ページタイトル">
<meta name="twitter:description" content="ページ説明">
<meta name="twitter:image" content="https://example.com/ogp.jpg">

twitter:card の種類

値 表示
summary 小さい画像
summary_large_image 大きい画像（推奨）

→ 基本は summary_large_image

6. キャッシュ対策（反映されない最大の原因）

OGPは SNS側にキャッシュされる ため、修正してもすぐ反映されません。

デバッグツール必須

  • Facebook：Sharing Debugger
  • X：Card Validator
  • LINE：OGP Debugger

→ 再スクレイピング（再取得）必須

7. canonical と og:url を必ず一致させる
<link rel="canonical" href="https://example.com/">
<meta property="og:url" content="https://example.com/">

注意点

  • http / https 混在 → SEO評価分散
  • www 有無 → SNSで別ページ扱い

実務用OGPテンプレート

<!-- OGP -->
<meta property="og:title" content="ページタイトル">
<meta property="og:description" content="ページ説明">
<meta property="og:type" content="website">
<meta property="og:url" content="https://example.com/">
<meta property="og:image" content="https://example.com/ogp.jpg">

<!-- Twitter Card -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="ページタイトル">
<meta name="twitter:description" content="ページ説明">
<meta name="twitter:image" content="https://example.com/ogp.jpg">
よくある失敗例（実務で頻出）
ミス 影響
画像サイズが小さい トリミング・画質劣化
相対パス指定 画像が表示されない
OGP未設定 SNSで意図しない表示
全ページ共通OGP CTR低下
キャッシュ未更新 変更が反映されない
さらに効果を高める応用設定
  • og:site_name（サイト名表示）
  • article:published_time（記事公開日）
  • article:author（著者情報）
<meta property="og:site_name" content="サイト名">
<meta property="article:published_time" content="2026-02-18">
