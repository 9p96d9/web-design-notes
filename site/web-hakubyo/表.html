HTMLの表について解説して

  • HTMLの表（table）は、データを行と列で整理して表示するための要素です。
    • tabelタグ：「表全体」を形作る構造
    • trタグ：表の中の「行」を形作る構造（table row）
    • thタグ：表の「見出し」を形作る構造（tabel head）
    • tdタグ：表の「データ」を形作る構造（tabele data）

🔹 HTMLの表（table）の基本

最小構成
<table>
  <tr>
    <td>データ1</td>
    <td>データ2</td>
  </tr>
</table>

各タグの意味

タグ 意味
<table> 表全体
<tr> 行（table row）
<td> セル（データ）
🔹 見出し付きの基本構造
<table border="1">
  <tr>
    <th>名前</th>
    <th>年齢</th>
  </tr>
  <tr>
    <td>田中</td>
    <td>25</td>
  </tr>
  <tr>
    <td>佐藤</td>
    <td>30</td>
  </tr>
</table>

追加タグ

タグ 説明
<cth> 見出しセル（太字＆中央揃え）
🔹 正しい構造（thead / tbody / tfoot）
<table>
  <thead>
    <tr>
      <th>商品名</th>
      <th>価格</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>りんご</td>
      <td>100円</td>
    </tr>
    <tr>
      <td>みかん</td>
      <td>80円</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>合計</td>
      <td>180円</td>
    </tr>
  </tfoot>
</table>
タグ 用途
<thead> 見出し
<tbody> 本体
<tfoot> 集計行
🔹 セル結合（行・列の結合）

横結合（colspan）

<td colspan="2">2列分結合</td>

縦結合（rowspan）

<td rowspan="2">2行分結合</td>
🔹 CSSで表をきれいにする
<style>
table {
  border-collapse: collapse;
  width: 60%;
}

th, td {
  border: 1px solid #666;
  padding: 8px;
  text-align: center;
}

th {
  background: #eee;
}
</style>

よく使うCSSプロパティ

プロパティ 効果
border-collapse: collapse 罫線を一本化
padding 余白
text-align 文字位置
background 背景色
🔹 アクセシビリティ対応（重要）
<table>
  <caption>社員一覧</caption>
  <thead>
    <tr>
      <th scope="col">名前</th>
      <th scope="col">部署</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">田中</th>
      <td>営業</td>
    </tr>
  </tbody>
</table>
要素 役割
<caption> 表の説明
scope="col" 列見出し
scope="row" 行見出し

👉️ スクリーンリーダー対応に重要

🔹 表を使うべき場面・使わない方がいい場面

使うべき

  • 成績表
  • 料金表
  • 時刻表
  • 統計データ

使わない方がいい

  • レイアウト目的（→ CSSのflex / gridを使う）
