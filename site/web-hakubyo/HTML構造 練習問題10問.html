超初心者向け HTML構造 練習問題10問

【準備】
以下の最小構成を毎回使いましょう：

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>練習</title>
  </head>
  <body>

  </body>
</html>
問題① 大見出しを作ろう

「自己紹介」という一番大きな見出しを表示してください。
ヒント： h1

問題② 文章を書こう

「こんにちは。HTMLを勉強中です。」という文章を表示してください。
ヒント： p

問題③ 見出し＋文章

以下を表示してください：

好きな食べ物
カレーが一番好きです。
ヒント： h2 と p

問題④ 箇条書きを作ろう

以下のリストを作成してください：

  • 映画
  • 音楽
  • ゲーム

ヒント： ul, li

問題⑤ リンクを作ろう

「Google」という文字をクリックしたら
「https://www.google.com」に飛ぶリンクを作ってください。
ヒント： a

問題⑥ 画像を表示しよう

好きな画像を1枚表示してください。
ヒント： img

問題⑦ グループ化しよう

以下を divでまとめて 表示してください：

  • タイトル：自己紹介
  • 文章：よろしくお願いします。

ヒント： div

問題⑧ セクション分け

以下の構造を sectionタグ を使って作ってください：

【趣味】
・読書
・旅行

【好きな食べ物】
・ラーメン
・寿司

ヒント： section, h2, ul, li

問題⑨ 親子構造を意識しよう【超重要】

以下の構造になるようにHTMLを書いてください

div
 ├ h1（タイトル）
 └ p（説明文）
問題⑩ ミニWebページを作ろう【総合】

自由テーマでOK
以下を含む簡単なWebページを作ってください：

  • タイトル（h1）
  • 説明文（p）
  • 見出し（h2）
  • 箇条書き（ul, li）
  • リンク（a）

解答例

① 大見出し
<h1>自己紹介</h1>

解説
h1 はページで 一番重要な見出し

② 文章
<p>こんにちは。HTMLを勉強中です。</p>

c
p は 文章（段落）

③ 見出し＋文章
<h2>好きな食べ物</h2>
<p>カレーが一番好きです。</p>
④ 箇条書き
<ul>
  <li>映画</li>
  <li>音楽</li>
  <li>ゲーム</li>
</ul>
⑤ リンク
<a href="https://www.google.com">Google</a>
⑥ 画像
<img src="https://placehold.jp/300x200.png" alt="サンプル画像">

解説

  • src → 画像URL
  • alt → 画像が表示できない時の文字
⑦ divでグループ化
<div>
  <h1>自己紹介</h1>
  <p>よろしくお願いします。</p>
</div>
⑧ section構造
<section>
  <h2>趣味</h2>
  <ul>
    <li>読書</li>
    <li>旅行</li>
  </ul>
</section>

<section>
  <h2>好きな食べ物</h2>
  <ul>
    <li>ラーメン</li>
    <li>寿司</li>
  </ul>
</section>
⑨ 親子構造
<div>
  <h1>タイトル</h1>
  <p>説明文</p>
</div>

解説
→ divの中にh1とpが入る

模範解答⑩ ミニWebページ（完成例）
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>自己紹介ページ</title>
  </head>
  <body>

    <h1>自己紹介</h1>
    <p>こんにちは。HTMLを勉強中です。</p>

    <h2>好きなこと</h2>
    <ul>
      <li>映画</li>
      <li>音楽</li>
      <li>プログラミング</li>
    </ul>

    <p>
      参考サイト：
      <a href="https://developer.mozilla.org/ja/">MDN Web Docs</a>
    </p>

  </body>
</html>
