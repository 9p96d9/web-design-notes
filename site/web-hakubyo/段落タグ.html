段落タグ

HTML 2026/01/14

段落タグ

  • プロンプト例

HTMLの段落について解説して

  • pタグはparagraph（パラグラフ）の頭文字です
  • HTMLで文章のひとまとまり（段落）を表す
<p>これは段落です。</p>

ブラウザでは、前後に余白（マージン）が付いて表示され、文章の区切りとして見やすくなります。

基本構文
<p>ここに文章を書きます。</p>
  • <pc → 段落の開始
  • </p> → 段落の終了
表示の例
<p>これは1つ目の段落です。</p>
<p>これは2つ目の段落です。</p>

【表示結果】

これは1つ目の段落です。
これは2つ目の段落です。

👉 自動的に改行＋余白が入ります。

改行との違い（<br>との比較）

❌ よくある誤解

これは1行目です。<br>
これは2行目です。

👉️ 改行はされるが段落にはならない

✅ 正しい段落

<p>これは1行目です。</p>
<p>これは2行目です。</p>
タグ 役割
<p> 文章のまとまり（意味のある段落）
<br> 単なる改行
段落内に入れられるタグ
  • <p> の中にはインライン要素を入れられます。
<p>これは<strong>重要</strong>な文章です。</p>

よく使うもの

  • <strong>（強調）
  • <em>（斜体・強調）
  • <a>（リンク）
  • <span>（装飾用）

❌ 入れられないもの

  • <div>
  • <h1>～<h6>
  • <ul>>>, <ol>
CSSでの装飾

【css】

p {
  color: #333;
  font-size: 16px;
  line-height: 1.8;
}

【html】

<p>読みやすい文章になります。</p>

【よく調整するプロパティ】

  • font-size → 文字サイズ
  • line-height → 行間
  • margin → 段落の間隔
よくあるミス

❌ 閉じタグ忘れ

<p>文章
<p>次の文章

👉️ レイアウト崩れの原因

❌ 段落の入れ子

<p>
  <p>これはNG</p>
</p>

👉️ HTML仕様違反

実践的な使い方例
<article>
  <h2>HTMLとは</h2>
  <p>HTMLはWebページを作るための言語です。</p>
  <p>見出し、段落、画像などを構造化できます。</p>
</article>
