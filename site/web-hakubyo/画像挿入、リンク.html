画像挿入、リンク

HTML 2026/01/17

画像挿入

  • プロンプト例

HTMLの画像表示について解説して

  • imgタグは文書内に画像を表示するタグです
  • img：image
  • src：source
  • 表示できる画像の形式は「.gif（GIF形式）」、「.jpg（JPEG形式）」、「.png（PNG形式）」「.webp（WebP形式）」などがあります
🖼 HTMLで画像を表示する方法

HTMLで画像を表示するには <img> タグ を使います。

<img src="image.jpg" alt="説明文">

属性の意味

属性 説明
src 画像ファイルのパス（必須）
alt 画像が表示されない時の代替テキスト（必須・SEO・アクセシビリティ重要）
  • src属性：画像の読み込み元を指定する属性
  • alt属性：画像の代替となるテキスト情報

その他の属性の意味

  • title属性：補足情報をツールチップとして表示
  • width属性とheight属性：画像の横幅と縦幅のサイズを指定
<img src=”画像ファイルのパス/ ファイル名.(png, jpg, gif など拡張子)  ” alt=”代替テキスト” title=”ツールチップで補足情報を記載” width=”画像の横幅” hight=”画像の高さ”>
画像作成
  • プロンプト例

正方形で水色の椅子の写真

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>はじめてのHTML：画像を表示</title>
</head>
<body>
<h1>画像を表示</h1>
<p>HTML内に画像を挿入する記述</p>
<p><img src="chair.jpg" alt="椅子"></p>
</body>
</html>

🔗 HTMLのリンク（<a>タグ）

  • プロンプト例

HTMLのリンクについて解説して

リンクには３つの使い方があります。

  1. テキストリンク
  2. 画像リンク
  3. メールリンク（セキリュティ上の問題から現在使用されることはありません）
  • aタグはページを移動するハイパーリンクを設定できます
  • 「a」はanchor（アンカー）の頭文字です
  • 「href」属性はhypertext reference（ハイパーテキスト リファレンス）の略称で、リンク先を指定することができます
  • aタグに「target」属性を付与すると、新しいウインドウが開いて、そこに新しいページが表示されます
📌 href属性とは？

「href」は リンク先のURL を指定します。

値 説明
https://～ 外部サイト
page.html 同じフォルダ内の別ページ
../index.html 1つ上の階層のページ
#id名 ページ内リンク（アンカー）
mailto: メール送信
tel: 電話発信
テキストリンク
<a href="移動先の住所（パス）">リンクテキスト</a>

外部サイトへのリンク

<a href="https://www.yahoo.co.jp">Yahoo</a>

ページ内リンク（アンカーリンク）
① 移動先にidを指定

<h2 id="section1">概要</h2>

② リンクを作成

<a href="#section1">概要へジャンプ</a>

➡ 同じページ内をスクロール移動できます。

画像リンク
<a href="移動先の住所（パス）"><img src="画像の置いてある場所" alt="代替え文字"></a>
メールリンク
  • セキュリティの問題でこの記述をする例は少ない
<a href="mailto:メールアドレス">お問い合わせ</a>

件名付き

<a href="mailto:test@example.com?subject=お問い合わせ">お問い合わせ</a>
📞 電話リンク（スマートフォン向け）
<a href="tel:09012345678">電話する</a>
新規ウィンドウで開く
  • target="_blank"
  • 「_」アンダースコア
<a href="#" target="_blank">別ページを開く</a>

セキュリティ対策（推奨）

<a href="https://www.google.com" target="_blank" rel="noopener noreferrer">Google</a>
⭐ よく使う属性まとめ
属性 役割
href リンク先
target="_blank" 新規タブで開く
rel セキュリティ指定
download ファイルダウンロード
title ツールチップ表示
📥 ダウンロードリンク
<a href="file.pdf" download>PDFをダウンロード</a>
