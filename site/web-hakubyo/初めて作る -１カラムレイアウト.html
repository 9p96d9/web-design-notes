初めて作る -１カラムレイアウト

コーディング基礎 2026/02/07

初めて作る -１カラムレイアウト

  • プロンプト例

完全未経験者が１カラムWebページを、見出しと段落と箇条書きの組み合わせ作る問題を作成して

完成例

📝 練習問題：1カラムのWebページを作ろう

🎯 目的

見出し・段落・箇条書きを使って、縦に1列だけのシンプルなWebページを作れるようになる。

📌 作るページのテーマ

「はじめてのプログラミング学習」

📐 ページ構成（完成イメージ）

ページには次の要素を上から順番に配置してください。

① ページのタイトル（大見出し）

  • はじめてのプログラミング学習

② 導入文（段落）

  • 次の文章を段落として表示してください。

このページでは、これからプログラミングを学ぶ人に向けて、学習のポイントを紹介します。
未経験者でも安心して始められる内容になっています。

③ セクション1：学習するメリット（中見出し＋箇条書き）
見出し：
プログラミングを学ぶメリット
箇条書き：

  • 論理的に考える力が身につく
  • Webサイトを作れるようになる
  • 仕事の選択肢が広がる

④ セクション2：おすすめの学習ステップ（中見出し＋段落＋箇条書き）
見出し：

  • おすすめの学習ステップ

段落：

  • 次の順番で学習すると、スムーズに理解できます。

箇条書き：

  • HTMLでページの構造を作る
  • CSSでデザインを整える
  • JavaScriptで動きをつける

⑤ フッター（小さな文字）

© 2026 Programming Study

📋 作成ルール
  • 1カラム（縦一列）レイアウト
  • HTMLとCSSのみ使用（JavaScript不要）
  • 文字の中央寄せや背景色を自由につけてもOK
💡 発展課題（余裕があれば）
  • 背景色を付ける
  • ボックスを角丸にする
  • 全体の幅を600pxくらいにする
  • フォントを読みやすくする
🧠 学習ポイント

この課題で次のことが身につきます。

  • <h1>〜<h3>
  • <p>
  • <ul><li>
  • CSSによる余白・文字サイズ・中央寄せ

テキスト

はじめてのプログラミング学習
このページでは、これからプログラミングを学ぶ人に向けて、学習のポイントを紹介します。 未経験者でも安心して始められる内容になっています。

プログラミングを学ぶメリット
論理的に考える力が身につく
Webサイトを作れるようになる
仕事の選択肢が広がる
おすすめの学習ステップ
次の順番で学習すると、スムーズに理解できます。

HTMLでページの構造を作る
CSSでデザインを整える
JavaScriptで動きをつける

🧩 模範解答：1カラムWebページ（HTML＋CSS）

  • コーディングルールは、自前のルールで記述（AIのコーディング大筋のみ利用します。）

HTML

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>はじめてのプログラミング学習</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
  <div class="container">

    <!-- header -->
    <header>
    <h1>はじめてのプログラミング学習</h1>
    <p>このページでは、これからプログラミングを学ぶ人に向けて、学習のポイントを紹介します。
      未経験者でも安心して始められる内容になっています。</p>
    </header>
    <!-- /header -->

    <!-- main -->
    <main>
      <section>
        <h2>プログラミングを学ぶメリット</h2>
        <ul>
          <li>論理的に考える力が身につく</li>
          <li>Webサイトを作れるようになる</li>
          <li>仕事の選択肢が広がる</li>
        </ul>
        <h2>おすすめの学習ステップ</h2>
        <p>次の順番で学習すると、スムーズに理解できます。</p>
        <ul>
          <li>HTMLでページの構造を作る</li>
          <li>CSSでデザインを整える</li>
          <li>JavaScriptで動きをつける</li>
        </ul>
      </section>
    </main>
    <!-- /main -->

    <!-- footer -->
    <footer>
      © 2026 Programming Study
    </footer>
    <!-- /footer -->

  </div><!-- /.container -->
</body>
</html>
  • 文法チェックでミスが無ければCSSの記述に入ります。
