ヘッダーとヒーローイメージ

  • プロンプト例

HTMLでheaderブロックを作成したい

  • header内は、h1とnavを横並び
  • h1は「Bloom Café」というロゴ
  • header幅 960px、padding: 20px 0;
  • navは「ホーム」「ホーム」「メニュー」「ギャラリー」
  • headerブロックの前後にコメントを挿入「<!-- header -->」「<!-- /header -->」

ChatGPT（画像）で作成→　

ワイヤーフレーム

画像サイズ

  • プロンプト例

100vhで表示するときヘッダーの高さを引き算する方法

👉 「画面全体の高さ（100vh）− ヘッダーの高さ（125px）」

記述例

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>ロゴとナビゲーションを横並び</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- header -->
<header class="header">
  <h1><img src="img/logo.jpg" alt="Bloom Café"></h1>
  <nav class="gnav">
    <ul>
      <li><a href="#" class="current">ホーム</a></li>
      <li><a href="#">コンセプト</a></li>
      <li><a href="#">メニュー</a></li>
      <li><a href="#">ギャラリー</a></li>
    </ul>
  </nav>
</header>
<!-- /header -->

<!-- main -->
<main class="main">
  <section class="hero">
    <h2>心地よいカフェ時間</h2>
    <p>自然光と花に包まれた癒しの空間</p>
  </section><!-- hero -->
</main>
<!-- /main -->
</body>
</html>


【CSS】

@charset "UTF-8";

/* -------------------------------
  reset 
------------------------------- */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
ul {
  list-style: none;
}
a {
  color: inherit;
  text-decoration: none;
}
img {
  max-width: 100%;
  vertical-align: bottom;
}


/* -------------------------------
  body
------------------------------- */
body {
  font-family: sans-serif;
  line-height: 1.6;
}


/* -------------------------------
  layout
------------------------------- */
.header {
  width: 960px;
  height: 125px;
  margin: 0 auto;  /* ブラウザ幅の中央配置 */
  padding: 10px 0;  /* header内の文字を読みやすく */
  display: flex;  /* 子要素を横並び */
  justify-content: space-between;  /* h1とnavを左右配置 */
  align-items: center;  /* headerの高さの中央に配置 */
}
h1 img {
  width: 200px;
  height: 105px;
  object-fit: cover;
}
.gnav ul {
  display: flex;  /* 親要素 ul 内の子要素 li を横並び */
  gap: 3px;
}
  .gnav li a {
    display: block;
    padding: 10px 30px;
    background-color: #ded0b4;
    transition: .3s;
  }
    .gnav li a:hover, li a.current {
      background-color: #6b614c;
      color: #fff;
    }


/* -------------------------------
  hero
------------------------------- */
.hero {
  width: 100%;
  height: calc(100vh - 125px); /* view height デバイスの高さ */
  background: url("../img/hero.jpg") no-repeat center / cover;
  /* ブラウザ内のコンテンツを上下左右の中央配置 */
  display: flex;
  justify-content: center;
  align-items: center;
}
.hero-content {
  text-align: center;
  color: #fff;
  text-shadow: 0 0 6px #302c23, 0 0 10px #302c23;
}
  .hero-content h2 {
    margin-bottom: 10px;
    font-size: 44px;
    font-family: serif;
  }
文字を読みやすく（画像の輝度を落とす）
  • オーバレイを設定
