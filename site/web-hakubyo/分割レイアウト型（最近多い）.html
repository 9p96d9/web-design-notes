分割レイアウト型（最近多い）

  • プロンプト例

分割レイアウト型の事例を作成して

完成イメージ
  • 左：写真
  • 右：テキスト
  • 高さ：画面いっぱい
  • 横並び：Flexbox
レイアウトのポイント

① Flexboxで横分割

.split{
  display: flex;
}

これで、左右のブロックが横並びになります。

② 幅50%で均等分割

width: 50%;

これで

  • 左 50%
  • 右 50%

になります。

③ 高さを画面いっぱい

height: 100vh;
  • vhは 画面の高さ基準です。

100vh = 画面いっぱい

よくあるLPの分割デザイン

① 写真 × キャッチコピー

| 画像 | テキスト |

② 商品説明

| 商品写真 | 説明 |

③ 交互レイアウト（LP王道）

| 画像 | 説明 |
| 説明 | 画像 |
| 画像 | 説明 |

事例１

テキスト
心地よいカフェ時間
自然光と花に包まれた空間で、 ゆったりとしたひとときをお過ごしください。 丁寧に淹れたコーヒーと季節のスイーツを ご用意しています。

MENUを見る
記述例

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>Split Layout</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<section class="split">
  <div class="split-image"></div>
  <div class="split-text">
    <h1>心地よいカフェ時間</h1>
    <p>自然光と花に包まれた空間で、
      ゆったりとしたひとときをお過ごしください。
      丁寧に淹れたコーヒーと季節のスイーツを
      ご用意しています。</p>
    <a href="#" class="btn">MENUを見る</a>
  </div>
</section>
</body>
</html>

【CSS】

@charset "UTF-8";

/* ------------------------------------------
  reset
------------------------------------------ */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}


/* ------------------------------------------
  body
------------------------------------------ */
body {
  background-color: #fff;
  color: #333;
  font-family: sans-serif;
  line-height: 1.0;
}


/* ------------------------------------------
  layout
------------------------------------------ */
.split {
  display:flex;
  height:100vh;
}

/* 左側 */
.split-image {
  width:50%;
  background-image:url("https://images.unsplash.com/photo-1509042239860-f550ce710b93");
  background-size:cover;
  background-position:center;
}

/* 右側 */
.split-text {
  width: 50%;
  display: flex;
  flex-direction: column;
  justify-content: center;
  padding: 60px;
  background: #f7f7f7;
}
  .split-text h1 {
    margin-bottom: 20px;
    font-size: 36px;
  }
  .split-text p {
    margin-bottom: 30px;
    line-height: 1.8;
  }
.btn{
  display: inline-block;
  padding: 12px 24px;
  background: #333;
  color: #fff;
  text-decoration: none;
}
