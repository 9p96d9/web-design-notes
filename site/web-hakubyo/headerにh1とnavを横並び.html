headerにh1とnavを横並び

コーディング基礎 2026/02/18

headerにh1とnavを横並び

  • プロンプト例

春の旅というWebページを作成したい

  • 日本の春がテーマ
  • ロゴとナビゲーションをheader内で横並び

ロゴ
  • ChatGPT（画像）で作成

記述例

【HTML】

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>春の旅</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- header -->
<header>
  <div class="container">
    <h1 class="logo"><img src="img/logo.png" alt="春の旅"></h1>
    <nav>
      <ul>
        <li><a href="#">HOME</a></li>
        <li><a href="#">桜スポット</a></li>
        <li><a href="#">旅の記録</a></li>
        <li><a href="#">お問い合わせ</a></li>
      </ul>
    </nav>
  </div>
</header>
<!-- /header -->

<!-- keyvisual -->
<div class="keyvisual">
<img src="https://images.unsplash.com/photo-1522383225653-ed111181a951">
  <div class="key-text">
    <h2>日本の春を旅する</h2>
    <p>桜とともに巡る旅の記録</p>
  </div><!-- /.key-text -->
</div><!-- /. keyvisual -->
</body>
</html>

【CSS】

@charset "UTF-8";

/* ----------------------------------------
  reset
---------------------------------------- */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
ul {
  list-style: none;
}
a {
  color: inherit;
  text-decoration: none;
}
img {
  max-width: 100%;
  vertical-align: bottom;
}


/* ----------------------------------------
  body
---------------------------------------- */
body {
  background-color: #fff;
  color: #333;
  font-size: 16px;
  font-family: serif;
  line-height: 1.0;
}


/* ----------------------------------------
  header
---------------------------------------- */
header{
  background: #fff5f7;
  border-bottom: 1px solid #eee;
}
.container{
  width: 960px;
  margin: auto;
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 20px 0;
}
.logo{
  width: 160px;
}
nav ul{
  display: flex;
  list-style: none;
  margin: 0;
  padding: 0;
  gap: 30px;
}
nav a{
  text-decoration: none;
  color: #444;
}


/* ----------------------------------------
  keyvisual
---------------------------------------- */

/* キービジュアル */
.keyvisual{
  position: relative;
  height: 50vh;
}
  .keyvisual img{
    width: 100%;
    height: 100%;
    object-fit: cover;
  }

/* キャッチコピー */
.key-text{
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%,-50%);
  padding: 20px 40px;
  background-color: #ad6763b6;
  color: white;
  text-align:  center;
}
  .key-text h2{
    font-size: 40px;
    margin-bottom: 10px;
  }
  .key-text p{
    font-size: 18px;
    font-family: sans-serif;
  }
