Flexbox（フレックスボックス

  • プロンプト例

CSSのFlexboxについて詳しく解説して

  • CSSの Flexbox（フレックスボックス） は、要素を横並びや縦並びに柔軟に配置するためのレイアウト方法です。
  • 特に ナビゲーション・カードレイアウト・中央配置 などでよく使われます。
Flexboxとは

Flexboxは 親要素に display:flex を指定すると子要素の並び方を制御できるレイアウトです。

【CSS】

.container {
  display: flex;
}

【HTML】

<div class="container">
  <div>BOX1</div>
  <div>BOX2</div>
  <div>BOX3</div>
</div>

結果

BOX1  BOX2  BOX3
  • 通常のHTMLは 縦に並びますが、Flexboxを使うと 横並びになります。
Flexboxの重要な概念

Flexboxには2つの役割があります。

名前 意味
Flex Container 親要素
Flex Item 子要素

【例】

container（親）
 ├ item
 ├ item
 └ item
並ぶ方向（flex-direction）

要素の並ぶ方向を決めます。

.container {
 display: flex;
 flex-direction: row;
}
値 意味
row 横並び（左→右）
row-reverse 横並び（右→左）
column 縦並び
column-reverse 縦逆

【例】

.container {
 display: flex;
 flex-direction: column;
}

【例】

BOX1
BOX2
BOX3
横方向の位置（justify-content）

横方向の配置を決めます。

.container {
 display: flex;
 justify-content: center;
}
値 意味
flex-start 左寄せ
center 中央
flex-end 右寄せ
space-between 均等配置
space-around 余白付き均等
space-evenly 完全均等

【例】

space-between
BOX1      BOX2      BOX3
縦方向の位置（align-items）

縦方向の位置を調整します。

.container {
 display: flex;
 align-items: center;
 height: 300px;
}
値 意味
flex-start 上
center 中央
flex-end 下
stretch 高さを伸ばす

【例】

    BOX1
    BOX2
    BOX3
要素を折り返す（flex-wrap）

横並びが多くなったとき改行します。

.container {
 display: flex;
 flex-wrap: wrap;
}

【結果】

BOX1 BOX2 BOX3
BOX4 BOX5 BOX6
Flexアイテムの幅（flex）

子要素のサイズを調整できます。

.item {
 flex: 1;
}

【例】

| BOX1 | BOX2 | BOX3 |

すべて同じ幅になります。

よく使うFlexboxパターン

ナビゲーション横並び
【CSS】

nav ul {
 display: flex;
 gap: 20px;
 list-style: none;
}

【HTML】

<nav>
  <ul>
    <li>Home</li>
    <li>About</li>
    <li>Blog</li>
    <li>Contact</li>
  </ul>
</nav>

カード横並び
【CSS】

.cards {
 display: flex;
 gap: 20px;
}

【HTML】

<div class="cards">
   <div class="card">Card</div>
   <div class="card">Card</div>
   <div class="card">Card</div>
</div>

完全中央配置（超重要）
【CSS】

.container {
 display: flex;
 justify-content: center;
 align-items: center;
 height: 100vh;
}
Flexboxを理解するコツ

覚える順番はこの5つです。

① display:flex
② justify-content（横方向）
③ align-items（縦方向）
④ flex-direction（並ぶ方向）
⑤ flex-wrap（折り返し）

この5つで 90%のレイアウトが作れます。

FlexboxとGridの違い
Flexbox Grid
1方向レイアウト 2次元レイアウト
横 or 縦 行＋列
ナビ・UI向き ページレイアウト向き

【例】

  • Flexbox（横並び）
  • Grid（表のようなレイアウト）
