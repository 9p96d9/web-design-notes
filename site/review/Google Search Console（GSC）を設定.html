Google Search Console（GSC）を設定

GoogleSearchConsole 2026/01/11

Google Search Console（GSC）を設定

  • プロンプト例

Google Search Consoleの設定をするときの注意点

① 初期設定時の注意点（最重要）

1. プロパティの種類は「ドメイン」推奨

ドメインプロパティ：example.com 配下の

http / https
www / non-ww

  • すべてを一括管理できる → 推奨
  • URLプレフィックス：個別URL単位で管理 → 初心者は混乱しやすい

👉 原則：ドメインプロパティを選択

2. 所有権確認は「DNS設定」が最も安定

DNSレコードでの認証が恒久的・トラブルが少ない
HTMLファイル認証やmetaタグ認証は、

  • サーバー移転
  • テーマ変更

で 認証が外れるリスクあり

3. 正規URL（canonical）と一致させる
  • Search Console登録URL
  • サイトの正規URL（canonical / 内部リンク）
  • これらが 完全一致していないと評価が分散

【例】

https://example.com
https://www.example.com

→ どちらかに統一 + リダイレクト設定

② 設定後すぐやるべき重要設定

1. XMLサイトマップの送信

【送信先】

インデックス作成 → サイトマップ

【例】

https://example.com/sitemap.xml

【効果】

  • クロール促進
  • インデックス漏れ防止
  • 新規ページの早期認識
2. インデックス登録状況の確認

インデックス作成 → ページ

チェック項目

  • 「登録済み」ページ数
  • 「クロール済み - 未登録」
  • 「検出 - インデックス未登録」

👉 低品質ページ・重複ページ・noindex誤設定がよく原因

③ 技術面の注意点（制作・運用現場で重要）

1. noindex / robots.txt の誤設定

以下は非常に多いミス：

<meta name="robots" content="noindex">

Disallow: /

👉 公開後も残っていると、全ページ非表示になる
- 公開前チェック必須

2. モバイルユーザビリティ

GSCは モバイルファーストインデックス

チェック箇所
エクスペリエンス → モバイルユーザビリティ

よくある問題

  • 文字が小さすぎる
  • クリック要素が近すぎる
  • viewport未設定
3. Core Web Vitals（表示速度）

エクスペリエンス → ウェブに関する主な指標

影響項目

  • LCP（表示速度）
  • CLS（レイアウトずれ）
  • INP（操作遅延）

👉 PageSpeed Insights と併用チェック推奨

④ SEO観点での注意点（運用フェーズ）

1. 検索パフォーマンスの正しい見方

検索結果 → 検索パフォーマンス

見るべき指標

  • 表示回数
  • クリック数
  • CTR
  • 平均掲載順位
  • 順位だけで一喜一憂しない

→ CTR × 表示回数 を重視

2. クエリ × ページ分析

「どの検索語句で、どのページが評価されているか」
👉 リライト対象ページの特定に直結

3. インデックス未登録URLの精査

理由例
内容薄い
重複コンテンツ
パラメータ付きURL量産
ページネーション過多

⑤ よくあるトラブル事例（実務）

事例 原因
全ページが検索に出ない noindex / robots.txt / 認証未完了
急激に順位下落 重複増加 / 低品質大量生成
インデックスされない クロール制限 / 内部リンク不足
HTTPS後に評価下落 リダイレクト・canonicalミス

⑥ Web制作現場向け 初期設定チェックリスト

公開時チェック用

  • ドメインプロパティで登録
  • DNS認証完了
  • XMLサイトマップ送信
  • noindex削除確認
  • robots.txt確認
  • canonical設定確認
  • 301リダイレクト確認
  • モバイル表示確認
