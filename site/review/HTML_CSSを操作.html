テキストの変更と取得

  • text()メソッドで命令
テキストの変更
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>メソッド：テキストの変更</title>
</head>
<body>
<p id="first">変更前</p>

<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
<script>
$(function(){
  $( 'p#first' ).text( '変更後' );
});
</script>
</body>
</html>

テキストの取得

<!DOCTYPE html>

HTMLの移動

  • HTMLの要素を文書内に新たに追加するのではなく、もともと存在していた要素の文書内の位置を変更する

HTML要素内の先頭に移動

  • prependTo()メソッド
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>メソッド：HTML要素内の先頭に移動</title>
</head>
<body>
<p id="first">テキストテキスト</p>
<strong>先頭に移動</strong>

<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
<script>
$(function(){
  $( 'strong' ).prependTo( 'p' );

</body>

CSSの制御

  • jQueryでは簡単な記述でCSSのプロパティの値を設定したり、取得したりできる
CSSプロパティの設定
  • css()メソッド
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>メソッド：CSSプロパティの設定</title>
</head>
<body>
<p>テキストテキストテキストテキストテキスト</p>

<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.7.1/jquery.min.js"></script>
<script>
$(function(){
  $ ('p' ).css( 'color', 'red' );
});
</script>
</body>
</html>

《一括して設定する場合》

<script>
$(function(){
  $('p').css({ 
      backgroundColor: 'skyblue', 
      fontWeight: 'bold',
      color: 'yellow' 
    });
});
</script>
