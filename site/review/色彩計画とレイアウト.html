CSS 2026/01/13

色彩計画とレイアウト

  • カスタムプロパティを使った効率的なレイアウト

カスタムプロパティで色彩計画
  • 「ベースカラー」「アクセントカラー」「アソートカラー」を設計しておきます
:root {
  --bgc_blue: #a9e5fc;
  --bgc_darkblue: #146abf;
  --title_color: #408edd;
}
交互に背景色を変更
  • 奇数番の「section」の背景色を「カスタムプロパティ」で指定する
section:nth-of-type(odd) {
  background-color: var(--bgc_blue);
}
