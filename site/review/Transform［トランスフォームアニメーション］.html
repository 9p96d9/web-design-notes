Transform［トランスフォームアニメーション］

CSS 2025/11/07

Transform［トランスフォームアニメーション］

  • 要素に移動(translate)、拡大縮小(scale)、回転(rotate)、傾斜(skew)などの変形(transform)を適応させるCSSプロパティです
transformプロパティの値に指定できる関数

関数名 読み方 実行効果
translate  トランスレイト  移動
rotate  ローテート  回転
scale  スケール  伸縮
skew  スキュー  傾斜

初期値

  • transform: none;
移動（translate）
  • もとの位置から「どれだけ移動させるか」を指定できます

プロパティ説明
translateX方向の移動距離, Y方向の移動距離
translateXX方向の移動距離
translateYY方向の移動距離
translateZZ方向の移動距離
translate3dX方向の移動距離, Y方向の移動距離, Z方向の移動距離

回転（rotate）
  • 要素を回転させることができます
  • degという単位で指定（degree：角度）

プロパティ説明
rotate回転角度
otate3d数値, 数値, 数値, 回転角度
rotateXX軸を軸とする回転角度
rotateYY軸を軸とする回転角度
rotateZZ軸を軸とする回転角度

縮尺（scale）
  • 要素の拡大と縮小を指定できます

プロパティ説明
scaleX方向の縮尺比率, Y方向の縮尺比率
scaleXX方向の縮尺比率
scaleYY方向の縮尺比率
scaleZZ方向の縮尺比率
scale3dX方向の縮尺比率, Y方向の縮尺比率, Z方向の縮尺比率

傾斜（skew）
  • 並行四辺形を表現する際に使用する値

プロパティ説明
skewX軸の傾斜角度, Y軸の傾斜角度
skewXX軸の傾斜角度
skewYY軸の傾斜角度

  transform: scale(0.5, 1);
}
.scale03:hover {
  transform: scale(1, 1.5);

/* skew() */
.skew01:hover {
  transform: skew(30deg, 0);
}
.skew02:hover {
  transform: skew(0, 30deg);
}
.skew03:hover {
  transform: skew(30deg, 30deg);
}
