CSSで縦書き

  • プロンプト例

日本語のコンテンツを縦書きの表現にしたい

日本語コンテンツを縦書き表示にする方法は、CSS の writing-mode を使うのが最も簡単で実用的です。

基本：CSSで縦書きにする

【html】

<p class="vertical">
  これは縦書きの日本語コンテンツです。Webでも自然な縦組み表示ができます。
</p>

【css】

.vertical {
  writing-mode: vertical-rl;
}

各プロパティの意味

writing-mode: vertical-rl vertical-lr
右から左へ進む縦書き（日本語の標準スタイル） 左から右へ進む縦書き（特殊用途）
実用向け：読みやすい縦書きレイアウト

【html】

<div class="vertical">
  日本語の縦書きは、文章のリズムや美しさを表現しやすく、和風デザインに非常に適しています。
</div>

【css】

.vertical {
  writing-mode: vertical-rl;
  line-height: 1.8;
  letter-spacing: 0.05em;
  font-size: 18px;
  height: 300px;
  border: 1px solid #ccc;
  padding: 10px;
}
句読点・記号の回転を自然にする
.vertical {
  text-orientation: mixed;
}
  • 漢字・かな → 縦
  • 英数字 → 横向き

➡ 日本語表示では ほぼ必須

縦書き × レスポンシブ対応（スマホ切替）
.vertical {
  writing-mode: vertical-rl;
}

@media (max-width: 768px) {
  .vertical {
    writing-mode: horizontal-tb;
  }
}

➡ PC：縦書き / スマホ：横書き の自然な切替

よくある用途
  • 和風デザインサイト
  • 俳句・短歌・詩
  • 小説・文章コンテンツ
  • 美術館・博物館系サイト
実用サンプル
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>縦書きサンプル</title>
<style>
.vertical {
  writing-mode: vertical-rl;
  text-orientation: mixed;
  line-height: 1.8;
  font-size: 18px;
  border: 1px solid #aaa;
  padding: 15px;
  height: 300px;
}

@media (max-width: 768px) {
  .vertical {
    writing-mode: horizontal-tb;
  }
}
</style>
</head>
<body>

<div class="vertical">
日本語の縦書き表現は、Webデザインに和の雰囲気と高級感を与えます。
</div>

</body>
</html>
