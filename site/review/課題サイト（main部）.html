  • マルチデバイス対応の課題サイトを作成

完成例

Web Fonts設定
  • 「欧文書体」→「日本語書体」→「汎用書体」の順で記述します
  • 今回は、「Josefin Sans」と「Noto Sans Japanese」
  • 「sans」は（サン）と読みます：フランス語で、英語では「none」の意味になります

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>〇〇の課題サイト</title>

<!-- Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Josefin+Sans:ital,wght@0,100..700;1,100..700&family=Noto+Sans+JP:wght@100..900&display=swap" rel="stylesheet">

<link rel="stylesheet" href="css/style.css">
</head>
課題のサムネイルをギャラリー的に配置
  • ギャラリー的にカード型のアイテムが横並びになるレイアウトは「ul」で設定します

ダミー画像

  • ダウンロードせず使えるダミー画像作成サービス

placehold.jp

  • Chrome拡張機能「モバイルシミュレーター 」をインストール
