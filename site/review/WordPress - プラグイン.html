WordPress - プラグイン

WP Multibyte Patch
  • WordPress 日本語版パッケージのためのマルチバイト機能の拡張
  • 「今すぐインストール」→「有効化」

Show Current Template
  • 使用中のテンプレートファイル名、テーマ名、インクルードされているファイル名をツールバーに表示するプラグイン
  • 「今すぐインストール」→「有効化」

All In One SEO
  • SEO ランキングを向上させ、トラフィックを増やす強力な SEO プラグイン
  • 「今すぐインストール」→「有効化」

Akismet
  • ブログをスパムから保護するプラグイン
  • 「今すぐインストール」→「有効化」

  • 「設定」
