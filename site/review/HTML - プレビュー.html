HTML - プレビュー

  • 基本的な文書構造を、Google Chromeでプレビュー

Live Server（拡張機能）でプレビュー

Google Chrome

  • PCに入っていない場合は、ダウンロードしてインストールします

www.google.com

Chromeを規定ブラウザに指定

  • 「設定」→「規定ブラウザ」

記述例
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>ページタイトル</title>
</head>
<body>
<!-- header -->
<header>
  <h1>メインタイトル</h1>
  <nav>
    <ul>
      <li><a href="#">ホーム</a></li>
      <li><a href="#">About</a></li>
      <li><a href="#">お問い合わせ</a></li>
    </ul>
  </nav>
</header>
<!-- /header -->

<!-- main -->
<main>
  <section>
    <h2>記事タイトル</h2>
    <p>ここに本文を書きます。</p>
  </section>
</main>
<!-- /main -->

<!-- footer -->
<footer>
  <p>&copy; 2025 あなたの名前またはサイト名</p>
</footer>
<!-- /footer -->
</body>
</html>
