EventListener

イベント 2025/10/18

イベントリスナー（EventListener）

  • DOMイベントリスナー
  • ひとつのイベントに複数のイベント関数を指定できる
addEventListenerでイベント関数を指定する
  • イベントを処理する関数
  • 「addEventListener」メソッドを使う

DOMオブジェクト . addEventListener ('イベント名',　実行したい関数,　falseまたはtrue)

※最後に指定する「falseまたはtrue」は、イベントをどの時点で実行するかを指定する値です。

  • ほとんどの場合は「false」を使います
読み込まれたときのイベント
  • ウィンドウが表示されたとき「DOMContentLoaded」（onloadよりも早い処理）
  • 「window」オブジェクトに対して設定します

ES6の場合

<script>
window.addEventListener('DOMContentLoaded', () => {
  alert("OK");
}, false);
</script>

ES5の場合

ボタンのクリック処理

ES6の場合

<body>
<h1>ボタンクリックイベント</h1>
<button id='mybtn'>クリックしてね</button>
<script>
window.addEventListener('load', () => {
  const btn = document.getElementById('mybtn');
  btn.addEventListener('click', () => {
    alert('クリックされた');
  }, false);
}, false);
</script>
</body>

ES5の場合

<body>
<h1>ボタンクリックイベント</h1>
<button id='mybtn'>クリックしてね</button>
<script >
window.addEventListener('load',
function() {
  var btn = document.getElementById('mybtn');
  btn.addEventListener('click',
    function () {
      alert(' クリックされた');
    }, false);
}, false);
</script>
</body>
複数のボタンの場合
  • イベントのプロパゲーション（イベントがDOMツリー上の子要素から親要素へ順に伝達すること）
  • キャプチャーフェーズ（イベントが「どの要素に対して発生したのか」）
  • ターゲットフェーズ（ターゲット要素が決まる、イベントの引数は「target」プロパティ）
  • パブリングフェーズ（結びつけられているイベントを末端から処理）

ES6の場合

<body>
<h1>クリックされたときにボタン名を表示する</h1>
<div id="buttongroup">
  <button id="btn1">1</button>
  <button id="btn2">2</button>
  <button id="btn3">3</button>
</div>
<script>
window.addEventListener('load', () => {
    const element = document.getElementById('buttongroup');
    element.addEventListener('click', (event) => {
      alert(event.target.innerHTML);
    }, false);
}, false);
</script>
</body>
