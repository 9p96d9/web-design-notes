JavaScriptのイベントとは？

JavaScriptのイベント（event）とは、ユーザーの操作やブラウザ上で起こる出来事のことです。

🔹 イベントの代表例
イベント 発生するタイミング
click 要素がクリックされたとき
mouseover マウスが要素に乗ったとき
keydown キーが押されたとき
submit フォームが送信されたとき
load ページや画像の読み込み完了時
change 入力値が変更されたとき
🔹 イベントの基本構文
要素.addEventListener("イベント名", 関数);

c例：ボタンをクリックしたらアラート表示

<button id="btn">クリック</button>

<script>
  const btn = document.getElementById("btn");

  btn.addEventListener("click", function() {
    alert("クリックされました！");
  });
</script>

👉 ボタンがクリックされると イベントが発生 → 処理が実行 されます。

🔹 イベントの流れ（重要）

イベント発生 → イベントリスナーが検知 → 関数（処理）実行

🔹 よく使うイベントジャンル

🖱 マウス系

  • click
  • dblclick
  • mouseenter
  • mouseleave

⌨ キーボード系

  • keydown
  • keyup

📝 フォーム系

  • submit
  • input
  • change
  • focus
  • blur
🔹 イベントオブジェクト
btn.addEventListener("click", function(e) {
  console.log(e);
});

→ クリック位置、対象要素などが取得できます。

🔹 初心者向け一言まとめ

イベントとは「ユーザーの行動に反応して処理を実行する仕組み」

🔹 functionを使ったイベント処理の基本例

ボタンをクリックしたらメッセージ表示
<button id="btn">クリック</button>

<script>
  const btn = document.getElementById("btn");

  function showMessage() {
    alert("クリックされました！");
  }

  btn.addEventListener("click", showMessage);
</script>

ポイント解説

  • function showMessage() {} → 実行したい処理を関数として定義
  • addEventListener("click", showMessage)

→ クリック時に関数を呼び出す

※ showMessage() と ()を付けない のが重要です。

🔹 引数ありのfunction + イベント

<button id="btn">クリック</button>

<script>
  const btn = document.getElementById("btn");

  function showMessage(message) {
    alert(message);
  }

  btn.addEventListener("click", function() {
    showMessage("ボタンが押されました！");
  });
</script>

👉 イベント + 自作引数 を一緒に使うパターンです。

🔹 イベントオブジェクトを使う例

<button id="btn">クリック</button>

<script>
  const btn = document.getElementById("btn");

  function showInfo(event) {
    console.log(event.target);
  }

  btn.addEventListener("click", showInfo);
</script>

👉 event.target → 実際にクリックされた要素

🔹 this を使ったfunction例

<button>赤</button>
<button>青</button>
<button>緑</button>

<script>
  const buttons = document.querySelectorAll("button");

  function changeColor() {
    this.style.background = this.textContent;
  }

  buttons.forEach(function(btn) {
    btn.addEventListener("click", changeColor);
  });
</script>

👉 クリックしたボタンの色に背景が変わります。

※ function を使うと this は「イベント元の要素」になる
（※ アロー関数だと this の挙動が変わります）

🔹 function と アロー関数の違い（イベント時）

書き方 this の指すもの
`function () {}` イベント元の要素
`() => {}` 外側のスコープ

🔹 よくあるミス ❌

btn.addEventListener("click", showMessage());

❌ 即実行されてしまう

⭕ 正解：

btn.addEventListener("click", showMessage);

🔹 実務でよく使う書き方（まとめ）

function handleClick(e) {
  console.log("クリック:", e.target);
}

btn.addEventListener("click", handleClick);
