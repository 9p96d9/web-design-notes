テンプレートリテラルで出力

  • プロンプト例

JavaScriptのテンプレートリテラルに解説して、問題例も５問作成して

テンプレートリテラルとは？
  • テンプレートリテラルは、文字列を簡単・柔軟に書ける記法です
  • バッククォート（ ` ）を使います
` 文字列 `

従来の書き方（シングルクォート）

const name = '太郎';
const message = 'こんにちは、' + name + 'さん！';

テンプレートリテラル

const name = '太郎';
const message = `こんにちは、${name}さん！`;

👉 ${} の中に変数や式を直接書ける のが最大の特徴です。

変数・計算式を埋め込める
const a = 10;
const b = 5;

console.log(`合計は ${a + b} です`);

【出力】

合計は 15 です
改行をそのまま書ける

従来の方法

const text = "こんにちは\nお元気ですか？";

テンプレートリテラル

const text = `こんにちは
お元気ですか？`;

👉 改行をそのまま書けて読みやすい

HTML文字列の生成がとても楽
const name = '花子';
const html = `
  <div>
    <p>こんにちは、${name}さん</p>
  </div>
`;

👉 Web開発で非常によく使われます

練習問題（5問）

問題①
  • 変数 name に 'Ken' が入っています。
  • テンプレートリテラルを使って
  • 「Hello, Ken!」 と表示してください。
問題②
  • price = 1200
  • tax = 1.1
  • テンプレートリテラルを使って「税込価格は 1320 円です」 と表示してください。
問題③
  • age = 20
  • 「あなたは20歳です」 と表示してください。
問題④
  • 次のような 複数行のメッセージ をテンプレートリテラルで作ってください。

おはようございます。
今日も頑張りましょう！

問題⑤（応用）
  • 次のHTMLをテンプレートリテラルで作ってください。
<div class="card">
  <h2>商品名: りんご</h2>
  <p>価格: 150円</p>
</div>

模範解答

解答①
const name = "Ken";
console.log(`Hello, ${name}!`);
解答②
const price = 1200;
const tax = 1.1;
console.log(`税込価格は ${price * tax} 円です`);
解答③
const age = 20;
console.log(`あなたは${age}歳です`);
解答④
const msg = `おはようございます。
今日も頑張りましょう！`;
解答⑤
const product = 'りんご';
const price = 150;

const html = `
<div class="card">
  <h2>商品名: ${product}</h2>
  <p>価格: ${price}円</p>
</div>
`;
