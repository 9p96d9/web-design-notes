JavaScript 学習ロードマップ（初心者向け）

フェーズ0：準備（1日）
ゴール：学習環境に慣れる

  • ブラウザ（Chrome）
  • エディタ（VS Code）
  • DevTools（右クリック → 検証）

やること

  • console.log("Hello"); を表示
  • エラーが出ても慌てない
フェーズ1：超基礎文法（1週間）

ゴール：読める・書ける感覚を掴む

学ぶ内容

  • 変数（let, const）
  • データ型（文字・数値・真偽）
  • 演算子（+, -, ===）
  • if / else

ミニ課題

  • 年齢判定プログラム
  • 数字が偶数か判定
フェーズ2：繰り返しと配列（1週間）

ゴール：データ処理ができる

学ぶ内容

  • for / while
  • 配列
  • 配列 + ループ

ミニ課題

  • 配列の合計を出す
  • 名前一覧を表示
フェーズ3：関数とオブジェクト（1週間）

ゴール：コードを整理できる

学ぶ内容

  • 関数
  • 引数 / 戻り値
  • オブジェクト

ミニ課題

  • ユーザー情報を表示
  • 計算用関数を作る
フェーズ4：DOM操作（2週間）

ゴール：Webページを操作できる

学ぶ内容

  • getElementById
  • querySelector
  • addEventListener
  • class操作

ミニ課題

  • ボタンで文字変更
  • カウンターアプリ
フェーズ5：少し実践的なJS（1週間）

ゴール：実務っぽい処理に慣れる

学ぶ内容

  • フォーム入力取得
  • バリデーション
  • localStorage
  • 簡単なデバッグ

ミニ課題

  • メモアプリ
  • 入力チェックフォーム
フェーズ6：ミニアプリ制作（2週間）

ゴール：自力で作れる自信をつける

おすすめ制作物

  • ToDoリスト
  • 電卓
  • じゃんけん
  • クイズアプリ

意識すること

  • 完璧を目指さない
  • ググりながらでOK
  • 動けば勝ち
フェーズ7：次のステップへ

進路別ガイド

Web制作なら

  • 非同期処理（Promise / async）
  • API連携
  • React / Vue

バックエンドなら

  • Node.js
  • Express
  • DB（MongoDB / MySQL）
学習ペース目安
  • 平日30分〜1時間でもOK
  • 週末にまとめて復習
  • 毎日触ることが最強

迷ったらこの順番だけ覚えて👇

変数 → if → ループ → 配列 → 関数 → DOM → 小作品
