乱数の発生

乱数 2025/10/19

乱数の発生 - random関数

  • Math.random() 関数は、 0 以上 1 未満 (0 は含むが、 1 は含まない) の範囲で浮動小数点の擬似乱数を返します
乱数の発生
  • 「random()」は、「0以上１未満の乱数を生成する」メソッド
<script>
for (let i=1; i<=5; i++) {
  let rnd = Math.random();
  console.log(rnd);
}
</script>

実行結果

ランダムな「整数」を生成する
  • 「floor()」は、「小数点以下を切り捨てる」メソッド

rnd = Math.floor(Math.random() * MAX + 1);

<body>
<h1>乱数を整数化して表示</h1>
<button id="generate">乱数を生成</button>
<h2 id="ans"></h2>
<script>
const maxNum = 6;
const element = document.getElementById('ans');
const button = document.getElementById('generate');

button.addEventListener('click', () => {
  element.innerHTML = ''; // 以前の結果をクリア
  for (let i = 1; i < maxNum; i++) {
    const num = Math.floor(Math.random() * maxNum + 1);
    element.innerHTML += `<p>${num}</p>`;
  }
});
</script>
</body>

おみくじ

ES6の場合

<body>
<h1>おみくじの結果を表示</h1>
<p>ボタンを押すと結果が表示されます。</p>
<button id="btn">おみくじを引く</button>
<h2 id="ans">ここに結果を表示</h2>
<script>
const result = () => {
  const omikuji = ['大吉', '吉', '中吉', '小吉', '凶'];
  const rnd = Math.floor(Math.random() * omikuji.length);
  const element = document.querySelector('#ans');
  element.textContent = omikuji[rnd];
};

document.querySelector('#btn').addEventListener('click', result);
</script>
</body>
