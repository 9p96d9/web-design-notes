🔰 アルゴリズムとは？

アルゴリズム = 問題を解決するための手順（やり方）
もっと簡単に言うと

「目的を達成するための順番どおりの作業リスト」

です。

🍳 料理で例えると
カレーを作るアルゴリズム

  1. 野菜を切る
  2. 肉を炒める
  3. 野菜を入れる
  4. 水を入れて煮る
  5. ルーを入れる

➡ この 手順の流れ = アルゴリズム

プログラミングでのアルゴリズム

プログラムは、

コンピュータに「何を」「どの順番で」やるかを指示する

ため、アルゴリズムがとても重要です。

例：1〜10までの合計を求める

考え方（アルゴリズム）

  1. 合計を入れる箱を用意
  2. 1〜10まで順番に足す
  3. 結果を表示
let sum = 0;

for (let i = 1; i <= 10; i++) {
  sum += i;
}

console.log(sum);

アルゴリズムの基本パターン3つ

  • ほとんどのプログラムは、この 3つの組み合わせ です
順次（じゅんじ）
  • 上から順番に実行
console.log("A");
console.log("B");
console.log("C");

➡ A → B → C の順で実行

分岐（ぶんき）
  • 条件によって処理を変える
let age = 20;

if (age >= 18) {
  console.log("大人です");
} else {
  console.log("子供です");
}
反復（繰り返し）
  • 同じ処理を何度も行う
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

➡ 1〜5を表示

🎯 よくあるアルゴリズム例（超重要）

最大値を求める
let numbers = [3, 7, 2, 9, 5];
let max = numbers[0];

for (let i = 1; i < numbers.length; i++) {
  if (numbers[i] > max) {
    max = numbers[i];
  }
}

console.log(max); // 9

考え方
最初の数を最大値とする

  1. 1つずつ比べる
  2. 大きければ更新
配列の合計
let numbers = [1, 2, 3, 4, 5];
let sum = 0;

for (let num of numbers) {
  sum += num;
}

console.log(sum); // 15
