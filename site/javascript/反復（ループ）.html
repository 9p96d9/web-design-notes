反復（ループ）

  • プロンプト例

JavaScriptで反復（ループ）の解説をして

  • ループとは、同じ処理を何度も繰り返す仕組みです。
  • 例えば「1〜10まで表示する」「配列の全要素を処理する」などで使います。

for 文（最も基本）

基本構文

for (初期化; 条件式; 更新) {
　繰り返したい処理
}

例：1〜5を表示
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

流れ

  1. let i = 1 → 変数を初期化
  2. i <= 5 → 条件チェック
  3. 中の処理実行
  4. i++ → 1増やす
  5. ②に戻る

while 文（条件が true の間繰り返す）

基本構文

while (条件式) {
　繰り返したい処理
}

例：1〜5を表示
let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}

📌 条件がずっと true のままだと無限ループになるので注意！

do...while 文（必ず1回は実行）
let i = 1;

do {
  console.log(i);
  i++;
} while (i <= 5);

👉 条件チェックが後なので、最低1回は必ず実行されます。

for...of（配列のループに最適）

例：配列の全要素を表示

const fruits = ['りんご', 'みかん', 'バナナ'];

for (const fruit of fruits) {
  console.log(fruit);
}

👉 配列の中身を1つずつ取り出すのに便利

forEach（配列専用）
const fruits = ['りんご', 'みかん', 'バナナ'];

fruits.forEach(function(fruit) {
  console.log(fruit);
});

またはアロー関数：

fruits.forEach(fruit => console.log(fruit));

break / continue

break：ループを中断
for (let i = 1; i <= 10; i++) {
  if (i === 5) break;
  console.log(i);
}

👉 1〜4 まで表示

continue：その回をスキップ
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  console.log(i);
}

👉 1, 2, 4, 5 を表示

よく使うループの使い分け

目的 おすすめ
回数が決まっている for
条件次第で繰り返す while
配列の中身処理 for...of / forEach
🔰 よくある実用例

配列の合計を求める

const numbers = [10, 20, 30];
let sum = 0;

for (const n of numbers) {
  sum += n;
}

console.log(sum); // 60
