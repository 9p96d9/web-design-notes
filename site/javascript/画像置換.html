画像置換

script.js

const thumbnails = document.querySelectorAll('.thumbnail');
const mainImage = document.querySelector('#mainImage');

thumbnails.forEach(thumb => {
    thumb.addEventListener('click', function() {
        // すべてのサムネイルからactiveクラスを削除
        thumbnails.forEach(t => t.classList.remove('active'));
        
        // クリックされたサムネイルにactiveクラスを追加
        this.classList.add('active');
        
        // メイン画像を変更
        const mainSrc = this.getAttribute('data-main');
        mainImage.src = mainSrc;
    });
});
① サムネイル画像を取得
const thumbnails = document.querySelectorAll('.thumbnail');

意味

  • .thumbnail という クラスを持つ要素をすべて取得
  • 複数あるので 配列のようなリスト（NodeList） になる

【例】

<img class="thumbnail" src="img1.jpg">
<img class="thumbnail" src="img2.jpg">
<img class="thumbnail" src="img3.jpg">

この3枚全部が thumbnails に入る。

② メイン画像を取得
const mainImage = document.querySelector('#mainImage');

意味

  • #mainImage の idを持つ要素を取得

【例】

<img id="mainImage" src="main.jpg">

この画像が 大きい表示用の画像。
