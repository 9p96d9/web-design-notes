超入門問題（テンプレートリテラル編）

演習課題 2025/10/06

prompt() + テンプレートリテラル編

  • 入力と出力の練習
  • prompt() で入力を受け取る
  • 文字列 → 数値の変換
  • テンプレートリテラル（``）バッククォートで囲む文字列で出力
実行環境
  • JavaScript Playground

playcode.io

第1問：名前を入力してあいさつしよう

【問題】

  • ユーザーに名前を入力してもらい、「こんにちは、〇〇さん！」と表示してください。

【ヒント】

  • prompt() を使うと入力を受け取れます。

【解答例】

const name = prompt("あなたの名前を教えてください：");
console.log(`こんにちは、${name}さん！`);
第2問：好きな食べ物を聞こう

【問題】

  • ユーザーに「好きな食べ物」を聞いて、「あなたの好きな食べ物は〇〇ですね！」と表示してください。

【解答例】

const food = prompt("好きな食べ物は何ですか？");
console.log(`あなたの好きな食べ物は${food}ですね！`);
第3問：年齢を聞いて来年の年齢を出そう

【問題】

  • ユーザーに年齢を聞いて、「来年は〇歳ですね」と表示してください。

【ヒント】

  • 入力された値は文字列なので、計算の前に数値に変換します。

　→ Number() を使います。（小数点、負の数も含む）
　→整数化（切り捨て）の場合は、parseInt()を使います。

【解答例】

let age = prompt("あなたの年齢を教えてください：");
age = parseInt(age);
console.log(`来年は${age + 1}歳ですね`);
第4問：商品の合計金額を計算しよう

【問題】

  • ユーザーに「商品価格」と「個数」を入力してもらい、「合計金額は〇〇円です」と表示してください。

【解答例】

const price = parseInt(prompt("商品の価格を入力してください："));
const count = parseInt(prompt("購入する個数を入力してください："));
console.log(`合計金額は${price * count}円です`);
第5問：簡単な自己紹介を作ろう

【問題】

  • ユーザーに名前・年齢・出身地を入力してもらい、「私は〇〇です。〇歳で、〇〇出身です。」と表示してください。

【解答例】

const name = prompt("あなたの名前を教えてください：");
const age = prompt("あなたの年齢を教えてください：");
const place = prompt("あなたの出身地を教えてください：");

console.log(`私は${name}です。${age}歳で、${place}出身です。`);
