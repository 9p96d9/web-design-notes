ページを操作

DOMイベント 2025/10/14

JavaScriptでページを操作

DOMツリーを操作する
  • HTMLはツリー構造になっていて、階層化されています
  • HTMLに相当する要素を「document」というオブジェクトで参照できます

idで要素を特定する
  • 子要素の順番をたどるのはわかりにくい
  • id属性を指定して変更する
  • 例：id名：ボタン「btn」、書き換える要素「msg」
  • 「textContent」は、HTMLを解釈せずにそのまま文字として出力する
<body>
<h1>ボタンのクリックでメッセージを表示</h1>
<button id="btn">押してください</button>
<h2 id="msg">ここを書き換える</h2>
<script>
  const btn = document.querySelector('#btn');
  const msg = document.querySelector('#msg');

  const btnClick = () => {
    msg.textContent = '押されました。';
  };

  btn.addEventListener('click', btnClick);
</script>
</body>

文字を入力

  • テキストボックスに入力された文字を取得する
  • 「value属性」で、入力された文字を取得できる

変数に代入

  • 処理の途中の値や計算結果、ユーザーが入力したデータなどさまざまな値を一時的にメモリに保存する
  • 変数には、変数宣言が必須（let）
  • 変数の値を何度も利用する場合は、実行速度が速くなります

let message = document.getElementById('mytext').value;
