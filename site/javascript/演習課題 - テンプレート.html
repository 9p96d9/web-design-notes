提出サムネイル
  • JavaScriptを実装したページを提出課題として表示するページへリンクする

モバイルシミュレーター - レスポンシブテストツール

  • Chrome「拡張機能」

デバイスフレームのスクリーンショット

記述ポイント

  • ページ全体のレイアウト（ヘッダー・メイン・フッター）を作るときによく使うGridで設定します。
  • 「フッターを常に画面下に配置するレイアウト」でよく使われます。

display: grid;
grid-template-rows: auto 1fr auto;
min-height: 100vh;

① display: grid;

要素を Gridレイアウトにします。

display: grid;

これを指定すると、その要素の子要素がグリッドで配置されます。

<body>
  <header></header>
  <main></main>
  <footer></footer>
</body>

body{
  display: grid;
}

すると

  • header / main / footer が グリッドの行として並びます。
② grid-template-rows: auto 1fr auto;

行の高さのルールを決めています。

grid-template-rows: auto 1fr auto;

これは 3行のレイアウトです。

行 サイズ 意味
1行目 auto コンテンツの高さ
2行目 1fr 残り全部
3行目 auto コンテンツの高さ

ポイント
auto：中身の高さに合わせる
1fr：残りのスペースを全部使う

③ min-height: 100vh;
min-height: 100vh;

これは
画面の高さと同じ高さを最低限確保する
という意味です。

vhとは

vh = viewport height

【例】

  • 100vh = 画面の高さ100%

つまり

  • bodyの高さ = 画面いっぱい

になります。

この3つを組み合わせるとどうなる？

body {
  display: grid;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

結果

画面いっぱいの高さ
↓
header
main（余白全部）
footer

つまり
コンテンツが少なくてもフッターが下に来る

よくある問題

普通のHTML

header
main（短い）
footer

だと

header
main
footer
（下に余白）

になります。

しかしこのGridを使うと

header
main
（空白をmainが担当）
footer

になるので
フッターが画面下に固定されたように見える
