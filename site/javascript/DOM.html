DOM（Document Object Model）

  • プロンプト例

JavaScriptのDOMについてわかりやすく解説して

👉 HTMLをJavaScriptから操作するための仕組み（プログラミング用の表現）
WebページのHTMLは、ブラウザの中で 「ツリー構造」 に変換され、JavaScriptから自由にアクセス・変更できます。

DOMを一言でいうと

JavaScriptでHTMLを操作するための窓口

1. DOMのイメージ（超重要）

【html】

<body>
  <h1>タイトル</h1>
  <p>文章</p>
  <button>クリック</button>
</body>

これはDOMでは、次のようなツリー構造になります。

document
 └─ body
     ├─ h1
     ├─ p
     └─ button

👉 HTMLの各要素が「ノード」として階層構造になる

2. なぜDOMが必要なのか？

DOMがあることで、JavaScriptから以下のような操作ができます：

  • HTML要素の取得
  • テキストの変更
  • 属性の変更
  • 要素の追加・削除
  • スタイルの変更

つまり、

Webページを動的に変更できる

というのがDOMの最大の役割です。

3. DOMの基本構造

document オブジェクト
JavaScriptでは、HTML全体を document オブジェクトとして扱います。

document

これは DOMの入口 です。

4. 要素の取得（DOM操作の基本）
  • DOMの取得（要素の取り方）

1. idで取得（最重要）
【html】

<h1 id="title">見出し</h1>

【js】

const element = document.getElementById('title');
console.log(element);

2. classで取得
【html】

<p class="item">A</p>
<p class="item">B</p>

【js】

const items = document.getElementsByClassName('item');
console.log(items[0]);

👉 HTMLCollection（複数） が返る。

3. querySelector（超重要・万能）
【html】

<p id="text">A</p>
<p class="item">B</p>
<p class="item">C</p>

【js】

const el = document.querySelector('#text'); // id
const item = document.querySelector('.item[1]'); // classの2番目

【js】

const all = document.querySelectorAll('.item'); // classすべて
メソッド 内容
querySelector 最初の1つ
querySelectorAll 全て
  • CSSと同じ書き方ができるため 最も柔軟。
document.querySelector("#title"); // id
document.querySelector("ul li");  // 子孫

👉 今はほぼ querySelector だけ覚えればOK

5. DOM要素の中身の取得・変更

① テキストの操作
【js】

const h1 = document.querySelector("h1");
console.log(h1.textContent);

h1.textContent = "変更後のタイトル";
プロパティ 特徴
textContent 純粋なテキスト
innerText 表示されるテキスト

通常は textContent推奨。

② HTMLを含めた操作
【js】

p.innerHTML = '<strong>太字</strong>';

⚠ XSS対策のため、外部入力を入れない

6. 属性の操作

① 取得

img.getAttribute('src');

② 変更

img.setAttribute('src', 'sample.png');

③ 直接操作（よく使う）
c
img.src = 'sample.png';
|

7. クラス操作（超重要）
element.classList.add('active');
element.classList.remove('active');
element.classList.toggle('active');
element.classList.contains('active');
メソッド 内容
add 追加
remove 削除
toggle 付け外し
contains 含むか

👉 CSS連携の要

8. スタイル操作
element.style.color = 'red';
element.style.fontSize = '24px';

⚠ CSSはCSSで管理し、JSではclass操作推奨

悪い例

element.style.display = 'none';

良い例

element.classList.add('hidden');
9. 要素の作成・追加

要素の生成

const p = document.createElement('p');
p.textContent = "新しい文章";

DOMに追加

document.body.appendChild(p);

指定位置に追加

parent.appendChild(child);
parent.prepend(child);
10. 要素の削除
element.remove();

または

parent.removeChild(child);
11. DOM操作の全体イメージ
const ul = document.querySelector('ul');

const li = document.createElement('li');
li.textContent = '新しい項目';

ul.appendChild(li);

👉 「取得 → 作成 → 変更 → 追加」 がDOM操作の基本パターン。

12.DOMとメモリの関係

【js】

const p = document.querySelector('#text');

p → [DOMオブジェクトのアドレス]

【js】

p.textContent = '変更';

👉 DOMのメモリを書き換えている → 画面に反映

13. DOMの処理の流れ（理解が重要）
  • HTML読み込み
  • DOMツリー構築
  • JavaScript実行
  • DOM操作反映 → 画面更新

👉 DOM操作は 画面表示に直結 するため、無駄な操作はパフォーマンス低下につながる。
