最終問いかけ

理解度を確かめるための問いかけです。答えを考えてみてください。

Q1. Step 0のCSSで「ヘッダーとフッターの背景色を変えたい」場合

何箇所修正する必要がありますか？

Step 0のCSSには #6F4E37 が7箇所あります。ヘッダーとフッターだけ変えたくても、検索して1つずつ確認・修正が必要です。

Q2. Step 4で同じことをするには？

_variables.scss の $brand-color を1行変えるだけです。

/* _variables.scss */
$brand-color: #3b82f6;  /* ← ここだけ変えれば全体に反映 */
Q3. 新しいセクション「スタッフ紹介」を追加するなら？

どのパーシャルを作りますか？

_staff.scss を作成し、style.scss に1行追加します。

/* style.scss */
@use 'variables';
@use 'mixin';
@use 'base';
@use 'header';
@use 'card';
@use 'staff';    /* ← 追加するだけ */
/* _staff.scss（新規作成） */
@use 'variables' as v;
@use 'mixin' as m;

.staff {
  padding: v.$spacing-lg 0;

  &__grid {
    @include m.flex-row(space-between);
    flex-wrap: wrap;
    gap: v.$spacing-md;
  }

  &__card {
    text-align: center;
    flex: 1;
    min-width: 200px;
  }

  &__photo {
    width: 120px;
    height: 120px;
    border-radius: 50%;
    object-fit: cover;
  }

  &__name {
    font-weight: bold;
    color: v.$brand-color;
    margin-top: v.$spacing-sm;
  }
}

実力チェック

以下を自分で書けるか確認しましょう。

  • [ ] $変数名: 値; で変数を定義できる
  • [ ] 変数を使って色・サイズ・余白を管理できる
  • [ ] &__element でBEMのセレクタをネストできる
  • [ ] &:hover でホバースタイルをネストできる
  • [ ] @mixin 名前 { } でmixinを定義できる
  • [ ] @include 名前; でmixinを呼び出せる
  • [ ] 引数付きのmixinを定義・呼び出しできる
  • [ ] パーシャルを作って @use で読み込める
  • [ ] sass --watch で自動コンパイルできる
