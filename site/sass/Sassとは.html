Sassとは

Sass基礎 2026/04/09

Sassとは？

Sass（サス） とは、CSSを拡張した言語です。

  • 変数・ネスト・関数など便利な機能を加えて書ける
  • 最終的に通常のCSSに変換（コンパイル）して使う
  • 拡張子は .scss（SCSS記法）または .sass（インデント記法）
  • 現在の主流は .scss 記法

CSSが苦手な「繰り返し」「管理のしにくさ」を解決してくれるツールです。

コンパイルフロー

Sassで書いたファイルは、ブラウザが直接読めません。コンパイル（変換）してCSSにする必要があります。

あなたが書くファイル          ブラウザが読むファイル
┌─────────────────┐          ┌─────────────────┐
│  style.scss      │  sass    │  style.css       │
│  （Sass記法）    │ ──────→ │  （通常のCSS）   │
└─────────────────┘  コンパイル └─────────────────┘
ファイルを分割する場合

大きなプロジェクトでは、役割ごとにファイルを分割して管理します。

┌──────────────────┐
│ _variables.scss  │ ─┐
│ _mixin.scss      │  │  @use で読み込み
│ _header.scss     │  ├──→ style.scss ──→ style.css
│ _card.scss       │  │
│ _base.scss       │ ─┘
└──────────────────┘
  • _ で始まるファイルをパーシャル（部分ファイル）という
  • パーシャル単体ではCSSに変換されない
  • @use で読み込まれたときだけ出力される

学習の進め方

この教材では、架空のカフェサイトを題材にしてSassを段階的に学びます。

ステップ記事学ぶこと
Step 0CSSのみ版でつらさを体験CSSだけで書くと何が大変か
Step 1変数を導入$変数名で繰り返す値をまとめる
Step 2ネストを導入セレクタの入れ子構造
Step 3mixinを導入スタイルのかたまりを再利用
Step 4ファイル分割で完成形パーシャルで役割ごとに整理

各ステップを順番に読み進めることで、CSSの「つらさ」がSassによってどう解消されるかを体感できます。

CSSとの主な違い

機能CSSSass（SCSS）
変数--変数名（カスタムプロパティ）$変数名（直感的に使える）
ネストできない（毎回セレクタを書く）セレクタを入れ子にできる
再利用コピペしかない@mixin / @include で定義・呼び出し
ファイル分割@import（本番では非推奨）@use で安全に分割管理
ブラウザ対応手動でベンダープレフィックスを書くmixinにまとめて1行で呼び出す
