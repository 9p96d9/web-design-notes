Step 0：CSSのみ版でつらさを体験

ステップ演習 2026/04/09

このステップでやること

まずSassを使わず、CSSだけでカフェサイトを書いてみます。

目的は「Sassがないと何が大変か」を体感することです。一見うまく書けていても、変更・保守のしにくさに気づいてもらいます。

問いかけ：ブランドカラーを変えると何箇所直す？

「ブランドカラー（#6F4E37）を別の色に変えるとしたら、何箇所直す必要がありますか？」

以下のCSS例を見てください。ブランドカラーが複数箇所に散らばっています。

/* style.css （CSSのみ版） */

/* ヘッダー */
.header {
  background-color: #6F4E37;
}

/* ヒーローセクション */
.hero__btn {
  background-color: #6F4E37;
  border-color: #6F4E37;
}

/* メニューカード */
.menu-card__title {
  color: #6F4E37;
}

/* フッター */
.footer {
  background-color: #6F4E37;
}

/* ボタンホバー */
.btn:hover {
  background-color: #6F4E37;
}

/* 見出し装飾 */
.section-title::before {
  background-color: #6F4E37;
}

/* リンク色 */
a {
  color: #6F4E37;
}

数えると 7箇所 あります。ブランドカラーが変わるたびに7箇所修正するのは大変です。修正漏れが起きやすく、バグの温床になります。

ベンダープレフィックスのコピペ問題

ベンダープレフィックスとは、ブラウザ対応のために書く接頭辞です（-webkit-、-ms- など）。

flexboxを使うとき、完全なブラウザ対応のために次のように書く必要があります。

/* flexboxを使うたびにこれをコピペする必要がある */
.header__inner {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: justify;
      -ms-flex-pack: justify;
          justify-content: space-between;
}

.hero__content {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: center;
      -ms-flex-pack: center;
          justify-content: center;
}

.menu-grid {
  display: -webkit-box;
  display: -ms-flexbox;
  display: flex;
  -webkit-box-pack: start;
      -ms-flex-pack: start;
          justify-content: flex-start;
}

同じコードが3箇所以上に散らばっています。

  • 1箇所直し忘れると、そのブラウザだけ崩れる
  • プロパティを追加するたびにすべてのコピーを修正しなければならない
  • コードが長くなって読みにくい

Step 0のまとめ：CSSだけの「つらさ」

問題何が起きるか
色を変えたい同じ色コードを何箇所も直す
共通スタイルを直したいコピペした全箇所を直す
ベンダープレフィックスコピペが増え、修正漏れが起きやすい
ファイルが大きくなるどこに何が書いてあるか分からなくなる
