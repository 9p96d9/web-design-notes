Step 4：ファイル分割で完成形

ステップ演習 2026/04/09

ファイル分割とは？

これまでのStep 1〜3では、1つの style.scss にすべてを書いてきました。

Step 4では、役割ごとにファイルを分割して管理します。これが実務で使われる完成形です。

フォルダ構成

scss/
├── style.scss       ← @use で読み込むだけ。スタイルは書かない
├── _variables.scss  ← 変数の定義
├── _mixin.scss      ← mixinの定義
├── _base.scss       ← リセットCSSなど基本スタイル
├── _header.scss     ← ヘッダーのスタイル
└── _card.scss       ← ヒーロー・メニュー・カード・フッターのスタイル

パーシャル（部分ファイル）とは

ファイル名の先頭に _（アンダースコア）を付けたファイルをパーシャルといいます。

  • パーシャル単体では CSSに変換されない
  • @use で読み込まれたときだけ出力される
  • @use で読み込むとき、ファイル名の _ と拡張子は省略できる
/* style.scss */
@use 'variables';   /* _variables.scss を読み込む */
@use 'mixin';       /* _mixin.scss を読み込む */
@use 'base';        /* _base.scss を読み込む */
@use 'header';      /* _header.scss を読み込む */
@use 'card';        /* _card.scss を読み込む */

/* style.scss にはスタイルを書かない。読み込みのみ。 */

各ファイルの中身

_variables.scss
/* _variables.scss */
$brand-color:    #6F4E37;
$white:          #ffffff;
$text-color:     #333333;
$bg-color:       #faf6f2;
$font-size-base: 16px;
$spacing-sm:     12px;
$spacing-md:     24px;
$spacing-lg:     48px;
$border-radius:  8px;
_mixin.scss
/* _mixin.scss */
@use 'variables' as v;   /* 変数ファイルを読み込む */

@mixin flex-row($justify: flex-start) {
  display: flex;
  justify-content: $justify;
}

@mixin cover-image {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}

@mixin button($bg: v.$brand-color, $color: v.$white) {
  background-color: $bg;
  color: $color;
  padding: 10px 20px;
  border: none;
  border-radius: v.$border-radius;
  cursor: pointer;
}
_base.scss
/* _base.scss */
@use 'variables' as v;

*, *::before, *::after {
  box-sizing: border-box;
}

body {
  font-family: 'Noto Sans JP', sans-serif;
  font-size: v.$font-size-base;
  color: v.$text-color;
  background-color: v.$bg-color;
  line-height: 1.7;
  margin: 0;
}

img {
  max-width: 100%;
  height: auto;
}

a {
  color: inherit;
  text-decoration: none;
}
_header.scss
/* _header.scss */
@use 'variables' as v;
@use 'mixin' as m;

.header {
  background-color: v.$brand-color;
  padding: v.$spacing-sm v.$spacing-md;

  &__inner {
    @include m.flex-row(space-between);
    max-width: 1100px;
    margin: 0 auto;
  }

  &__logo {
    color: v.$white;
    font-size: 24px;
    font-weight: bold;
  }

  &__nav {
    @include m.flex-row;
    gap: v.$spacing-md;

    a {
      color: v.$white;

      &:hover {
        text-decoration: underline;
      }
    }
  }
}

@use と @import の違い

@import は古い方法で、現在は非推奨です。

@import（古い）@use（新しい）
名前空間なし（全変数がグローバル）あり（ファイル名が名前空間になる）
変数の参照$brand-colorv.$brand-color（as v の場合）
読み込み回数複数回読み込まれることがある1回だけ読み込まれる
推奨非推奨（将来削除予定）推奨
名前空間を省略する書き方
@use 'variables' as *;   /* as * で名前空間なし（@import に近い書き方） */

.header {
  background-color: $brand-color;   /* v.$brand-color ではなく $brand-color で使える */
}

小規模なプロジェクトや学習用途では as * も使われますが、大規模プロジェクトでは名前空間を明示する方が安全です。

Step 4のまとめ

ファイル分割の利点：

  • 役割ごとにファイルが分かれて探しやすい
  • チームで作業するとき担当範囲が明確になる
  • コンポーネント単位で管理できる
  • _variables.scss を変えれば全体のデザインが変わる

新しいセクション「スタッフ紹介」を追加するなら、_staff.scss というパーシャルを作り、style.scss に @use 'staff'; を1行追加するだけです。
