Step 1：変数を導入

ステップ演習 2026/04/09

変数とは？

Sassの変数は、「繰り返す値に名前をつけて1箇所にまとめる」機能です。

$brand-color: #6F4E37;  /* ← この1行を変えるだけで全体に反映！ */

Sassの変数は $変数名: 値; の形で定義します。

変数の定義と使い方

/* 変数の定義（ファイルの上部にまとめて書く） */
$brand-color:   #6F4E37;   /* ブランドカラー（コーヒーブラウン） */
$white:         #ffffff;
$text-color:    #333333;
$font-size-base: 16px;
$spacing-md:    24px;

/* 変数の使用 */
.header {
  background-color: $brand-color;  /* 変数を参照 */
  color: $white;
  font-size: $font-size-base;
}

.hero__btn {
  background-color: $brand-color;  /* 同じ変数 */
  padding: $spacing-md;
}

.footer {
  background-color: $brand-color;  /* 同じ変数 */
}

Step 0との比較

Step 0（CSSのみ）Step 1（変数あり）
ブランドカラー変更7箇所を手動修正$brand-color の1行だけ修正
フォントサイズ変更全箇所を検索・置換$font-size-base の1行だけ
修正漏れのリスク高いほぼない

変数の命名ルール

  • $ で始める
  • 英数字・ハイフン・アンダースコアが使える
  • 大文字・小文字は区別される（$Color と $color は別の変数）
  • ハイフン区切りが一般的（$brand-color）
よく変数にするもの
カテゴリ例
色$brand-color, $text-color, $bg-color
フォント$font-size-base, $font-size-sm, $font-family
余白$spacing-sm, $spacing-md, $spacing-lg
ブレークポイント$bp-tablet, $bp-desktop
ボーダー$border-radius, $border-color

コンパイルすると？

変数はコンパイル時に実際の値に置き換えられます。ブラウザが受け取るCSSはこうなります。

/* コンパイル後の style.css */
.header {
  background-color: #6F4E37;   /* $brand-color が展開された */
  color: #ffffff;
  font-size: 16px;
}

.hero__btn {
  background-color: #6F4E37;
  padding: 24px;
}

.footer {
  background-color: #6F4E37;
}

変数という概念はブラウザには届かず、コンパイル時点でただの値に変換されます。
