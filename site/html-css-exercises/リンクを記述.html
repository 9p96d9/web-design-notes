リンクを記述

HTML 2025/12/11

リンクを記述

  • プロンプト例

HTMLのリンクについて解説して

リンクとは？

  • HTMLのリンクは、別のページや場所へ移動するための仕組み
  • クリックすると、指定したURLやページにジャンプできる
基本構文（aタグ）
  • リンクは <a>（アンカータグ） を使う
<a href="#">ここをクリック</a>

各部分の意味

部分 説明
<a> リンクを作るタグ
href リンク先のURL（必須）
ここをクリック 画面に表示される文字

別ページへのリンク

🌐 外部サイトへのリンク
<a href="https://www.google.com">Google</a>

👉 クリックすると Google が開きます。

📁 同じサイト内のページへのリンク
<a href="about.html">会社概要</a>

フォルダ指定

<a href="pages/contact.html">お問い合わせ</a>

🎯 ページ内リンク（アンカーリンク）

同じページ内の特定位置へ移動できます。

移動先

<h2 id="section1">サービス内容</h2>

リンク

<a href="#section1">サービス内容へ</a>

🆕 新しいタブで開く（target="_blank"）

  • 属性「target="_blank"」を指定する
<a href="https://example.com" target="_blank">新しいタブで開く</a>

よく使う組み合わせ（セキュリティ対策）

<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  外部サイト
</a>
📧 メールリンク
  • メールを起動
<a href="mailto:test@example.com">メールを送る</a>
📞 電話リンク（スマホ向け）
<a href="tel:09012345678">電話をかける</a>
🖼 画像をリンクにする
<a href="https://example.com">
  <img src="logo.png" alt="ロゴ">
</a>
よくある注意点
  • href がないとリンクにならない
  • URLのタイプミスに注意
  • 外部リンクは _blank + rel が無難

CSSで見た目を変える

a {
  color: blue;
  text-decoration: none;
}
a:hover {
  text-decoration: underline;
}

🔥 よく使う属性まとめ

属性 説明
href リンク先URL
target 開き方
rel セキュリティ指定
download ファイルDL
title ツールチップ表示
📌 ダウンロードリンク
<a href="file.pdf" download>PDFをダウンロード</a>

🎓 実践サンプル

<!DOCTYPE html>
<html>
<body>

<h1>リンクの例</h1>

<a href="https://google.com" target="_blank">Google</a><br>
<a href="#bottom">ページ下へ</a>

<div style="margin-top:1000px;"></div>

<h2 id="bottom">ここがページの下</h2>

</body>
</html>
