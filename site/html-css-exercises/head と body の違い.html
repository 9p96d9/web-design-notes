head と body の違い

HTML 2025/12/05

head と body の違い

  • プロンプト例

headとbodyの違いを詳しく解説して

要素 役割
<head> ページの設定・裏側の情報
<body> 画面に表示される内容
<head> の役割（設定エリア）

👉 ブラウザや検索エンジン向けの情報

主な役割

  • 文字コードの指定
  • スマホ対応設定
  • ページタイトル
  • CSSの読み込み
  • JavaScriptの読み込み
  • SEO用の設定
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>自己紹介ページ</title>
  <link rel="stylesheet" href="style.css">
</head>

各タグの意味

タグ 役割
<meta charset="UTF-8"> 日本語が文字化けしない
<meta name="viewport"> スマートフォン対応
<title> タブに表示される名前
<link> CSSの読み込み
<script> JSの読み込み

📌 headの中身は基本的に画面には表示されません

<body> の役割（表示エリア）

👉 実際にユーザーが見る部分

主な役割

  • 文字
  • 画像
  • ボタン
  • リンク
  • 表
  • フォーム

【例】

<body>
  <h1>こんにちは！</h1>
  <p>私の自己紹介ページです。</p>
  <img src="photo.jpg" alt="プロフィール写真">
  <a href="#">お問い合わせ</a>
</body>
イメージで理解しよう

人間に例えると

HTML 人体
<head> 脳（設定・制御）
<body> 体（見える部分）
よくある間違い

❌ bodyに入れるべきでないもの

<meta charset="UTF-8">
<title>タイトル</title>

❌ headに入れるべきでないもの

<h1>見出し</h1>
<p>文章</p>
実践ミニサンプル
  • スマートフォン対応の記述は不要
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>headとbodyの違い</title>
</head>
<body>
  <h1>ここが画面に表示されます</h1>
  <p>これはbodyの中身です。</p>
</body>
</html>
