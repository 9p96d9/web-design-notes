🎯 1カラム練習に最適なテーマ

  • プロンプト例

1カラムで作りたい

🥇 テーマ：架空のカフェ紹介サイト（最もおすすめ）

理由

  • 構造がシンプル
  • sectionを自然に3〜4個作れる
  • 文章中心でデザインに集中できる
  • 画像も使える
🧱 基本構造（1カラム）
<body>
  <header></header>
  <main>
    <section></section>
    <section></section>
    <section></section>
  </main>
  <footer></footer>
</body>

📘 練習課題（具体的設計）

🟢 課題1：固定幅1カラム

条件

  • 幅：800px
  • 中央寄せ（margin: 0 auto;）
  • 背景色：bodyは薄いグレー
  • mainは白
  • headerは濃い色＋白文字

セクション内容

  1. コンセプト
  2. メニュー紹介
  3. アクセス情報
🟡 課題2：余白設計を意識する
  • sectionごとに padding を設定
  • h2 と p の間に margin
  • footer は中央揃え

→ 「余白＝デザイン」という感覚を身につける

🔵 課題3：色彩設計
  • ベースカラー
  • アクセントカラー
  • 補色を使ったボタン
