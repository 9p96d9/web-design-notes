背景画像- スペイン観光

コーディング演習 2025/12/16

背景画像- スペイン観光

  • プロンプト例

シンプルな１カラムでWebページを作成したい

  • テーマ「スペイン観光」
  • header,main,footer
  • headerには、h1とpが入り背景画像の設定
  • mainには、h2「おすすめスポット」section内にh3とpで４ブロック
  • footerには、著作マーク
テキスト
スペイン観光
情熱と歴史が彩る国・スペインの魅力を巡る旅

おすすめスポット
バルセロナ
ガウディ建築と地中海の美しい街並みが魅力の都市です。

マドリード
美術館と王宮、活気ある街の雰囲気を楽しめます。

セビリア
フラメンコと歴史的建築が融合したアンダルシアの中心地。

グラナダ
世界遺産アルハンブラ宮殿が有名な幻想的な街です。
