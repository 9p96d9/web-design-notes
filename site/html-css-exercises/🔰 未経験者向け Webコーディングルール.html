🔰 未経験者向け Webコーディングルール

  • プロンプト例

未経験者が作るWebページのコーディングルール

① ファイル・フォルダ構成の基本

まずは 整理された構成 を作ることが超重要です。

project/
 ├ index.html
 ├ css/
 │   └ style.css
 ├ js/
 │   └ script.js
 └ img/

ルール

  • HTML / CSS / JS を分ける
  • 画像は必ず img フォルダに入れる
  • ファイル名は 英小文字 + 単語区切りはハイフン

【例】main-visual.jpg, site-header.css

② HTMLの基本ルール

インデント（字下げ）を必ず揃える

<header>
  <h1>タイトル</h1>
  <nav>
    <ul>
      <li>メニュー</li>
    </ul>
  </nav>
</header>

→ 構造が一目で分かる = バグ防止

正しいタグを使う（意味を大切に）

目的 タグ
見出し <h1>～<h6>
段落 <p>
リスト <ul> <li>
ナビ <nav>
ヘッダー <header>
フッター <footer>

❌ <div> ばかり使う → NG
⭕ 意味のあるタグを優先

class名の付け方
何の役割か分かる名前にする

<div class="header">
<div class="main-visual">
<div class="contact-form">
③ CSSの基本ルール

CSSは必ず外部ファイルで管理

<link rel="stylesheet" href="css/style.css">

❌ HTML内に直接書く
⭕ CSSファイルにまとめる

上から「大 → 小」構成で書く

/* 全体 */
body {}

/* レイアウト */
.header {}
.main {}
.footer {}

/* 部品 */
.btn {}
.card {}

数値の単位ルール

用途 推奨
文字サイズ rem
余白 px or rem
幅 % or px

まずは px でOK！

④ 命名ルール（class名）

基本形：役割 + 内容

.header
.header-logo
.header-nav
.main-visual
.news-list
.news-item

誰が見ても意味が分かる名前が正解

⑤ コメントを必ず書く

HTML

<!-- ヘッダー -->
<header>

CSS

/* ===== ヘッダー ===== */
.header {}

→ 後で見返したときの自分を助ける

⑥ コーディングの正しい手順
  1. ワイヤーフレーム（簡単な構成図）を書く
  2. HTMLで構造を作る
  3. CSSでデザイン
  4. レスポンシブ対応

最初からデザインしない！

⑦ 初心者が必ず守るべき5大ルール
  1. インデントを揃える
  2. 意味のあるタグを使う
  3. class名は分かりやすく
  4. CSSを整理して書く
  5. コメントを書く
⑧ 超おすすめ学習ステップ

① HTMLのみでページを完成させる
→ 構造理解

② CSSで見た目を整える
→ デザイン理解

③ レスポンシブ対応
→ 実務レベル

⑨ 超初心者用 最小テンプレート
<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>サイトタイトル</title>
<link rel="stylesheet" href="css/style.css">
</head>
<body>
<!-- header -->
<header class="header">
  <h1>サイトタイトル</h1>
</header>
<!-- /header -->

<!-- main -->
<main class="main">
  <p>本文</p>
</main>
<!-- /main -->

<!-- footer -->
<footer class="footer">
  <p>© 2026</p>
</footer>
<!-- /footer -->
</body>
</html>
