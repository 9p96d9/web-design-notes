HTMLの表組みについて解説して

HTMLの表組み（テーブル）とは？

HTMLの表組み（table）は、行と列を使ってデータを整理して表示するための仕組みです。

基本構造
  • <th>は見出し。文字が太字＋中央揃えになる（ブラウザ標準）
  • <tr>の中に <th> や <td> を並べる
<table>
  <tr>
    <th>名前</th>
    <th>年齢</th>
  </tr>
  <tr>
    <td>田中</td>
    <td>25</td>
  </tr>
  <tr>
    <td>佐藤</td>
    <td>30</td>
  </tr>
</table>

タグの意味

  • HTMLの表は、主にこのタグで構成されます
タグ 意味
<table> 表全体
<tr> 行（table row）
<th> 見出しセル（table header）
<td> データセル（table data）

行・列の考え方

<tr> ← 行
<td> ← 列（セル）

  • この場合、1行3列
<table>
<tr>
  <td>A</td>
  <td>B</td>
  <td>C</td>
</tr>
</table>
セルを結合する（重要）

列を結合（横に広げる）

  • 横方向の結合（colspan）
<td colspan="2">2列分</td>

行を結合（縦に広げる）

  • 縦方向の結合（rowspan）
<td rowspan="2">2行分</td>

<table border="1">
  <tr>
    <th>名前</th>
    <th colspan="2">連絡先</th>
  </tr>
  <tr>
    <td>田中</td>
    <td>電話</td>
    <td>メール</td>
  </tr>
</table>
意味を持たせるタグ（少しレベルアップ）
  • アクセシビリティ & 可読性アップ

表の論理構造（thead, tbody, tfoot）
タグ役割
<thead>見出し部分
<tbody>データ部分
<foot>合計・注釈など
→ アクセシビリティと保守性が向上

<table border="1">
  <thead>
    <tr>
      <th>商品</th>
      <th>価格</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>りんご</td>
      <td>100円</td>
    </tr>
    <tr>
      <td>みかん</td>
      <td>80円</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>合計</td>
      <td>180円</td>
    </tr>
  </tfoot>
</table>

border="1" は使っていい？
→ 学習用OK / 実務NG
→ 実務では CSSで制御

見た目を整える（CSSと一緒に使う）
  • HTMLだけだと線が出ないので、CSSで装飾するのが一般的
<style>
  table {
    border-collapse: collapse;
  }
  th, td {
    border: 1px solid #333;
    padding: 8px;
  }
</style>

border-collapse: collapse;

  • 罫線が二重にならず、きれいに表示される
表組みを使うときの注意点 ⚠️
  • ❌ divだけで表を作ってはいけない
  • ❌ レイアウト目的で table を使う
  • ⭕ データ表現のみに使う
よくある使いどころ
  • 成績表・一覧表
  • 管理画面のデータ一覧
  • CSVデータの表示
  • スケジュール表
まとめ
要素 ポイント
table 表全体
tr 行
th 見出し
td データ
colspan / rowspan セル結合
thead / tbody / tfoot 意味構造
